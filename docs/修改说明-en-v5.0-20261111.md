### 2.3 两处指定更新（P0 · 本次核心）

**更新 1 · 作者指南 AI 获取**

- `en/03-定刊.md` 新增「6.1 作者指南获取（AI 主动取数 + 人工核对门禁）」三层口径：取数层（AI 搜索下载官方原文存档到 `03-定刊/原文/`）/ 核对层（人对照官方原文逐条核，硬门禁）/ 留证层（来源 URL / 抓取日期 / 存档路径三列）。
- 硬约束表加「来源 URL / 抓取日期」两列，新增「投稿系统」「字符限制字段」两行。
- `en/B-模板.md` 模板 8 同步加两列两行；`en/01-起步.md:38` 的 `原文/` 目录说明扩展。
- `en/00-总览.md` 第六节第 3 步 AI 可做列补「主动搜索并下载官方《作者指南》存档」，人必须做列补「对照官方原文逐条核硬约束」。
- 新增 `D-提示词/D3c-定刊-作者指南获取.md`。
- **调和口径**：保留「定刊当天、写正文前」「逐条可核」「没有官方原文不许写正文」三条时机铁律，显式写明「**自动获取 ≠ 替代人工核对**」。只放宽「谁去取」，不放宽「谁拍板、以什么为准」——避免推翻被两篇论文验证过的防幻觉铁律（旧条文「用户亲自下载、AI 不得转述替代」的历史理由仍成立，只是载体从「人」换成「AI 取数 + 人核」）。

**更新 2 · AI 自动资料获取路径**

- `en/03-定刊.md` 新增「四·补 AI 自动资料获取路径」：**四级效力源表**（A 官方硬约束源 = 唯一判据源 / B Crossref+OpenAlex API = 可核验元数据 / C Wikipedia 镜像 + 期刊官方 RSS 静态页 = 探索性线索、**不作判据性事实源** / D 兜底）；四类源用法；`curl api.crossref.org/works/{DOI}` 与 `?query.bibliographic=` 题名反查、Windows SSL 失败改 curl；《闭环：AI 取数 → 留证三列 → 人拍板》。
- `en/02-选题.md` 第三节「去哪找」加自动取数入口；`en/04-两库.md` 新增第六节「自动资料获取入口」并挂四查的 DOI 双通道。
- 新增 `D-提示词/S6-自动资料获取.md`、`S7-DOI双通道核验.md`。
- **这是净新增**：原私有资料与旧 `en/` 均无 Wikipedia / RSS / 镜像 / OpenAlex 的自动获取路径（仅 Crossref 作 DOI 实测），无历史条文可照搬；分级是为了不重蹈「凭非官方渠道定机构英文名」的覆辙。
