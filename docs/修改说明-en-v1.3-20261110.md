# 英文线 v1.3 修改说明（2026-11-10）

> 范围：`en/`；`zh/` 不动（仓库版本随之升为 v3.0，中文线仍为 v5）。
> 性质：**补回丢失的两层内容**，不是改骨架。九步一步没加，加的是"怎么判断自己错了"和"具体怎么动手"。

---

## 一、触发：诊断出两类内容被抽象掉了

对照两条产线的实战记录（两篇论文的写作大事记、幻觉根源与防复发机制、六大重点复盘）与 v3.0.2 原稿复核，v1.2 的英文线丢的不是"翻译细节"，是两层：

| 层 | 是什么 | v1.2 的缺口 |
|---|---|---|
| **攻击层** | 判断自己是不是错了 | 对抗审查只剩 4 行；命题反例检验整章缺失；无审稿记录 |
| **执行层** | 具体怎么动手 | 找刊只有骨架没有来源与判据；文献只剩"四查"；26 份提示词压成 1 段 |

量化对照（改动前）：

| 项 | 中文线 | 英文线 v1.2 |
|---|---|---|
| 正文总字符 | 6.5 万 | 3.6 万 |
| 可直接粘贴的提示词 | 26 份 / 2.1 万字 | 1 段 |
| 对抗审查 | 独立一步 + 硬门禁 + 3 份提示词 | 4 行 |
| 文献核验 | 三步串行 + 渠道表 + 4 份提示词 | 四查 12 个勾选框 |

**最要命的不是缺条数，是缺解药**：`07` 的 48 条记录写得不错，但每条只到"症状 → 根因 → 拦截点"，没写"怎么救"。查到"综述被批 descriptive"，翻到方法文件只有一句"每组写三句"。**查得到病因，抓不到药**——这是"质量不如中文版"的真实来源。

## 二、改了什么

### 2.1 攻击层（P0，不补这份 SOP 不成立）

| 文件 | 改动 | 为什么 |
|---|---|---|
| **`08-对抗审稿法.md`（新增）** | 发现型/复查型分工、命题反例四步、文内自拆、处置四选一、方法 A/B/C/D、意见编号与分级、记录表 | 原稿最硬的一块（8.2/8.6）在英文线零字；没有它，第 5 步到第 6 步是"直接下笔"，中间没有任何针对命题的拦截 |
| `01` 新增 **5-5** | 写最强反驳 → 判证据强度 → 标正文是否回应 → 处置四选一（改命题／限定范围／补论据／写进局限）；**定硬门禁**，不过不许进第 6 步；改命题须回第 2 步返工并重跑受影响检查 | v1.1 的教训已经付过代价：先清稿才补做对抗检验，结果 P1 改命题、P2 降档，相关段落全重写，已导出的 docx 作废 |
| `01` **8-6 重写** | 从"三个立场各提 3 条"扩为：**发现型只在中文稿做**（成本差数倍，且只有中文稿你能把关）＋英文阶段只做落地复查/英文专有维度/通畅＋禁止英文阶段提内容级建议＋意见必须给原文定位与致命/重要/次要分级，无定位视为无效 | 原来那句"各提 3 条"最大问题是**没有分工**：在英文阶段提"应该补一节"，采纳一次就全稿重译 |
| `01` 5-4 后加**段型前置** | 逐段标论证/描述/推演 + 导语/小结，再动笔 | 见 2.2 |
| `03` 表 11 | 命题-反例-回应表（含证据强度、正文是否回应、处置结论） | 对抗审查必须落文件，否则"审过没审过"说不清 |

### 2.2 执行层 · 选刊（P0）

| 文件 | 改动 |
|---|---|
| `01` **3-1b 新增** | 权威源分级：MJL Collection 字段是收录判定金标准／JCR 是 IF 官方源／分区表必须标口径／**预警名单必查**／Scopus-SJR 只作补充不作判定依据／Aims & Scope 作主题匹配终审／**已发表文献反查最重要** |
| `01` **3-2 加先例检索** | "这刊收不收这个概念稿"要**拿先例文章证**，不靠类型清单。做法：翻 2–3 期样刊的全部研究论文，数其中"0 图 0 表"的纯概念稿有几篇 |
| `01` **3-3 重写** | 候选池表（每刊一行，**"主题匹配证据"列是全表灵魂**）＋顺位判据：**初审周期 / 录用率 / 试错成本**，三项至少两项有数；排除项成条（增刊特刊默认排除、ESCI 有 IF 有分区但不计正刊） |
| `03` 表 9、表 10 | 候选池表、近刊对标四栏笔记 |
| `02` | 指南与近刊实刊冲突时**按更严的执行**，并在 Cover Letter 说明 |

**脱敏后的实例写法**（保留结构，不保留身份）："某刊初审 11 天、录用率约 5%，适合先投试错；另一刊初审 30 天、约 11%，作主攻；第三刊约 23%，作保底"。

### 2.3 执行层 · 文献核验（P0）

`02` 的文献部分由"四查 + 一个脚本"改为**三步串行**：

| 步 | 内容 | 关键点 |
|---|---|---|
| **查一 · 真实性（1-0～1-3，三档）** | Crossref 为核心（DOI 优先解析）／期刊官网／Scopus 公开页／Google Scholar 只作兜底且**不能推翻 Crossref**／arXiv 独立核／**中国 DOI 走 doi.org 会重定向 chndoi.org，属正常不是错** | 判定三档：**可信**（≥2 个独立权威源核心字段一致；格式差异不算事实错误）／**存疑**（仅弱源可检、增刊内刊早期未数字化）／**疑似伪造**（全渠道无 + 刊名刊号不存在 + 年份早于创刊） |
| **查二 · 标号映射与条数对账** | 正文引用 ↔ 文献表双向闭合；同一文献出现次数上限；**条数 vs 选题阶段承诺区间对账**，少了要写理由 | 防"文献表 40 条，承诺 25–30 条，说不出为什么" |
| **查三 · 语义与漏引（3-0～3-5）** | L1 全量摘要级相关性（出疑点 + 置信度高/中/低）／L2 只对中低置信度 + 涉及关键数据方法定义的引文下全文逐句比对／**无编号转述扫描**（转述词表机械筛"含转述却无引用"的句子）／**引号内容审计 + 直引比例**（直引为 0 不得进清稿，目标 1%–5%，超 10% 必压）／页码以 PDF 页脚或文章编号为准 | 无编号转述扫描是**漏引的唯一防线**；原 v1.2 只查"表→正文"单向闭合 |

**修掉一个会误杀的判据**：v1.2 是二值判断"查不到就删"。英文线上这是错的——老文献、预印本、会议摘要、小众专著都会被误杀。现改为三档，"存疑"档降级使用而非删除。

### 2.4 执行层 · 提示词（P0）

新增 `en/提示词/` 12 份，全部是**可整段粘贴**的执行卡，含输入、分步指令、输出格式、自检项：

| 卡 | 对应动作 | 卡 | 对应动作 |
|---|---|---|---|
| 01 找刊候选发现 | 3-1b / 3-2 / 3-3 | 07 语义相关性与漏引 | 查三（L1/L2 + 转述扫描） |
| 02 近刊对标提取 | 3-5 | 08 引号内容审计 | 查三 3-4（直引比例） |
| 03 命题反方检验 | 5-5 | 09 期刊要求对照 | 3-4 之后 |
| 04 全文对照检查 | 6-2 / 8-5 | 10 投稿前终检与投稿信 | 9-1 / 9-2 |
| 05 文献真实性三档核验 | 查一 1-2 | 11 三角色审稿 | 8-6 |
| 06 标号映射与条数对账 | 查二 | 12 返修分级回应 | 9-4 |

不搬 26 份的理由：中文线的一半提示词是知网检索式、字形层、降 AI 率专用，英文线没有对应动作。

### 2.5 材料与事实层（P0）

`03` 新增 **表 12 材料与数字台账**，`01` 6-6 与 `05` 增补：任何进论文的数字必须能说出"分子是什么、分母是什么、出自哪张表"；**算不出来的数字不许进论文**。declaration 里"非实证/理论推演"的口径必须与正文实际材料一致，否则就是 `07` #54（声明非实证，正文却写"本研究发现 62%"）。

> 取舍：**不引入中文线的【论N】【述】【推】【料N】编号体系**——英文线材料形态差异大，编号维护成本高于收益。改为"台账 + 三问"，保留可追溯性。

### 2.6 质量层（P1，六处）

| # | 改动 | 位置 |
|---|---|---|
| 1 | **段落分型**：论证/描述/推演 + 导语/小结；**删掉 v1.2 "每段都有主张和证据"这条错判据**——描述段（现状、资源禀赋、案例）本不承担论证，按旧判据会逼出无料评价和"由此可见"包装 | `05` §十一、`01` 段型前置、`02` 终检 |

## 三、脱敏

本次复核发现仓库里有两处既有泄露（v1.1 遗留），已改：

| 位置 | 原文 | 改为 |
|---|---|---|
| `CHANGELOG.md` v1.1 段 | 真实刊名缩写、真实平台名 + 条数 | 主攻刊 A → 备选刊 B、某平台 47 条 |
| `docs/修改说明-en-v1.1-20261108.md` | 同上，另含真实专题卷期 | A 刊 / B 刊 / 某平台 |

原则：**保留结构，去掉身份**。"某刊初审 11 天、录用率 5%"这类句子保留全部信息量，不指向任何具体刊物。

**未处理、请你定**：`docs/使用边界.md` 与根 `README.md` 提到中文线示例名「陕西壁画 → 钧瓷」。该示例文件在 `zh/` 里本就有（`zh/示例-陕西壁画迁移到钧瓷.md`），属中文线既有公开内容。英文线已全部脱敏，但中文线这一处是否收敛，需要你判断——**如果这两个词指向你真实论文的对象，建议把文件名与正文对象都换成抽象代号**。

## 四、刻意不做的

| 内容 | 为什么不搬 |
|---|---|
| 知网检索式语法坑（括号内 OR、`%=` 回退、三级回退） | 英文线走滚雪球与引文反查，不走检索式 |
| 中文标点字形层（`w:hint="eastAsia"`）、CAJ、汉字↔Word 字数折算 | 中文排版与中文投稿生态专属 |
| 降 AI 率改写、查重、AI 率检测 | 中文检测生态专属；英文线只保留"AI 语言特征自检" |
| 【论N】【料N】编号体系 | 见 2.5 取舍说明 |
| 26 份提示词全量 | 只取英文线用得上的 12 份 |
| 12 个顶层目录 + 三线结构 | 压成 README 的交付清单，不搬目录层级 |

**没有扩步骤**：九步不变。v1.1 定的原则是对的——步骤一多，人和 AI 都记不住。
