# D5 结构 · 反方扮演

来源：`05-结构.md` 第五节。什么时候用：第 5 步，每条核心命题过一次。
前置条件：一条命题（在 Z 条件下，X 导致 Y）；主张-出处表。
人必须确认：处置四选一（改 / 限定 / 补 / 维持）与回应句。


```text
我给你一条命题：〔在 Z 条件下，X 导致 Y〕。
任务：站在最强反方，给 2 条具体反驳——要能指到数据、机制或同类文献，
不要"有人可能不同意"这种空话。
对每条反驳给四种处置选项中最合适的一个：改 / 限定 / 补 / 维持，并写一句回应。
约束：不得新造证据；不知道就说"需要补什么"。
输出：反驳1,反驳2,处置,回应句。
```

**使用提醒**：反驳必须指到数据、文号或机制，「有人可能不同意」不算反驳；不得新造证据。
