# S4 专卡 · 拒稿分诊

来源：`11-投递与返修.md` 第六、七节。什么时候用：第 11 步，收到拒稿信。
前置条件：拒稿信原文。
人必须确认：是否返修 / 换刊 / 回第几步。


```text
我给你拒稿信。
任务：判断是 desk reject（未外审）还是 post-review；
把意见归类：方法 / 命题 / 表达 / 范围。
给动作：回第几步、改什么、不改什么。
约束：不写"重写全文"这类建议；优先最小改动。
输出：类型 + 分类 + 动作表。
```

**使用提醒**：desk reject 回第 3 步换刊，不重写全文；前刊未终结绝不投他刊；不走「自动转投」。
