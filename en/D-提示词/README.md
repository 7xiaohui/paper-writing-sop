# D-提示词（索引 · v5.0）

> 每张卡一个文件，直接打开喂给 AI。**D 系列 = 主卡**（跟着 11 步走）；**S 系列 = 专卡**（跨步骤的封闭任务）。
> v5.0 起每张卡都有统一头部：**来源 / 什么时候用 / 前置条件 / 人必须确认 / 正文 / 使用提醒**。缺输入时 AI 会用默认值补，这就是幻觉的来源，所以「前置条件」必须写全。
> 判据以对应步骤正文为准；卡只产出草稿，不产出「可以进下一步」的结论。

## 用卡三条规矩

1. **每张卡都是封闭任务**：材料没给全，让 AI 说「材料不够」，不要让它编。
2. **AI 输出是草稿**：按 `../A-检查清单.md` 判；判不过，回卡重喂。
3. **不写「帮我润色整篇」**：整段润色必然改内容。一次一段、一次一任务。
4. **复核必须独立**：换会话 / 换模型重投，写的人不校自己的人。
5. **自动取数类卡（S6/D3c）只产出「原文 + 清单 + 留证」**，不产出「可以写正文」的结论；硬约束事实必须由人对照官方原文核。
