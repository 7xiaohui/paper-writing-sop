# D4b 两库 · 真实性三档核验

来源：`04-两库.md` 第五节「步骤一 · 真」。什么时候用：参考文献清单成形后、四查串行第一步。
前置条件：参考文献清单（含 DOI 列）；能联网；`04-两库/四查报告.md` 已建。
人必须确认：存疑 / 疑似伪造条目的处置（降级使用或删除）。

```text
你是文献真实性核验员。我给你一份参考文献清单（含 DOI）。逐条做：

1. 国际 DOI：curl https://api.crossref.org/works/{DOI}，比对返回的
   标题 / 第一作者 / 年份 / 刊名 / 卷期页 与清单是否一致；
2. 中国 DOI（CNKI 系）：若 Crossref 返回 404，**不要直接判错** ——
   中国 DOI 由 ISTIC 注册，走 doi.org 内容协商重定向到 chndoi.org，
   以 doi.org 能否解析（HTTP 200）为准；
3. 没有 DOI 的条目：用题名反查（Crossref ?query.bibliographic=题名）
   或期刊官网目次 / 官方题录交叉核实；仍查不到的标「存疑」，不删也不硬凑；
4. Windows 环境若 python urllib 因 SSL 证书失败 → 改用 curl。

三档判定（取代二值「查不到就删」）：
- 可信：≥2 个独立权威源核心字段一致（格式差异不算事实错误）；
- 存疑：仅弱源可检、增刊/内刊/早期未数字化、预印本与正式版不一致 → 降级使用，不删；
- 疑似伪造：全渠道无 + 刊名刊号不存在 + 年份早于创刊 → 交人处置，正文不引。

输出：每条 = DOI | 通道（Crossref / doi.org→chndoi.org / 题名反查） | 判定档 |
差异字段 | 原始响应路径或抓取时间 | 建议动作。
最后给三档汇总数与「存疑/疑似伪造」清单。

硬约束：不编造解析结果；不把「格式差异」当「事实错误」；
不把老文献、会议摘要、小众专著因查不到而直接删除；不替人拍板删除。
```

**使用提醒**：三档判定取代二值判断，是为了不误杀老文献、预印本、会议摘要与小众专著。中国 DOI 双通道来自 `04-两库.md` 第五节实测口径：Crossref 404 属正常，不要判死刑。本卡只做「真」查；「对」（标号与条数对账）与「该+漏」（语义 / 转述 / 引号）分别见 `D4c` 与 `04-两库.md` 第五节的第二、三步。
