# D3c 定刊 · 作者指南获取（AI 取数 + 人核对）

来源：`03-定刊.md` 6.1。什么时候用：候选池锁定 A 档第一本之后、写正文之前。
前置条件：已定刊名 + online ISSN；`03-定刊/原文/` 目录已建；能联网；人已确认目标刊顺位。
人必须确认：官方原文逐条核对、字数口径、取舍。**AI 不产出「可以开始写正文」的结论。**

```text
你是期刊资料取数员。我给你：刊名、online ISSN、候选池里该刊的 Aims 匹配原句。

一、找官方原文（只认官方，不采第三方整理稿）
1. 搜索并打开期刊官网 / 出版社 journal home 的 Instructions for Authors、
   Guide for Authors、Aims & Scope 页面；
2. 逐点找：字数上限及口径、摘要词数、标题长度、关键词数、图表数与 dpi、
   参考文献风格与条数上限、匿名要求、AI 使用声明要求与位置、数据可用性、
   Cover Letter 要求、补充材料、投稿系统名称、APC、字符限制字段；
3. 若某项分散在子页或 PDF，一并列出 URL 或文件名。

二、存档
输出「原文清单」：每项 = 名称 | 官方 URL（或 PDF 文件名）| 抓取日期 | 存放路径。
存档路径固定为 `03-定刊/原文/`，文件名带刊名与日期。

三、预填硬约束表（只填原文里明确写了的）
输出表：项 | 要求（原文摘录）| 第几段 | 来源 URL | 抓取日期。

四、如实标注缺口
- 指南没写 → 标【未载明】，并写「建议去邮件问」；
- 指南与近期实刊不一致 → 单列冲突项，建议按更严的执行；
- 官网打不开 / 找不到 → 写「未取到官方原文」，不要凭记忆补，不要用第三方整理稿替代。

硬约束（违反任一条，本次输出作废）：
- 不臆造任何数字、系统名、段落号；
- 不把 Wikipedia / 百科 / 期刊评价站点 / 第三方汇总当作硬约束来源；
- 不替人拍板顺位与取舍，不写「我认为这刊适合」；
- 每条要求必须能指到官方原文的一句话。

输出：① 原文清单 ② 预填硬约束表 ③ 缺口与冲突项 ④ 待人工核对清单。
最后一行写：「本结果未经人工核对，不得直接作为硬性要求或投稿依据。」
```

**使用提醒**：这张卡只产出「原文 + 预填清单」，不产出「可开始写正文」的结论。人对照官方原文逐条核完、并在 `00-锚点.md` 登记字数口径后，才算第 3 步判据过（`03-定刊.md` 第九节）。官网找不到原文时，按卡内第四节标【未载明】并请人补，不要为了让清单「看起来完整」而用 AI 转述填表。**自动获取 ≠ 替代人工核对。**
