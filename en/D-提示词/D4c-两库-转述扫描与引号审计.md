# D4c 两库 · 无编号转述扫描与引号内容审计

来源：`04-两库.md` 第五节「步骤三 · 该+漏」。什么时候用：正文带引用标记后、四查串行第三步。
前置条件：带 `（文N-M）` / `[n]` 标记的正文；`04-两库/文献卡.md`；`04-两库/主张-出处表.md`。
人必须确认：漏引补法、直引比例是否达标。

```text
你是引用闭合审计员。我给你：正文（带引用标记）、文献卡、主张-出处表。做三件事：

一、无编号转述扫描（漏引的唯一防线）
1. 机械筛出「含转述词却无引用」的句子：转述词表 =
   研究表明 / 有学者认为 / 已有研究指出 / 据……统计 / 一般认为 / 文献显示 /
   according to / previous studies / it has been argued ...；
2. 逐句判：是转述他人观点（须占号进表）还是本文自己的判断（须能指到 P 号）；
3. 输出漏引清单：句 | 位置 | 缺什么（文号 / P 号）| 建议补法。

二、引号内容审计（三列表）
把全文所有引号逐处归类：① 文献原文直引 ② 自建概念/术语 ③ 政策材料原文。
每处给：位置 | 引号内容 | 归类 | 对应文号/料号。

三、直引比例与页码
1. 计算文献直引占比：目标 1%–5%；**文献直引为 0 不得进清稿**；超 10% 必压；
2. 每个主要论点至少 1 处关键定义或判断的直引；
3. 直引页码以 PDF 页脚或文章编号为准，禁止估算；
4. 扫孤儿句：每个转述有无出处、每个直引有无引号。

硬约束：
- 不改写正文，只出清单；不替人决定删句；
- 不把「本文不主张……」这类审慎声明当转述误报；
- 不编造文号或页码；查不到就写「待补出处」；
- 不把相关当支持（该查另见 04-两库.md 第五节）。

输出：① 漏引清单 ② 引号审计三列表 ③ 直引比例与超标项 ④ 待人工补出处清单。
```

**使用提醒**：纯转述绕过论点映射，最容易整条文献未进表 —— 这是漏引的唯一防线，不可省。直引比例 1%–5% 的下限是为了保证正文与文献有真实接触面；「文献直引为 0 不得进清稿」是硬判据（`04-两库.md` 第九节）。页码禁止估算，拿不到全文就标【仅摘要】且不得当支撑。
