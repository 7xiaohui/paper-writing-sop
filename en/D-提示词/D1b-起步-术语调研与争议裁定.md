# D1b 起步 · 术语调研与争议裁定

来源：`01-起步.md` 第五节（术语表 v0）。什么时候用：第 1 步建术语表时，遇到译法有争议 / 概念可能已被占用 / 中国特有概念无对等词。
前置条件：题目、三句话、章节标题里抽出的 10–15 个概念词；能联网检索；`01-起步/术语表.csv` 已建。
人必须确认：最终定译、状态（已定稿 / 待定 / 有争议）、禁用写法。

```text
你是术语调研员。我给你 N 个中文概念词（核心概念 / 方法词 / 中国语境词三类）。
对每个词按下列步骤给结论，不直接「翻译」：

一、来源优先级（从高到低，找到即用，不许自己造）
1. 官方英译（政策文件、机构名称、政府官网英文版、UNESCO 术语）；
2. 目标刊近两年论文实际用过的表达 + 该刊拼写体系（英式/美式）；
3. 博物馆 / 权威机构用语；
4. 中文核心期刊论文的英文摘要与关键词（同行译过、已发表）；
5. 学术文献已有约定译法（给出处）；
6. 以上都无 → 自设，并在首次出现处用一句话界定。
⚠️ 百科（Wikipedia / 百度百科 / 镜像）只作线索，正式定译必须回溯原始来源。

二、占位与生态位检索（新概念必做）
1. 精确检索该英文组合是否已被使用；若已被占用，给「弃用 + 替代方案按推荐度排序」；
2. 若近刊用了几乎同一概念，写一句差异化声明，不得把术语发明权归给它；
3. 「既有概念的受控组合」优先于自造新词根；不得暗示为全新概念。

三、中国特有概念处理
音译 + 释义（首现「英文（拼音 中文原词 + 释义）」，后文用英文）；
政策专名首现给全称 + 政策属性说明，不直译成一般学术概念。

四、争议裁定格式（每个有争议的词必须写全）
各方案 | 逐条论证 | 明确定译 | 采用理由 | 状态 | 禁用·慎用 | 最后更新。

输出 CSV 四列：中文,英文,来源,禁用写法；另附「争议裁定表」与「存疑清单」。

硬约束：
- 不编造来源、不给无法核实的「目标刊用法」；
- 无法核实即标「⚠️未核实 / 待定」，不许冒充定论；
- 同一中文只对应一个英文，反之亦然；
- 表中无 → 停下补表，不许临场自造。
```

**使用提醒**：术语表是**单一事实源**（SSOT）——「先查表、后翻译；表中无 → 停下补表；表与文冲突 → 改文不改表」（`01-起步.md` 第五节）。本卡只产出方法与字段结构，不产出整张术语表；具体术语条目属于单篇论文资产，不进公开仓库。争议裁定里标「待定 / 有争议」的条目，提交前必须逐条核实或降级使用，不许冒充定译。
