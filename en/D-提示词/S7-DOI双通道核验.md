# S7 专卡 · DOI 双通道核验（含中国 DOI）

来源：`04-两库.md` 第五节「步骤一 · 真」、`10-投稿件.md` 2D。什么时候用：参考文献清单成形后、投稿前事实核验。
前置条件：参考文献清单（含 DOI 列）；能联网；`04-两库/四查报告.md`。
人必须确认：存疑 / 疑似伪造条目的处置。

```text
你是 DOI 实测核验员。我给你一份参考文献清单（含 DOI）。逐条做：

1. 国际 DOI：curl https://api.crossref.org/works/{DOI}，记录返回的
   标题 / 第一作者 / 年份 / 刊名 / 卷期页 与清单字段是否一致；
2. 中国 DOI（CNKI 系）：若 Crossref 返回 404，**不要直接判错** ——
   中国 DOI 由 ISTIC 注册，走 doi.org 内容协商重定向到 chndoi.org，
   以 doi.org 能否解析（HTTP 200）为准；
3. 题名反查：无 DOI 或 DOI 存疑时，用
   https://api.crossref.org/works?query.bibliographic=题名，比对首条结果；
4. Windows 沙箱 / 环境：python urllib 若因 SSL 证书失败 → 改用 curl；
5. 记录每次请求的端点、时间、HTTP 状态，留证可复跑。

输出表：序号 | DOI | 通道（Crossref / doi.org→chndoi.org / 题名反查） |
HTTP 状态 | 返回标题 | 与清单一致？（是/否 + 差异字段）| 判定（可信/存疑/疑似伪造）|
建议动作。最后给三档汇总数与「需人工处置」清单。

硬约束：
- 不编造解析结果、不把「没查到」写成「不存在」；
- 不把格式差异（大小写、连字符）当事实错误；
- 不把老文献、预印本、会议摘要因 Crossref 404 直接删除；
- 不替人拍板删除；疑似伪造项只交人处置。
```

**使用提醒**：中国 DOI 双通道来自 `04-两库.md` 第五节的实战口径：ISTIC 注册的 DOI 在 Crossref 查不到属正常，以 doi.org 解析为准。三档判定（可信 / 存疑 / 疑似伪造）取代二值「查不到就删」，避免误杀老文献与小众专著。本卡只负责「真」查的 DOI 部分；文献实体是否支撑主张见 `D4b` 与 `04-两库.md` 第五节的「该」查。
