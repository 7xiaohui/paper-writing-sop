# D11 返修 · 回应起草

来源：`11-投递与返修.md` 第六节。什么时候用：第 11 步，收到审稿意见后。
前置条件：审稿意见原文 + 已改的段落号 / 行号。
人必须确认：不同意的意见是否给足证据。


```text
我给你审稿意见原文和我已改的段落号。
任务：逐条起草回应。格式：
- 原文引用审稿意见；
- 我们的理解（一句）；
- 改在哪（line number / 段落号）；
- 不同意时给证据（数据 / 文献 / 方法限制），不辩护态度。
约束：礼貌、简短、不写"非常感谢您的宝贵意见"开头；
不同意的不要硬改，给理由。
输出 response letter 草稿。
```

**使用提醒**：拒稿先跑 `S4` 分诊再决定回第几步；不同意给证据不硬顶；改一处查连锁（编号 / 数字 / 结论 / 摘要 / 引言承诺）。
