# D3 定刊 · 题录初筛

来源：`03-定刊.md` 第四节。什么时候用：第 3 步，题录拉回后。
前置条件：一个 ISSN 与近两年题录（Crossref JSON 或导出表）；关键词。
人必须确认：书评 / 综述 / 社论的排除判定、最终「同题数」。


```text
我给你一个 ISSN 和近两年题录（Crossref JSON 或导出表）。
任务：按关键词〔……〕筛出与"〔选题〕"相关的题名；数"同题数"；
标出哪些是书评 / 综述 / 社论（不计入）。
约束：只数题名，不做质量判断；总数给出但同时给"人工数"。
输出：相关题名列表 + 计数 + 排除项列表。
```

**使用提醒**：`total-results` 只报规模，不当同题数；最终人工过前 20–30 条题名。拉数据用 `S1`，四源分级取数用 `S6`。
