# 对抗审稿法（自己先把刀递出去）

> **问题**：稿子写完了，谁来挑错？单作者没有同行预读；英文不是母语，英文稿里的逻辑漏洞自己读不出来。
> **答案**：把"通读一遍提提意见"换成**有靶子的对抗**——先立命题，再逼出最强反驳，最后按表处置。
> **一句话**：**无靶子不改稿；有靶子必落表；表上每条都要能指回原文。**
> **位置**：方法在本文件；两次调用分别在 `01` 的 **5-5（定稿前·硬门禁）** 与 **8-6（成稿后·落地复查）**。

---

## 一、先定分工：发现型审稿 vs 复查型审稿

**这一节是整份文件的前提。搞错分工，前面的功夫全部作废。**

| 类型 | 在哪做 | 干什么 | 产出 |
|---|---|---|---|
| **发现型审稿**（找问题） | **中文稿**（每次大改后） | 逻辑漏洞、论证缺口、RQ 不对齐、概念层级不清、命题站不住 | 命题-反例-回应表 + 修改台账 |
| **复查型审稿**（查落地） | **英文稿 + 中英对照** | 中文定下的修改英文有没有漏；词数、术语、拼写、长句 | 落地对照表 |

### 为什么"发现型"必须在中文稿（三条硬理由）

1. **你能把关的只有中文。** 英文稿里藏着逻辑漏洞，你和 AI 都读不出来——AI 只能保证"语法对"，**不保证"论证对"**。在看得懂的语言里找问题，才抓得准。
2. **成本差数倍。** 中文改一处 = 改一处；英文改一处 = 改一处 **+ 回写中文 + 重译该段 + 重跑检查**。
3. **中文是源、英文是派生**（`README` 铁律 1）。源头的问题必须在源头解决。

### 英文阶段发现"内容级问题"怎么办

| 情形 | 后果 |
|---|---|
| 发现型在**中文**做 | 发现大问题 → 中文改 → 英文一次译对 ✅ |
| 发现型拖到**英文**才做 | 英文发现大问题 → 源头是错的 → 中文要改 → 英文重译 → 全管线重跑 ❌ |

**规则**：英文稿阶段若发现内容级问题，**必须回中文稿改，再重跑受影响段落**。不允许"只在英文那侧打补丁"（打一次补丁，中英就永久不同步，见 `07` #49）。

## 二、命题反例检验（四个动作，串行，不许跳）

> 这是"发现型审稿"的主武器。**只攻击命题的成立性，不评价文笔。**
> 时间：1–2 天（命题 2–5 条，每条 30 分钟想 + 10 分钟落表）。

### 2-0 立靶之前：命题分档（甲/乙/丙）

命题不分档，后面全是空转。**每一条核心命题先归入下面三档之一**，档位决定你能用什么动词。

| 档 | 是什么 | 允许的写法 | 不许的写法 |
|---|---|---|---|
| **甲 · 已证事实** | 别人已发表、可核到出处的结论 | "X 已被证明…""据 A（2020），…" | 不加引用就当自己的发现 |
| **乙 · 本文主张** | 本文要论证的判断（有证据支撑，但属于你的解释） | "本文认为…""证据支持…""可以推断…" | "证明""证实""必然" |
| **丙 · 待检验假设** | 机制成立才应观察到的蕴含，本文材料不足 | "若…成立，应观察到…""有待检验" | 写成结论，或写进摘要断言句 |

**判据**：三条命题三条档位，没有一条空着。**摘要里的每一句断言，档位不得高于正文**（摘要写"证明"，正文只敢写"可以推断" = 档位倒挂，审稿人第一刀就砍这里，见 `07` #50）。

### 2-1 第一步 · 立靶（把命题抄成一句一条）

从 `01` 的 2-1 三问 / `03` 表 1 的"一句话判断" / 表 3 论证表的"相信什么"列，抽出 **2–5 条核心命题**。

```
P1 ________________________________（一句，不超过 40 字，可被反驳）
P2 ________________________________
P3 ________________________________
```

**四条硬要求**：

- 一句一条，**不许两条并一条**（并了就没法单独处置）；
- 必须是**可被反驳的判断**——"具有重要意义""值得关注"不是命题，是态度；
- 每条挂**正文位置**（第几节第几段），不挂位置的命题等于不存在；
- 每条挂**证据类型**：文献转述 / 材料数据 / 纯推理。

### 2-2 第二步 · 写最强反驳（五种找法，逐条试）

对每条命题，按下面五类各找一次。**找不到就写"未找到"，不许留空。**

| 找法 | 问句 | 例子（脱敏） |
|---|---|---|
| **① 反例** | 有没有一个案例/一篇文章，结论正好相反？ | 命题说"平台化削弱地方性"，找得到一个平台化反而强化地方性的案例 |
| **② 竞争解释** | 同一现象，有没有更简单的解释？ | 差异可能来自样本构成，不来自机制 |
| **③ 范围过宽** | 这个判断在哪些条件下不成立？ | 只在"高参与成本"的政策里成立 |
| **④ 因果倒置** | 是不是把结果当成了原因？ | 是"可见性带来流量"，还是"流量带来可见性" |
| **⑤ 相关性当因果** | 证据只说明同时出现，还是说明引起？ | 两条曲线同向，不等于一条推动另一条 |

**写反驳的三条硬约束**（照抄进提示词）：

- **不许编造反例数据**。引用反例必须给可核来源；给不出就写"逻辑上的可能反驳"，并标明"未找到实例"。
- **不许写空话**。"论证不够充分""建议加强理论深度"一律视为无效——**没有具体攻击点的意见，不许进表**。
- **不许因为"这是作者自己的研究"而降标准**。

### 2-3 第三步 · 文内自拆（最硬的反驳不用向外找）

> **别人打你，你还有机会辩；自己引的文献打你，没得辩。**

**做法**：把正文里**承担论证**的引文（不是点缀性的）逐条调出来，问三句：

1. 这篇文献被本文**转述成什么**？（抄正文那句）
2. 它**原文实际主张什么**？（看摘要/结论，别凭记忆）
3. **两者互斥吗？** 若互斥 → 你的命题被自己引的文献拆了。

**典型形态**（都发生过）：

| 形态 | 样子 | 为什么致命 |
|---|---|---|
| **不是 A 而是 B** | 命题写"不是 A，而是 B"；却引了一篇说"A 与 B 相互促进"的文献 | 你引的这句正好否掉你的排他性 |
| **定义漂移** | 前半篇按 A 的定义用，引文按 B 的定义引 | 同一篇文献支撑了两个互斥的用法 |
| **反向证据被当支持** | 文献结论有条件限定，本文引用时把限定删了 | 审稿人一查原文即穿 |
| **发明权误挂** | 术语是别人先提的，本文写成"本文提出" | 补引即可，不补就是硬伤（`07` #51） |

**判据**：承重引文（通常 5–10 条）逐条过完三句；出现互斥的，进 2-4 处置。

### 2-4 第四步 · 处置四选一（每条命题必须选一个）

| 处置 | 什么时候选 | 动作 | 下游影响 |
|---|---|---|---|
| **① 改命题** | 反驳成立，且无法用现有材料回应 | 回第 2 步重写命题 | **重跑**受影响的 5-1、5-2、6-x、文献四查、终检 2/7 |
| **② 限定范围** | 反驳只在某些条件下成立 | 在命题里加条件句，正文补"适用范围"段 | 局部的：改该节 + 摘要 + 结论各一句 |
| **③ 补论据** | 反驳成立，但手上确有材料能回应 | 补一条证据/一个案例/一句界定 | 补引文 → 重跑闭合与语义复核 |
| **④ 维持 + 写进局限** | 反驳存在但代价可接受，且本文范围本就不覆盖 | 在讨论/局限段明写"本文不处理 X" | 局限段 + 摘要不许多说 |

**只许四选一，不许"再想想"。** 表里出现空处置 = 这条命题没过门禁。

> ⚠️ **最常见的一种偷懒**：把"改命题"写成"补一句限定语"。这两者不一样——**限定范围是改命题的一种，不是辩解**。如果加了限定之后命题仍然被同一反驳击中，那就是没改。

### 2-5 产出：命题-反例-回应表（`03` 表 11）

| 命题号 | 命题原文 | 最强反驳 | 证据强度 | 正文是否已回应（位置） | 处置 | 理由 |
|---|---|---|---|---|---|---|
| P1 |  |  | 文献/材料/纯推理（弱） | 第 X 节 / 未回应 | 改/限定/补/维持 |  |

**判据（硬门禁，五条全过才算过）**：

- [ ] 每条命题都有**至少一条**最强反驳（"未找到"要写明找过哪五类）
- [ ] 每条命题都有**处置**，且处置为"改/限定/补"的，正文位置已标出
- [ ] 处置为"维持"的，局限段确有对应句子
- [ ] 处置为"改命题"的，**已回第 2 步返工，且重跑了受影响的检查**
- [ ] 表已落文件、编号、标状态（见第四节）

**没过门禁不许进第 6 步清稿、第 7 步英译、第 9 步投稿。** 这是全流程唯一一处"回头改结构"的正式入口，也是唯一一次"改一处、全篇作废"的高风险动作——所以必须前置到中文稿。

## 三、四种提问姿势（怎么让 AI 真的开火）

> 直接说"帮我审一下"，得到的一定是"本文结构清晰、论证充分，建议……"。**必须给约束、给范围、给交付格式。**

### 方法 A（主用）· 分节苛刻审稿人

```
你现在是【目标刊】的审稿人，立场是【最苛刻的某学派学者】。
只审【第 X 节】，逐段提出必须回应的质疑。
每条注明：① 依据的段落原文（逐字引 10 字以上）；② 严重程度（致命/重要/次要）；③ 改法。
没有原文定位的意见，视为无效，不要输出。
```

**三条关键约束**：

- **限定范围**：一次只审**一节**（先理论节，再方法/发现，最后讨论结论）。全文一起审，出来的都是"结构清晰"；
- **要原文定位**：**没有段落原文的质疑一律无效**——这是防"正确的废话"最有效的一招；
- **要分级**：致命 / 重要 / 次要，便于排优先级，也便于你只改致命的。

**为什么管用**：它把"发现问题"变成"**生成攻击**"——模型必须找到可攻击点才能交差，不会和稀泥。

### 方法 B · 定点爆破（P0 四处，最不可能出错、一旦出错最致命）

| P0 位置 | 查什么 | 判据 |
|---|---|---|
| **定义 vs 证据** | 把定义抄一遍，把数据能证明的抄一遍 | 定义 ⊆ 证据；定义比证据大就拆概念或降定义 |
| **比较单位** | A 与 B 的差异，能否由主体构成／计数口径／样本量解释 | 能解释 → 不许归因于 A 与 B |
| **"全量"型主张** | 凡"全量／所有／均／每"，回编码表核覆盖率 | 覆盖率 = 100%，或已改口径 |
| **标题承诺** | 标题每个名词，摘要与正文有没有落点 | 0 个悬空承诺 |

> 这四处不需要聪明，只需要**机械**。跑不出结论说明你没抄原文，不是说明没问题。

### 方法 C · 反问法（逼出结构性硬伤）

```
假设这篇稿投给【目标刊】后被 desk reject，
最可能的三个理由是什么？给具体段落证据 + 补救方案。
```

**价值**：它逼出的是"概念贡献不清晰 / 与 Aims 不匹配 / 类型不符"这类**结构性硬伤**，比逐字挑错值钱十倍。桌面拒稿大多死在这里，不死在句子（`06` §一）。

### 方法 D · 多立场三角色（裁定，不采纳）

至少设 **3 个不同立场**：

| 角色 | 盯什么 | 常见意见 |
|---|---|---|
| **理论** | 概念是否成立、与先行研究差异在哪 | "这个概念与 A 的 X 有何不同？" |
| **方法** | 样本、编码、归因、可复现 | "样本量支撑不了这个推断" |
| **目标刊读者** | 是不是本刊的题、贡献句是否清楚 | "读不出你相对于本刊近作的新意" |

**注意**：三个立场的意见**会互相冲突**（理论派嫌太实证，方法派嫌太思辨）。**这正是价值所在——你要做的是裁定，不是全部采纳。**

> 三角色的完整提示词见 `提示词/11-三角色审稿（多立场裁定）.md`。

## 四、意见分级与采纳纪律（这一节决定对抗有没有用）

### 4-1 三级分类

| 级 | 判据 | 处理 |
|---|---|---|
| **致命** | 命题被推翻、定义大于证据、比较不可比、类型不符 | 必改；改不动就降档（改命题/换刊） |
| **重要** | 论证有缺口、证据链少一环、概念与先行研究未区分 | 改，或在正文写明为何不处理 |
| **次要** | 表述、顺序、例子多寡 | 批量处理，不许逐条纠缠 |

### 4-2 三条不采纳的合法理由（只认这三条）

1. **审稿人读错了**（指出原文，并**把原文改清楚**——两边都做）；
2. **超出本文范围**（明写"本文不处理 X"，并给替代动作：进局限/进未来研究）；
3. **与其他意见冲突，已作另一种裁定**（写明裁定理由）。

**不合法**：懒得改、改了会超字数、觉得对方不懂。这三条一旦出现在记录里，下次就会变成"全部不采纳"。

### 4-3 记录必须落文件（否则等于没审）

**审稿记录表**（放工作区固定位置，如 `审稿记录/`），一人一行：

| 批次 | 日期 | 对象（文件名+版本） | 方法（A/B/C/D） | 意见数 | 致命/重要/次要 | 已改 | 未改 | 状态 |
|---|---|---|---|---|---|---|---|---|
| 01 |  |  |  |  |  |  |  | 进行中/关闭 |

**为什么要这张表**：真实发生过"审过没审过说不清"——三批审稿做完，回头找不着哪条改了哪条没改，最后只能重审一遍。**状态栏写"关闭"的批次，才能进下一步。**

## 五、英文阶段只做三件事（越界禁令）

```
① 落地复查：中文定下的每条修改，英文有没有漏（逐条对照修改台账）
② 英文专有维度：词数（口径）/ 术语正字 / 英式美式拼写 / 长句可读性
③ 英文通畅：只找语病，不动术语、数字、事实
```

🔴 **越界禁止**：英文阶段**不得**提出"新增论据""调整论证结构""改结论"这类内容级建议。提了会怎样：

| 越界后果 | 代价 |
|---|---|
| 英文侧打补丁 | 中英永久不同步，下轮改稿以哪边为准说不清 |
| 回中文改 | 中文改 → 英文重译 → 五查重跑 → 终检重跑，一轮 3–5 天 |
| 不改 | 那就不该提——提了不改，等于给自己埋一个"知道有问题但没处理"的雷 |

## 六、批次与时间（别指望一次审完）

| 批次 | 对象 | 方法 | 产出 | 时机 |
|---|---|---|---|---|
| 第 1 批 | 引言 + 理论/框架节 | A（分节）+ B（定义-证据） | 命题-反例表（初版） | 第 5 步末（**5-5 门禁**） |
| 第 2 批 | 方法 + 发现节 | A + B（比较单位、全量主张） | 表更新 + 修改台账 | 第 6 步中段 |
| 第 3 批 | 讨论 + 结论 + 摘要 | C（反问）+ D（三角色） | 表定稿 + 局限段 | 第 6 步末 |
| 第 4 批 | 英文稿 | 只做落地复查 + 英文维度 | 落地对照表 | 第 8 步（**8-6**） |

**时间**：每批 0.5–1 天。**总计 2–3 天**，换来的是"不会在第 9 步被审稿人第一次指出结构问题"。

**止损**：同一批审完，致命意见 > 5 条 → 不是审稿问题，是选题或框架问题，回第 2 步；某一节连续两批都是致命意见 → 这节该删（`05` §七"删掉本节会断吗"）。

## 七、六种典型失败

| 失败 | 症状 | 根因 | 修法 |
|---|---|---|---|
| **通读式审稿** | "整体不错，建议加强理论深度" | 没给靶子、没限范围 | 改方法 A，一节一审，要原文定位 |
| **全部采纳** | 改完论证走形，结论变了 | 把"意见"当"判决" | 三级分类；只改致命的；冲突意见要裁定 |
| **全部不采纳** | 记录里"未改"占八成 | 没有合法理由约束 | 只认三条合法理由；其余必改 |
| **审在英文稿** | 英文发现结构问题，全稿重译 | 分工错 | 发现型回中文；英文只做复查 |
| **审完不留痕** | 说不清哪条改了 | 没落表 | 审稿记录表 + 修改台账，状态写"关闭" |
| **命题写成态度** | "具有重要意义""值得关注" | 2-1 立靶没做 | 回 2-0 分档，重写为可被反驳的判断 |

## 八、一页速记

```
分工：发现型 → 中文稿 ｜ 复查型 → 英文稿
立靶：2–5 条命题，一条一句，挂位置，挂证据类型
开火：反例 / 竞争解释 / 范围过宽 / 因果倒置 / 相关性当因果（五类各找一次）
自拆：承重引文 5–10 条，抄转述 → 看原文 → 判互斥
```
