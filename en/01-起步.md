# 第 1 步 · 起步：工作区、锚点、术语表、类型

> **一句话**：动手写之前，先把"东西放哪、什么算数、这是什么类型的论文"定下来。
> **输入**：一个方向、手上材料清单
> **产出**：工作区树、`00-锚点.md`、`01-起步/类型判定.md`、`01-起步/术语表.csv`
> **耗时**：半天
> **判据**：`check_workspace.py` 显示第 1 步就位；锚点 5 条齐；术语 ≥10 条且每条有来源；类型唯一

---

## 一、为什么先建工作区（三句话）

1. **产物要有固定归宿**。写到最后，手上有十几个版本、几十篇 PDF，没有固定名字就分不清哪份是当前版。
2. **进度要能看见**。"我做到哪了"不该靠记忆，靠"这个文件在不在"。
3. **换会话不丢上下文**。AI 每次新开都是白纸，锚点是它唯一能读到的"我们之前定了什么"。

## 三、三条命名规则（只有三条）

1. **目录号 = 步骤号**。找不到东西时，问"它属于第几步"，而不是"我上次放哪了"。
2. **产物名固定**。`02-选题/选题卡.md` 永远叫这个名字；不出现"新建文档(3)""最终版2"。
3. **版本后缀只加在稿子上**。`中文-v1`、`中文-v2`、`中文-冻结-v1`；表格不写版本，改一次覆盖一次，历史进 `_存档/`。

文件名的其余部分建议带内容：`文7-Smith-2019-visibility.pdf`、`料3-2-统计年鉴-2025-表4.pdf`。**编号在前，内容在后**，排序即检索。

## 四、锚点五条（`00-锚点.md`）

锚点不是日记，是一页"这个项目当前的宪法"。只写五条，多一条都不要：

| # | 条目 | 写什么 | 为什么 |
|---|---|---|---|
| 1 | **中英同步** | 改中文必改英文对应段；改英文只许语言层 | 否则一稿两义，返修时不知以哪边为准 |
| 2 | **单一事实源** | 数字从材料台账取，术语从术语表取，决策从本文件取 | 同一指标三个值，是返修最常见的硬伤 |
| 3 | **只移不删** | 旧版本进 `_存档/`，不 rm | 审稿人问"上一版怎么写的"，要拿得出 |
| 4 | **一稿多投红线** | 前刊未终结，绝不投他刊 | 学术不端，没有第二次机会 |
| 5 | **无靶子不改稿** | 每次修改必须指向一条具体意见或一个具体错误 | "帮我优化一下"= 100% 白改 |

**写法**：每条一行结论 + 一行"本次项目的具体口径"。例：

```
3. 只移不删。→ 本项目：旧稿进 _存档/，命名 2026-11-10_中文-v3.md。
2. 单一事实源。→ 本项目：样本数只认 材料台账 M01 = 48；术语只认 术语表 v1。
```

**判据**：五条都在；每条有"本次口径"，不是空话。

## 五、术语表 v0（`01-起步/术语表.csv`）

翻译出问题，九成不是英语差，是**同一个概念写了三种英文**。术语表要在写正文之前建，不是翻译之前。

**四列，只有四列**：

```csv
中文,英文,来源,禁用写法
解释密度,explanation density,目标刊 2024 年论文关键词,explanation quantity
政策执行落差,implementation gap,某 SSCI 2021 摘要,policy gap
```

**建表三步**：

1. **抽词**：从你的题目、三句话、章节标题里抽 10–15 个概念词。分三类：核心概念（3–5）、方法词（2–3）、中国语境词（3–4）。
2. **找英文，不自己译**。来源优先级：
   - 目标刊近两年论文**实际用过**的表达（最优先）；
   - 中文核心期刊论文的**英文摘要与关键词**（同行译过、已发表）；
   - 官方英译（政策文件、机构名称）；
   - 实在找不到 → 自设，并在**首次出现处**用一句话界定。
3. **写禁用写法**。你曾经用过、但不打算再用的译法，全部登记。这是防"三种译法"的唯一办法。

**判据**：≥10 条；每条"来源"列不是空的；同一中文只有一个英文（反过来说，同一英文也只对应一个中文）。

**维护**：正文出现新术语 → **先入表，再动正文**。表里没有 → 停下来补，不许"这次先这么写"。

## 六、类型判定（`01-起步/类型判定.md`）

**只判一次，全篇按这个类型写。** 判错，后面每一段的段型都会错。

| 类型 | 结构 | 必写的一句话 | 最容易死在哪 |
|---|---|---|---|
| **概念型** | 定义 → 机制（2–4 个）→ 可观察蕴含 → 案例示意 → 边界 | "若机制成立，应观察到……" | 被判"空"：只有概念，没有可观察后果 |
| **比较型** | 分析单位 → 维度（3–5）→ 同异 → 解释变量 → 回理论 | "比较设计是最相似还是最不同" | 被判"案例不可比"：差异可由规模、口径解释 |
| **对策型** | 诊断 → 工具匹配 → 可行性与副作用 → 指标 | 每条建议挂"机制 / 执行者 / 失败条件" | 被判"政策愿望清单" |
| **小调查型** | 抽样 → 描述统计 → 与质性互证 → 不外推 | "n<30，定位为 exploratory，不做检验" | 被判"样本不足还推断" |

**判定问句**：删掉所有形容词之后，这篇论文**靠什么让人相信**？
- 靠一个可观察的后果 → 概念型；
- 靠两个对象的对照 → 比较型；
- 靠一条可执行的路径 → 对策型；
- 靠一批自己采的数据 → 小调查型。

**判据**：只能选一个。想写"既是概念又是实证"的，回第 2 步重压。

同时在这里写一句**源语言**：中文源 / 直接英文。它决定第 7–8 步走哪条路（见 `00-总览` 第五节）。

## 七、合规三档（同一张纸，动笔前定）

| 问题 | 选项 | 影响 |
|---|---|---|
| **AI 用到哪一档** | 只润色 / 翻译＋润色 / 生成初稿 | 决定第 9 步声明怎么写，也决定你能否说"初稿非 AI 生成" |
| **是否建立在已发表成果上** | 是 / 否 | 是 → 只许"引用＋概括"，不许"整段翻译"；新内容建议 ≥30% |
| **是否涉及人类被试** | 公开文本 / 问卷访谈 | 问卷访谈 → 需知情同意、伦理声明、数据脱敏 |

**为什么现在定**：这三条写完稿再改，成本是全篇——声明口径要改、方法段要改、附录要改，还可能和已投稿的版本冲突。
