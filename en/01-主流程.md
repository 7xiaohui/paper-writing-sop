# 主流程：九步

> 每一步的格式固定：**输入 → 动作卡 → 产出 → 判据**。判据不过，不进入下一步。
> 动作卡只写"做什么、做成什么样"，理由不写（理由在失败时查 `07-失败模式库.md`）。

---

# 第 1 步 · 判断能不能写

> **一句话**：先证明"这个题现在能写"，再动手。三证不齐，换题比硬写便宜十倍。

**输入**：一个方向、手上材料清单
**产出**：学科定位卡 + 文献可及性判断 + 合规档位
**耗时**：半天

### 1-1 写三句话

```
① 我看到的反常：______（一句话，描述现象）
② 我要问的问题：______（一句话，问句）
③ 我现在的判断：______（一句话，可能是什么机制/关系）
```

**判据**：三句里没有"很重要""意义重大""值得研究"。有就重写。

### 1-2 学科定位（三证）

对每个候选刊填一行，三证齐全才算过：

| 证 | 看什么 | 不过就排除 |
|---|---|---|
| 一 | 该刊 Aims & Scope 里能摘出与本稿相关的 1–2 句 | 摘不出 |
| 二 | 该刊近 2 年有 3 篇同主题文章 | 一篇都没有 |
| 三 | 该刊收本稿这个类型（概念/比较/对策/小调查） | 不收 |

**反查优先**：拿 3–5 篇"最像本稿"的文章，看它们发在哪、在哪个栏目。**栏目比 Aims 更可靠**，因为栏目是编辑用脚投票的结果。

### 1-3 文献可及性

**判据**：现在就能拿到 **≥ 5 篇**同主题英文全文。
拿不到 → 走 `04` 的三条获取路径；仍然拿不到 → 这个题现在不能写（不是"英文差"，是"没米"）。

### 1-4 合规预判（三条，动笔前定）

| 问题 | 选项 | 影响 |
|---|---|---|
| AI 用到哪一档 | 只润色 / 翻译+润色 / 生成初稿 | 决定声明怎么写（见 8-1、9-2） |
| 是否建立在已发表成果上 | 是 / 否 | 是 → 只许"引用"，不许"翻译搬运"（见 8-2） |
| 是否涉及人类被试 | 公开内容 / 问卷访谈 | 问卷访谈 → 需知情同意与伦理声明 |

> **为什么要现在定**：这三条一旦写完稿再改，成本是全篇。

---

# 第 2 步 · 选题与定位

> **一句话**：把题目压成"一个判断 + 刚好够的证据"。

**输入**：三句话、材料清单
**产出**：选题卡（`03-模板.md` 表 1）
**耗时**：1 天

### 2-1 最小可发表单元（三问）

| 问 | 答不出说明什么 |
|---|---|
| 改变谁的什么判断？ | 你不知道读者是谁，综述会写成自说自话 |
| 我有什么是别人没有的？ | 你只有"我也这么认为"，没有证据优势 |
| 发表后别人引用它会引哪一句？ | 你没有贡献句，摘要会写成"本文研究了…" |

### 2-2 判类型（只判一次，全篇按这个类型写）

| 类型 | 结构 | 必写声明 | 最容易死在哪 |
|---|---|---|---|
| **概念型** | 定义 → 机制（2–4 个）→ 可观察蕴含 → 案例示意 → 边界 | "若机制成立，应观察到…" | 被判"空" |
| **比较型** | 单位 → 维度（3–5）→ 同异 → 解释变量 → 回理论 | 比较设计类型（最相似/最不同） | 被判"案例不可比" |
| **对策型** | 诊断 → 工具匹配 → 可行性与副作用 → 指标 | 每条建议挂"机制/执行者/失败条件" | 被判"政策愿望清单" |
| **小调查型** | 抽样 → 描述统计 → 与质性互证 → 不外推 | n<30 不做检验，定位为 exploratory | 被判"样本不足还推断" |

**判据**：类型唯一。想写"既是概念又是实证"的，回到 2-1 重压。

### 2-3 题目试写三版

- 版本 A：现象式（"X 如何被 Y 改变"）
- 版本 B：机制式（"从 A 到 B：X 的机制研究"）
- 版本 C：判断式（"X 不是 Y，而是 Z"）

**判据**：三版都能一句话读通；选一个，另外两个删掉（留着必漂移）。

# 第 3 步 · 找刊定刊

> **一句话**：先证明"这本刊会收这个题"，再查它的硬性要求。

**输入**：选题卡
**产出**：候选池 + 硬约束清单 + 近刊对标 + 字数契约
**耗时**：3–5 天

### 3-1 筛选大前提（七项，先定再找）

收录类型（SSCI/SCIE/AHCI/ESCI）· 是否在预警名单 · 分区口径（单位认哪套）· 经费（APC 上限）· 论文类型 · 语言 · 见刊周期。

**判据**：七项写成一句话，例如"只认 SSCI/AHCI 正刊、零 APC、两年内见刊"。

### 3-2 两条路找候选

- **路 A 专业对口**：领域关键词 → 直接定位。
- **路 B 专业不对口但能发**：拿 3–5 篇"最像的文章" → 看它们发在哪。

> 路 B 常有更好的分区和更快的周期，却因为"不在第一反应里"被漏掉。**两条都要走。**

### 3-3 三证锁定

同 1-2。锁定 **1 主选 + 1 备选**。顺位表贴在显眼处（"这刊是冲还是保"是最容易忘的事）。

### 3-4 指南原文 → 硬约束清单

**去官网下载《作者指南》原文，存进工作区。不许听转述、不许看第三方整理。**

逐项抄进 `03-模板.md` 表 5，特别注意六项：

1. **字数口径**：含不含摘要/尾注/参考文献/表格/图注/附录（逐项勾）
2. **摘要**：上限、结构（是否要求结构化）
3. **关键词**：个数
4. **必含章节**：致谢/利益/数据可用性/AI 声明/作者简介
5. **AI 政策**：详述型 / 声明型 / 禁止型（决定 8-1 怎么写）
6. **投稿系统**：名字 + **系统里有没有第二个摘要框**（见 9-2）

**判据**：清单每一行都能指出"指南第几段说的"。指不出 = 没抄完。

### 3-5 近刊对标（定刊当天做）

下载 3–5 篇近 2 年同主题文章，记四栏：

| 栏 | 记什么 | 直接影响 |
|---|---|---|
| 摘要 | 各篇词数、均值、最大值、句式 | 我方摘要写多长（**不超过样本最大值**） |
| 结构 | 有无独立理论章、章节编号方式、结论段写法 | 我方骨架 |
| 语域 | 人称（we/I/the paper）、时态、高频概念词 | 英译风格 |
| 引用 | 参考文献条数均值、是否爱引本刊 | 文献规模 |

**副产品**：会顺带发现"必引文献"。⚠️ 若近刊用了与你相近的术语，**不得把术语发明权归给它**，先核先行归属。

### 3-6 字数契约（动笔前签字）

```
目标刊词数上限：____（口径：含/不含参考文献）
中文写作目标：____ 字（学术文本按 1 英文词 ≈ 2 汉字，留 10% 余量）
摘要目标：____ 词（按近刊均值，不超最大值）
关键词：____ 个
```

> **经验**：宁可中文写少、英文后期稍扩；**不要中文写超、英文被迫大砍**（大砍必伤结构）。
> **字数问题的正解是换刊，不是删框架**。合法压缩空间通常只有 5–10%。

# 第 4 步 · 读文献

> **一句话**：不追求"读得多"，追求"每篇都有位置"。
> **完整方法见 `04-文献选读法.md`。这里只列动作与判据。**

**输入**：三句话、词表种子（中文论文的英文摘要）
**产出**：文献卡 15–25 张 + 六组表 + 四查报告
**耗时**：5–8 天

| 卡 | 动作 | 判据 |
|---|---|---|
| **4-1 造词表** | 抄中文论文的英文摘要、目标刊关键词 → 中文/英文候选/来源 三列 | ≥10 条，每条有来源；同一概念只留一个英文词 |
| **4-2 滚雪球** | 种子 3–5 篇 → 后向（它们的参考文献）→ 前向（引用它们的近 2 年文章） | 候选 25–40 条（题录级即可） |
| **4-3 三十秒判生死** | 看五信号：刊物 / 题名命中 / 年份 / 类型词 / 参考文献里有没有你认识的 3 篇 | 5 过 4 进；过 3 存疑；≤2 弃 |
| **4-4 六信号填卡** | 题名概念词 / 摘要首句 / 摘要末句 / 一级小标题 / 图表标题 / 结论首段+前 5 条参考文献 | 每篇 5 分钟，填八列，**含"拟引句"** |
| **4-5 分诊** | 三标签：相关度（高/中/低）、用途（定义/机制/情境/方法/反例）、证据强度（全文/摘要/题录） | 每篇三标签齐全；无标签的删 |
| **4-6 六组归位** | 定义 / 机制 / 情境 / 方法 / 政策 / 边界反例，每组 2–5 篇，**每组写三句**（他们说/分歧/我站哪） | 每组 ≥2 篇且三句写得出 |
| **4-7 精读 5–8 篇** | 只读：引言末段、理论节首段、结论首段、图表 | 每篇产出 150 字：问题/答案/没解决/我怎么接 |
| **4-8 文献四查** | 真不真 / 对不对 / 引没引 / 该不该（见 `02`） | 四查 0 错 |

**止损三条**：读不懂 → 降级为摘要级；找不到全文 → 不撑核心命题；与三句话无关 → 删（哪怕权威）。

# 第 5 步 · 定结构

> **一句话**：先定"每节要让读者相信什么"，再定"每段第一句说什么"，最后才写正文。

**输入**：六组表、类型判定、字数契约
**产出**：论证表 + 标题句串 + 字数分配
**耗时**：2 天

### 5-1 论证表（一页，不是提纲）

`03-模板.md` 表 3。每节一行：

| 节 | 这一节要让读者相信什么（一句话） | 依据（哪几条证据/哪几篇/哪个表） | 读者会怎么反驳 | 我怎么回应 |
|---|---|---|---|---|

**判据**：
- 每行"相信什么"都是一个**可被反驳的主张**（不可反驳 = 废话）；
- "依据"栏必须指向具体文献卡编号或数据表；
- "反驳"栏空着的行，说明你没想清楚，回去想。

### 5-2 标题句串

把每一段的第一句写出来，按顺序连成一串（20–40 句）。

**判据**：**只读这串句子，能不能复述完整论证？** 能 → 结构成立；不能 → 改结构，此时改一句的成本是写正文后的十分之一。

> 这是全流程性价比最高的一个动作。**句串不通，正文一定不通。**

### 5-3 字数分配

按 `03-模板.md` 表 4 填到"段"一级：每段配 120–180 词。

**判据**：合计 = 中文写作目标 ±5%；单节不超过总额 30%。

### 5-4 六缝预检（结构层，先查四缝）

| 缝 | 检测问句 |
|---|---|
| 理论并置缝 | 这两套理论凭什么放在一起？（一个定问题、一个定机制，或造一个接驳概念） |
| 概念-落点缝 | 结论里的关键词，引言定义过吗？ |
| 承诺-兑现缝 | 引言每个缺口，由哪个发现回答？ |
| 概念空转缝 | 这个核心词在操作上指哪几样可观察的东西？ |

**判据**：四问都有答案；答不上的先改结构，别写正文。

# 第 6 步 · 写初稿

> **一句话**：**先句子、后段落、再节**。禁止"生成一节"。
> **完整方法见 `05-初稿生成法.md`。**

**输入**：标题句串、论证表、字数分配
**产出**：中文定稿
**耗时**：10–15 天

| 卡 | 动作 | 判据 |
|---|---|---|
| **6-1 逐段扩写** | 一段一段长：主张（已定）+ 证据（指定来源）+ 解释 + 回扣/过渡。AI 三条禁令：不新增论点、不新增证据、不提高主张强度 | 每段 4–6 句，120–180 词 |
| **6-2 段落四问** | 主张能被反驳吗 / 证据直接支持主张吗 / 有没有"正确的废话" / 末句指向下一段吗 | 四问都过 |
| **6-3 节三问** | 首段交代"本节做什么"吗 / 末段交代"所以呢"吗 / 删掉本节论证会断吗 | 三问都过（"不会断"= 可删） |
| **6-4 连接词通读** | 只查"因为/因此/然而/相反/所以"，逐处问"真的成立吗" | 无跳步 |
| **6-5 冷却复读** | 放 24 小时，只读标题句串 + 每节首末段 | 还能复述论证 |

**中文阶段只改四类硬问题**：事实错、口径不一致、概念不准、逻辑不闭合。
**不要改**：句子优美、用词高级、衔接顺滑——这些在英译阶段会整段重写，现在花的功夫 100% 作废。

---

# 第 7 步 · 译英文

> **一句话**：中文冻结后才译；只改英文，不回头改中文（除非期刊变更）。

**输入**：中文定稿
**产出**：英文稿 + 五查报告
**耗时**：5–8 天

| 卡 | 动作 | 判据 |
|---|---|---|
| **7-1 冻结快照** | 复制一份 `中文-冻结.md`，**永不回写** | 有独立文件，且后续只读 |
| **7-2 分块翻译** | 顺序固定：摘要 → 各节 → 声明 → 参考文献 → 附录。**不并行**（并行必术语漂移） | 每块译完立即自检术语 |
| **7-3 术语对齐** | 跑术语脚本；英式/美式拼写全篇统一（他人标题原文例外） | 禁用词 0；异写 0 |
| **7-4 回译抽检** | 抽 10 段英→中回译，与原意比对 | 语义漂移 0 |
| **7-5 对照稿确认** | 中英逐段并排；**作者只读中文侧**判断内容，扫英文侧判断通顺 | 作者签字 |
| **7-6 抽英文单行稿** | 机械抽取英文段，**不重写** | 反向清点：标题数/表数/图数/关键句都在 |
| **7-7 译文五查** | 术语 / 回译 / 数字 / 格式 / 通畅（见 `02`） | 五查全过 |

**英文三条红线**：不自创译法；不增译、不减译；中文模糊处标记出来交作者，不许"顺手写通顺"。

> **诚实定位**：这套方法能保证"术语一致、语法正确、语域规范"，**不保证母语级自然**。要再进一步，只有付费母语润色。

# 第 8 步 · 做成投稿件

> **一句话**：把 md 变成 4 份能上传的 docx，并且**不留任何工作痕迹**。

**输入**：英文定稿 + 图件
**产出**：匿名主稿 / 标题页 / Cover Letter / 图注表 + 300dpi 图 + 终检报告
**耗时**：2 天

### 8-1 去工作痕迹（交稿前两查）

见 `02-检查清单.md`。六类要清：待定/中间态、内部工作语、投稿策略、版本尾注、回迁语、审稿痕迹。
五类要留：审慎声明、方法说明、附录导读、数据可用性、工作稿专属记录（**只留在工作稿**）。

**判据**：六类 = 0；五类未被误删。

### 8-2 匿名化（**自引怎么处理**）

双盲刊要求匿名稿无作者信息，但自引又不能凭空消失。三步：

1. **改第三人称**：不写 "our previous work"，写 "Author (2024) argued…"。
2. **文献表处理**：按该刊要求，或保留匿名化条目（"Author. 2024. …"），或整条移出并在 Cover Letter 说明。
3. **Cover Letter 交代一句**：说明"为满足匿名评审要求，作者自引已改为第三人称，相应条目见 XX"。

**判据**：正文 0 处姓名/单位/致谢/基金/邮箱/ORCID；**且**附录/参考文献/图表未被误删（对比匿名前后词数差，差值应等于被删身份信息的词数）。

> ⚠️ **注意区分两件事**：
> - **匿名自引**（上面这套，是技术处理）；
> - **重复发表**（把已发表的中文内容翻译成英文再发，是学术不端）。
> 后者只有一条规则：**已发表内容只许"引用+概括"，不许"整段翻译"**；新文必须有新增数据/新增论证/新增对话（经验值：新内容 ≥30%）。

### 8-3 生成四份 docx

匿名主稿 / 标题页与声明 / Cover Letter / 图注与表注。图片一律 300dpi 定尺（宽按版心，例 1713px@300dpi ≈ 14.5cm）。

### 8-4 文件属性清理

清：生成器名、生成器日期、缩略图、修订痕迹、批注、人员信息、图片 EXIF。
**删缩略图必须同时删 `_rels/.rels` 里的对应关系**，否则文件打不开——清完必须打开验证。

### 8-5 成稿十二项终检

见 `02-检查清单.md` 第四张。**逐项跑，改过就重跑。**

# 第 9 步 · 投稿与返修

> **一句话**：投出去只是开始；真正决定命运的是返修和转投。

**输入**：材料包
**产出**：投稿号 / 返修稿 / 转投方案
**耗时**：1 天 + 事件驱动

### 9-1 投稿前四查

内容层 / 文件层 / 作者信息 / 事实核验（见 `02`）。

### 9-2 系统填写（**注意隐藏字段**）

| 字段 | 注意 |
|---|---|
| 标题 / 摘要 | 系统可能另有**第二个摘要框**（"简要摘要"，字数比正文摘要更少）。现场压缩即可，**不必回改正文摘要**——那是一次性工作 |
| 关键词 | 个数按指南；系统可能限制分隔符 |
| 作者信息 | 姓名用字、**机构官方英文名**（不是百科译名）、ORCID、基金编号逐字核 |
| 推荐审稿人 | 同领域、无利益冲突；可填 3–5 位 |
| AI 声明 | 按 3-4 查到的刊型（详述/声明/禁止）写 |
| Cover Letter | 四段：投什么 + 文章做了什么（3 句）+ 为何适合本刊（引 Aims 原句）+ 常规声明 |

### 9-3 状态跟踪

每个状态记一行：日期 / 状态 / 依据（邮件原句）/ 下一步。

### 9-4 返修五步

见 `06-返修与转投.md`：冷静期 → 编号分级 → 逐条回应表 → 只改必要处 → 二次体检。

### 9-5 拒稿分诊

| 类型 | 判据 | 动作 |
|---|---|---|
| **桌面拒稿 · 不符主题**（**最常见**） | 无外审意见，或只有一句"not a good fit" | **不修改内容，换刊**。改内容没用，问题在刊物归属 |
| 桌面拒稿 · 类型/完整性 | 明确说"不收这种文章"或格式问题 | 换刊，或补齐格式 |
| 外审后拒 | 有具体意见 | 先改，再投（意见是免费资源） |
| Reject & Resubmit | 实质重大返修 | 按返修流程做，回原刊 |

**转投三条硬规矩**：前刊未终结绝不投他刊；**不用期刊的"自动转投"**（会传旧版）；转投前做差异清单（字数口径/摘要/关键词/章节/引用体例/学科话术）。
