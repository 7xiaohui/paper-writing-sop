# 主流程：九步

> 每一步的格式固定：**输入 → 动作卡 → 产出 → 判据**。判据不过，不进入下一步。
> 动作卡只写"做什么、做成什么样"，理由不写（理由在失败时查 `07-失败模式库.md`）。

---

# 第 1 步 · 判断能不能写

> **一句话**：先证明"这个题现在能写"，再动手。三证不齐，换题比硬写便宜十倍。

**输入**：一个方向、手上材料清单
**产出**：学科定位卡 + 文献可及性判断 + 合规档位
**耗时**：半天

### 1-1 写三句话

```
① 我看到的反常：______（一句话，描述现象）
② 我要问的问题：______（一句话，问句）
③ 我现在的判断：______（一句话，可能是什么机制/关系）
```

**判据**：三句里没有"很重要""意义重大""值得研究"。有就重写。

### 1-2 学科定位（三证）

对每个候选刊填一行，三证齐全才算过：

| 证 | 看什么 | 不过就排除 |
|---|---|---|
| 一 | 该刊 Aims & Scope 里能摘出与本稿相关的 1–2 句 | 摘不出 |
| 二 | 该刊近 2 年有 3 篇同主题文章 | 一篇都没有 |
| 三 | 该刊收本稿这个类型（概念/比较/对策/小调查） | 不收 |

**反查优先**：拿 3–5 篇"最像本稿"的文章，看它们发在哪、在哪个栏目。**栏目比 Aims 更可靠**，因为栏目是编辑用脚投票的结果。

### 1-3 文献可及性

**判据**：现在就能拿到 **≥ 5 篇**同主题英文全文。
拿不到 → 走 `04` 的三条获取路径；仍然拿不到 → 这个题现在不能写（不是"英文差"，是"没米"）。

### 1-4 合规预判（三条，动笔前定）

| 问题 | 选项 | 影响 |
|---|---|---|
| AI 用到哪一档 | 只润色 / 翻译+润色 / 生成初稿 | 决定声明怎么写（见 8-1、9-2） |
| 是否建立在已发表成果上 | 是 / 否 | 是 → 只许"引用"，不许"翻译搬运"（见 8-2） |
| 是否涉及人类被试 | 公开内容 / 问卷访谈 | 问卷访谈 → 需知情同意与伦理声明 |

> **为什么要现在定**：这三条一旦写完稿再改，成本是全篇。

# 第 2 步 · 选题与定位

> **一句话**：把题目压成"一个判断 + 刚好够的证据"。

**输入**：三句话、材料清单
**产出**：选题卡（`03-模板.md` 表 1）
**耗时**：1 天

### 2-1 最小可发表单元（三问）

| 问 | 答不出说明什么 |
|---|---|
| 改变谁的什么判断？ | 你不知道读者是谁，综述会写成自说自话 |
| 我有什么是别人没有的？ | 你只有"我也这么认为"，没有证据优势 |
| 发表后别人引用它会引哪一句？ | 你没有贡献句，摘要会写成"本文研究了…" |

### 2-2 判类型（只判一次，全篇按这个类型写）

| 类型 | 结构 | 必写声明 | 最容易死在哪 |
|---|---|---|---|
| **概念型** | 定义 → 机制（2–4 个）→ 可观察蕴含 → 案例示意 → 边界 | "若机制成立，应观察到…" | 被判"空" |
| **比较型** | 单位 → 维度（3–5）→ 同异 → 解释变量 → 回理论 | 比较设计类型（最相似/最不同） | 被判"案例不可比" |
| **对策型** | 诊断 → 工具匹配 → 可行性与副作用 → 指标 | 每条建议挂"机制/执行者/失败条件" | 被判"政策愿望清单" |
| **小调查型** | 抽样 → 描述统计 → 与质性互证 → 不外推 | n<30 不做检验，定位为 exploratory | 被判"样本不足还推断" |

**判据**：类型唯一。想写"既是概念又是实证"的，回到 2-1 重压。

### 2-3 题目试写三版

- 版本 A：现象式（"X 如何被 Y 改变"）
- 版本 B：机制式（"从 A 到 B：X 的机制研究"）
- 版本 C：判断式（"X 不是 Y，而是 Z"）

**判据**：三版都能一句话读通；选一个，另外两个删掉（留着必漂移）。

### 2-4 贡献定位（三句 + 双靶）

选题卡的"引用哪一句"，不能是"本文研究了 X"，必须能被别人原样引走。

```
已有两类研究：A 从（角度）解释，B 从（角度）解释；
但两者都未解释（缺口句，一句话）；
本文以（分析单位/机制/材料）补上这一段，据此提出（命题）。
```

**双靶对标**：找**两个最像本文**的先行研究，各写一句"差在哪"。

| 靶 | 它做到哪 | 本文差在哪 |
|---|---|---|
| 靶一（最像） |  |  |
| 靶二（次像） |  |  |

**判据**：
- 三句能连着读通，且**不含**"填补空白""首次""具有重要意义"；
- 双靶各有一句具体差异（不是"视角不同"这种空话）；
- ⚠️ **术语生态位预警**：若近刊已有人用几乎相同的概念，**必须当场差异化并核先行归属**，不得把术语发明权归给它，也不得装作没看见（`07` #51）。

# 第 3 步 · 找刊定刊

> **一句话**：先证明"这本刊会收这个题"，再查它的硬性要求。

**输入**：选题卡
**产出**：候选池 + 硬约束清单 + 近刊对标 + 字数契约
**耗时**：3–5 天

### 3-1 筛选大前提（七项，先定再找）

收录类型（SSCI/SCIE/AHCI/ESCI）· 是否在预警名单 · 分区口径（单位认哪套）· 经费（APC 上限）· 论文类型 · 语言 · 见刊周期。

**判据**：七项写成一句话，例如"只认 SSCI/AHCI 正刊、零 APC、两年内见刊"。**筛子没画好，找到的是一堆没用的名字。**

### 3-1b 去哪查（权威度分级，不许凭印象）

| 源 | 能查什么 | 权威度 | 注意 |
|---|---|---|---|
| **Web of Science / Master Journal List** | 收录状态 | ⭐⭐⭐⭐⭐ **收录判定金标准** | 只认这里的 Collection 字段，别信第三方转载 |
| **JCR** | IF、JCR 分区 | ⭐⭐⭐⭐⭐ 官方 IF 源 | — |
| **中科院分区表（含"新锐"）** | 分区 | ⭐⭐⭐⭐ 国内认 | 与 JCR 口径不同，**必须标口径**，以职称/结项文件为准 |
| **Scopus / SJR / CiteScore** | 补充指标 | ⭐⭐⭐ | **不作收录判定依据** |
| **中科院国际期刊预警名单** | 排除项 | ⭐⭐⭐⭐⭐ | 🔴 **必查**；进了预警刊 = 白投，甚至负资产 |
| **期刊官网 Aims & Scope** | 能否发这个主题 | ⭐⭐⭐⭐⭐ | 主题匹配的终审 |
| **已发表文献反查** | 我这个主题最近发在哪 | ⭐⭐⭐⭐⭐ | **最重要**，见 3-2 路 B |

> **ESCI 有 IF、有分区，但不是正刊。** 这一条单独记，因为"有 IF"最容易被当成"是 SSCI"。

### 3-2 两条路找候选 + 先例检索

- **路 A 专业对口**：领域关键词 → 直接定位。
- **路 B 专业不对口但能发**：拿 3–5 篇"最像的文章" → 看它们发在哪、在哪个栏目。

> 路 B 常有更好的分区和更快的周期，却因为"不在第一反应里"被漏掉。**两条都要走。**

**先例检索（回答"这本刊收不收我这种类型"）**：不许靠读类型清单，必须用**已发表先例**证明。

```
在该刊近 3 年（或近 3 期样刊）里，找同类型文章：
  ① 逐篇记：题名 / 年份 / 有几图几表 / 大致篇幅 / 有无实证数据
  ② 结论只写一句："找到 N 篇同类型先例"或"未找到"
```

> **这一步决定生死**：一套 77 份附件的样刊里，翻出 8 篇 0 图 0 表的纯概念稿，才敢确认"这本刊收概念稿"。读 Aims 读不出这件事，**只有先把同类文章找出来**。
> **栏目比 Aims 更可靠**：栏目是编辑用脚投票的结果。近刊若设了明文欢迎的栏目（section / article type），摘原句进候选池。

### 3-3 候选池与顺位（凭什么判冲刺还是保底）

`03-模板.md` 表 9，每刊一行。**"主题匹配证据"那一列是全表灵魂**——写不出"Aims 原句 / 某某年发过类似主题 / 栏目明文欢迎"的刊，直接删。

**顺位三判据**（不按 IF 排）：

| 判据 | 看什么 | 影响 |
|---|---|---|
| **初审周期** | 投稿到第一次决定的天数（近刊致谢日期、社群经验、期刊统计页） | 决定"试错成本" |
| **录用率** | 官网/主编访谈/第三方统计（没有就标"未知"） | 决定"值不值得先投" |
| **试错成本** | 周期 × 被拒后重投的工作量（字数口径差异越大，成本越高） | 决定投的顺序 |

**判据**：锁定 **1 主选 + 1 备选 + 1 保底**；顺位表贴在显眼处（"这刊是冲还是保"是最容易忘的事），并写清每一档的**依据**，不许只写"感觉合适"。

**排除项成条**：增刊/特刊默认排除；整系排除的出版方单列；ESCI 单列；预警名单内的直接划掉。

> 完整检索提示词见 `提示词/01-找刊候选发现.md`。


### 3-4 指南原文 → 硬约束清单

**去官网下载《作者指南》原文，存进工作区。不许听转述、不许看第三方整理。**

逐项抄进 `03-模板.md` 表 5，特别注意六项：

1. **字数口径**：含不含摘要/尾注/参考文献/表格/图注/附录（逐项勾）
2. **摘要**：上限、结构（是否要求结构化）
3. **关键词**：个数
4. **必含章节**：致谢/利益/数据可用性/AI 声明/作者简介
5. **AI 政策**：详述型 / 声明型 / 禁止型（决定 8-1 怎么写）
6. **投稿系统**：名字 + **系统里有没有第二个摘要框**（见 9-2）

**判据**：清单每一行都能指出"指南第几段说的"。指不出 = 没抄完。

> **指南与近刊实刊冲突时，按更严的执行**，并在 Cover Letter 说明一句"本文按指南的 X 要求执行"。理由：编辑按指南退修，不按惯例退修。


### 3-5 近刊对标（定刊当天做）

下载 3–5 篇近 2 年同主题文章，记四栏：

| 栏 | 记什么 | 直接影响 |
|---|---|---|
| 摘要 | 各篇词数、均值、最大值、句式 | 我方摘要写多长（**不超过样本最大值**） |
| 结构 | 有无独立理论章、章节编号方式、结论段写法 | 我方骨架 |
| 语域 | 人称（we/I/the paper）、时态、高频概念词 | 英译风格 |
| 引用 | 参考文献条数均值、是否爱引本刊 | 文献规模 |

**副产品**：会顺带发现"必引文献"。⚠️ 若近刊用了与你相近的术语，**不得把术语发明权归给它**，先核先行归属。

### 3-6 字数契约（三档，动笔前签字）

```
上限：____ 词｜口径（逐项勾）：□正文 □摘要 □表 □文献 □图注 □注 □附录
A 正文 = 上限 − 文献 − 表 − 图注 − 注 − 附录
B 正文 + 文献 + 表 + 图注 + 注
C 全部（含附录）
中文目标：____ 字（1 英文词 ≈ 2 汉字，留 10%）
摘要：____ 词｜关键词：____ 个
```

**判据**：A/B/C 三档都 ≤ 上限，以最严档为准；三档写进《表 5》。
**换刊重算**：换刊先重算三档；若 A 比现稿少 >20%，先判"换刊还是砍发现"，不许直接删字。
> **经验**：宁可中文写少、英文后期稍扩；**字数问题的正解是换刊或砍发现，不是抠字**。合法压缩通常只有 5–10%；要砍 >20%，先把附录转补充材料，再动正文。

# 第 4 步 · 读文献

> **一句话**：不追求"读得多"，追求"每篇都有位置"。
> **完整方法见 `04-文献选读法.md`。这里只列动作与判据。**

**输入**：三句话、词表种子（中文论文的英文摘要）
**产出**：文献卡 15–25 张 + 六组表 + 四查报告
**耗时**：5–8 天

| 卡 | 动作 | 判据 |
|---|---|---|
| **4-1 造词表** | 抄中文论文的英文摘要、目标刊关键词 → 中文/英文候选/来源 三列 | ≥10 条，每条有来源；同一概念只留一个英文词 |
| **4-2 滚雪球** | 种子 3–5 篇 → 后向（它们的参考文献）→ 前向（引用它们的近 2 年文章） | 候选 25–40 条（题录级即可） |
| **4-3 三十秒判生死** | 看五信号：刊物 / 题名命中 / 年份 / 类型词 / 参考文献里有没有你认识的 3 篇 | 5 过 4 进；过 3 存疑；≤2 弃 |
| **4-4 六信号填卡** | 题名概念词 / 摘要首句 / 摘要末句 / 一级小标题 / 图表标题 / 结论首段+前 5 条参考文献 | 每篇 5 分钟，填八列，**含"拟引句"** |
| **4-5 分诊** | 三标签：相关度（高/中/低）、用途（定义/机制/情境/方法/反例）、证据强度（全文/摘要/题录） | 每篇三标签齐全；无标签的删 |
| **4-6 六组归位** | 定义 / 机制 / 情境 / 方法 / 政策 / 边界反例，每组 2–5 篇，**每组写三句**（他们说/分歧/我站哪） | 每组 ≥2 篇且三句写得出 |
| **4-7 精读 5–8 篇** | 只读：引言末段、理论节首段、结论首段、图表 | 每篇产出 150 字：问题/答案/没解决/我怎么接 |
| **4-8 文献四查** | **串行跑，不许并**：真不真（三档）→ 对不对（字段页码）→ 引没引（标号闭合＋条数对账）→ 该不该（语义 L1/L2＋漏引＋引号审计）。见 `02` §一 | 四查 0 错；“查不到”不等于“造假” |

**止损三条**：读不懂 → 降级为摘要级；找不到全文 → 不撑核心命题；与三句话无关 → 删（哪怕权威）。

**四查的串行纪律**：
- **先脚本，后语义**。标号闭合交脚本（`check_refs.py`），不让 AI"数一遍"；语义复核**另开会话**，不许与写作会话共用（复核独立性——写作时顺手看过的句子，复核时会天然认可）。
- **三档判定，不做二值判断**。"查不到"只说明降级使用 + 人工核，只有"疑似伪造"（全渠道无 + 刊名刊号不存在 + 年份早于创刊）才删。
- **补两条容易漏的**：无编号转述扫描（含转述词却无引用 = 漏引的唯一防线）、引号内容审计（直引占正文 1%–5%，为 0 不得进清稿）。

# 第 5 步 · 定结构

> **一句话**：先定"每节要让读者相信什么"，再定"每段第一句说什么"，最后才写正文。

**输入**：六组表、类型判定、字数契约
**产出**：论证表 + 标题句串 + 字数分配
**耗时**：2 天

### 5-1 论证表（一页，不是提纲）

`03-模板.md` 表 3。每节一行：

| 节 | 这一节要让读者相信什么（一句话） | 依据（哪几条证据/哪几篇/哪个表） | 读者会怎么反驳 | 我怎么回应 |
|---|---|---|---|---|

**判据**：
- 每行"相信什么"都是一个**可被反驳的主张**（不可反驳 = 废话）；
- "依据"栏必须指向具体文献卡编号或数据表；
- "反驳"栏空着的行，说明你没想清楚，回去想。

### 5-2 标题句串

把每一段的第一句写出来，按顺序连成一串（20–40 句）。

**判据**：**只读这串句子，能不能复述完整论证？** 能 → 结构成立；不能 → 改结构，此时改一句的成本是写正文后的十分之一。

> 这是全流程性价比最高的一个动作。**句串不通，正文一定不通。**

### 5-3 字数分配

按 `03-模板.md` 表 4 填到"段"一级：每段配 120–180 词。

**判据**：合计 = 中文写作目标 ±5%；单节不超过总额 30%。

### 5-4 六缝预检（结构层）

| 缝 | 检测问句 |
|---|---|
| 理论并置缝 | 这两套理论凭什么放在一起？（一个定问题、一个定机制，或造一个接驳概念） |
| 概念-落点缝 | 结论里的关键词，引言定义过吗？ |
| 承诺-兑现缝 | 引言每个缺口，由哪个发现回答？ |
| 概念空转缝 | 这个核心词在操作上指哪几样可观察的东西？ |
| **定义-证据缝** | 把定义抄一遍、把数据能证明的抄一遍；定义比证据大 → 拆概念或降定义 |
| **比较单位缝** | A 与 B 的差异，能否由主体构成／计数口径／样本量解释？能 → 不许归因于 A 与 B |

**判据**：六问都有答案；答不上的先改结构，别写正文。

### 5-5 命题反方检验（**硬门禁**，结构层的最后一道）

> **这一卡不做完，不许进第 6 步。** 理由：此时改命题只改骨架；等到清稿或英译之后再改，全篇作废（真实发生过：清稿后补做，一条命题改、一条降档，全稿重写，已导出的 docx 作废）。
> **完整方法见 `08-对抗审稿法.md` 第二节。**

**四个动作，串行**：

```
① 立靶：抽 2–5 条核心命题，一条一句，挂位置、挂证据类型（文献/材料/纯推理）
   ↓
② 最强反驳：五类各找一次（反例／竞争解释／范围过宽／因果倒置／相关性当因果），找不到写"未找到"
   ↓
③ 文内自拆：承重引文 5–10 条，抄本文转述 → 看原文主张 → 判是否互斥
   ↓
④ 处置四选一：改命题／限定范围／补论据／维持并写进局限（不许空）
```

**判据（五条全过）**：
- [ ] 每条命题都有至少一条最强反驳
- [ ] 每条命题都有处置，且"改/限定/补"的已标出正文位置
- [ ] "维持"的，局限段确有对应句子
- [ ] "改命题"的已回第 2 步返工，**并重跑受影响检查**（5-1 / 5-2 / 文献四查 / 终检 2、7）
- [ ] `03` 表 11 已填、已编号、状态已标

**挡在门外的东西**：命题写成态度（"具有重要意义"）、反驳写成空话（"论证不够充分"）、处置写成"再想想"、审完不留表。三种都不算过。

> **补充：命题分档**。每条命题先归"已证事实 / 本文主张 / 待检验假设"，档位决定动词（证明→认为→可以推断）。**摘要的档位不得高于正文**——摘要写"证明"、正文只敢写"可以推断"，是最常见的倒挂（`07` #50）。

# 第 6 步 · 写初稿

> **一句话**：**先句子、后段落、再节**。禁止"生成一节"。
> **完整方法见 `05-初稿生成法.md`。**

**输入**：标题句串、论证表、字数分配
**产出**：中文定稿
**耗时**：10–15 天

### 动笔前先定段型（**不是每段都有论点**）

| 型 | 有没有主张 | 靠什么支撑 | 典型章节 | 典型错配 |
|---|---|---|---|---|
| **论证段** | 有，来自论证表 | 文献转述 ＋（可选）材料 ＋ 推理 | 理论、机制、综述评价 | 只转述文献，没落回本文对象 |
| **描述段** | 无，只陈述事实 | **至少 1 条材料/数据** | 现状、资源禀赋、案例 | **无料评价**（"价值重大""优势明显"） |
| **推演段** | 有，属作者自己的分析 | 前文论点/材料 ＋ 逻辑 | 原因分析、对策推导 | 不指向前文依据，凭空推 |
| **导语**（章首） | 无 | 复述本章论点与要用的材料 | 每章第一段 | 提前下结论、新增观点 |
| **小结**（章末） | 无（只回收） | 回收本章论点 | 每章末段 | 外推、引入新料、"综上所述意义重大" |

**三条硬规则**：① 描述段禁止无料评价；② 论证段必须落回本文对象；③ 推演段必须指向前文依据。

| 卡 | 动作 | 判据 |
|---|---|---|
| **6-1 逐段扩写** | 一段一段长：主张（已定）+ 证据（指定来源）+ 解释 + 回扣/过渡。AI 三条禁令：不新增论点、不新增证据、不提高主张强度 | 每段 4–6 句，120–180 词 |
| **6-2 段落四问** | 先判型，再问：主张能被反驳吗（论证/推演段）/ 证据直接支持主张吗 / 有没有"正确的废话" / 末句指向下一段吗 | 四问都过；描述段不问第一问，只问"有没有料" |
| **6-3 节三问** | 首段交代"本节做什么"吗 / 末段交代"所以呢"吗 / 删掉本节论证会断吗 | 三问都过（"不会断"= 可删） |
| **6-4 连接词通读** | 只查"因为/因此/然而/相反/所以"，逐处问"真的成立吗" | 无跳步 |
| **6-5 冷却复读** | 放 24 小时，只读标题句串 + 每节首末段 | 还能复述论证 |
| **6-6 数据-主张对账** | 正文凡"全量／所有／均／每"的主张，回编码表核覆盖率；不足 100% 就改口径 | "全量"类主张覆盖率 = 100%，或已改成"代表性／部分" |
| **6-7 对象迁移残留扫描** | 若本文改写过研究对象/场域：搜原对象的地名、数据、年代、专属结论 | 残留 0 处；跨对象只搬"维度"，不搬结论与证据 |


**中文阶段只改四类硬问题**：事实错、口径不一致、概念不准、逻辑不闭合。
**不要改**：句子优美、用词高级、衔接顺滑——这些在英译阶段会整段重写，现在花的功夫 100% 作废。

# 第 7 步 · 译英文

> **一句话**：中文冻结后才译；只改英文，不回头改中文（除非期刊变更）。

**输入**：中文定稿
**产出**：英文稿 + 五查报告
**耗时**：5–8 天

| 卡 | 动作 | 判据 |
|---|---|---|
| **7-1 冻结快照** | 复制一份 `中文-冻结.md`，**永不回写** | 有独立文件，且后续只读 |
| **7-2 分块翻译** | 顺序固定：摘要 → 各节 → 声明 → 参考文献 → 附录。**不并行**（并行必术语漂移） | 每块译完立即自检术语 |
| **7-3 术语对齐** | 跑术语脚本；英式/美式拼写全篇统一（他人标题原文例外） | 禁用词 0；异写 0 |
| **7-4 回译抽检** | 抽 10 段英→中回译，与原意比对 | 语义漂移 0 |
| **7-5 对照稿确认** | 中英逐段并排；**作者只读中文侧**判断内容，扫英文侧判断通顺 | 作者签字 |
| **7-6 抽英文单行稿** | 机械抽取英文段，**不重写** | 反向清点：标题数/表数/图数/关键句都在 |
| **7-7 译文五查** | 术语 / 回译 / 数字 / 格式 / 通畅（见 `02`） | 五查全过 |

**英文三条红线**：不自创译法；不增译、不减译；中文模糊处标记出来交作者，不许"顺手写通顺"。

### 7-8 同步与真源（改稿铁律）

| 规则 | 内容 | 违反的后果 |
|---|---|---|
| **中文是源** | 中文冻结后才译；英文稿里不许出现中文稿没有的论点 | 一稿两义，返修时不知以哪边为准 |
| **改一侧必改另一侧** | 中文改动 → 英文对应段同批改；英文改动（只许语言层）→ 不回写中文 | 中英摘要两版、发现数不一致（`07` #20、#49） |
| **只改真源** | md 是真源，docx 由真源生成；**不许直接改 docx** | 下轮生成覆盖你的手改，改动丢失 |
| **单一事实源** | 数字只从 `numbers.md` 取，术语只从术语表取，决策只从 `decisions.md` 取 | 同一指标三个值（`07` #35–#37） |

**判据**：改完一处，能说出"这个改动影响了哪几个文件"，并逐个回勾。


> **诚实定位**：这套方法能保证"术语一致、语法正确、语域规范"，**不保证母语级自然**。要再进一步，只有付费母语润色。

# 第 8 步 · 做成投稿件

> **一句话**：把 md 变成 4 份能上传的 docx，并且**不留任何工作痕迹**。

**输入**：英文定稿 + 图件
**产出**：匿名主稿 / 标题页 / Cover Letter / 图注表 + 300dpi 图 + 终检报告
**耗时**：2 天

### 8-1 去工作痕迹（交稿前两查）

见 `02-检查清单.md`。六类要清：待定/中间态、内部工作语、投稿策略、版本尾注、回迁语、审稿痕迹。
五类要留：审慎声明、方法说明、附录导读、数据可用性、工作稿专属记录（**只留在工作稿**）。

**判据**：六类 = 0；五类未被误删。

### 8-2 匿名化（**自引怎么处理**）

双盲刊要求匿名稿无作者信息，但自引又不能凭空消失。三步：

1. **改第三人称**：不写 "our previous work"，写 "Author (2024) argued…"。
2. **文献表处理**：按该刊要求，或保留匿名化条目（"Author. 2024. …"），或整条移出并在 Cover Letter 说明。
3. **Cover Letter 交代一句**：说明"为满足匿名评审要求，作者自引已改为第三人称，相应条目见 XX"。

**判据**：正文 0 处姓名/单位/致谢/基金/邮箱/ORCID；**且**附录/参考文献/图表未被误删（对比匿名前后词数差，差值应等于被删身份信息的词数）。

> ⚠️ **注意区分两件事**：
> - **匿名自引**（上面这套，是技术处理）；
> - **重复发表**（把已发表的中文内容翻译成英文再发，是学术不端）。
> 后者只有一条规则：**已发表内容只许"引用+概括"，不许"整段翻译"**；新文必须有新增数据/新增论证/新增对话（经验值：新内容 ≥30%）。

### 8-3 生成四份 docx

匿名主稿 / 标题页与声明 / Cover Letter / 图注与表注。图片一律 300dpi 定尺（宽按版心，例 1713px@300dpi ≈ 14.5cm）。

### 8-4 文件属性清理

清：生成器名、生成器日期、缩略图、修订痕迹、批注、人员信息、图片 EXIF。
**先跑脚本**：`python 工具/scripts/scrub_meta.py <投稿件目录>`；再人工看三项：缩略图无、`generated by python-docx` 无、created 不是 2013。
**删缩略图必须同时删 `_rels/.rels` 里的对应关系**，否则文件打不开——脚本已处理，清完仍要开档验证。

### 8-5 成稿十八项终检

见 `02-检查清单.md` 第四张。**逐项跑，改过就重跑。**

### 8-6 三角色审稿（**复查型，不越界**）

> **分工铁律**：发现型审稿（找逻辑漏洞、改论证）**只在中文稿做**；英文阶段只做三件事——
> **① 落地复查**（中文定下的每条修改，英文有没有漏）｜**② 英文专有维度**（词数口径、术语正字、英式/美式拼写、长句可读性）｜**③ 英文通畅**（只找语病，不动术语/数字/事实）。
> **越界禁止**：英文阶段不得提"新增论据 / 调整论证结构 / 改结论"。提了不改，等于给自己埋雷；提了要改，全稿重译（`08` §一）。

三个立场各提 3 条，只改"成立"的：**理论**（概念是否成立、与先行研究差异）｜**方法**（样本、编码、归因）｜**目标刊读者**（是否本刊的题、贡献句是否清楚）。

**每条必须给**：严重程度（致命/重要/次要）+ 原文定位（≥10 字原句）+ 一句话改法。**无定位的意见视为无效。**

**采纳纪律**：不采纳只认三条理由——审稿人读错了（指出原文 + 把原文改清楚，两边都做）｜超出本文范围（写明"本文不处理 X" + 替代动作）｜与其他意见冲突已另作裁定（写明理由）。

**记录**：意见落审稿记录表（批次/对象/方法/意见数/已改/未改/状态），状态写"关闭"才能投稿。

> 提示词：`提示词/11-三角色审稿.md`。

# 第 9 步 · 投稿与返修

> **一句话**：投出去只是开始；真正决定命运的是返修和转投。

**输入**：材料包
**产出**：投稿号 / 返修稿 / 转投方案
**耗时**：1 天 + 事件驱动

### 9-1 投稿前四查

内容层 / 文件层 / 作者信息 / 事实核验（见 `02`）。
**没有脚本输出 = 没查**；至少贴 `check_counts` / `check_refs` / `scrub_meta` 三项的输出，再说"可投"。

### 9-2 系统填写（**注意隐藏字段**）

| 字段 | 注意 |
|---|---|
| 标题 / 摘要 | 系统可能另有**第二个摘要框**（"简要摘要"，字数比正文摘要更少）。现场压缩即可，**不必回改正文摘要**——那是一次性工作 |
| 关键词 | 个数按指南；系统可能限制分隔符 |
| **字符限制字段** | 标题、running head、推广摘要、tweet、图摘要说明：系统说 character 就数字符（含空格），说 word 才数词；两个都数，取严 |
| 作者信息 | 姓名用字、**机构官方英文名**（不是百科译名）、ORCID、基金编号逐字核 |
| 推荐审稿人 | 同领域、无利益冲突；可填 3–5 位 |
| AI 声明 | 按 3-4 查到的刊型（详述/声明/禁止）写 |
| Cover Letter | 四段：投什么 + 文章做了什么（3 句）+ 为何适合本刊（引 Aims 原句 + 近刊／专题一句）+ 常规声明 |

### 9-3 状态跟踪与冻结

每个状态记一行：日期 / 状态 / 依据（邮件原句）/ 下一步。
**投稿后 24h 内冻结**：上传文件复制到 `_submitted_YYYYMMDD/`，记 SHA256、字数、稿件号；此后只读。要"含作者版"另存 `_author`，不改 `_submitted`。

### 9-4 返修五步

见 `06-返修与转投.md`：冷静期 → 编号分级 → 逐条回应表 → 只改必要处 → 二次体检。

### 9-5 拒稿分诊

| 类型 | 判据 | 动作 |
|---|---|---|
| **桌面拒稿 · 不符主题**（**最常见**） | 无外审意见，或只有一句"not a good fit" | **不修改内容，换刊**。改内容没用，问题在刊物归属 |
| 桌面拒稿 · 类型/完整性 | 明确说"不收这种文章"或格式问题 | 换刊，或补齐格式 |
| 外审后拒 | 有具体意见 | 先改，再投（意见是免费资源） |
| Reject & Resubmit | 实质重大返修 | 按返修流程做，回原刊 |

**转投三条硬规矩**：前刊未终结绝不投他刊；**不用期刊的"自动转投"**（会传旧版）；转投前做差异清单（字数口径/摘要/关键词/章节/引用体例/学科话术）。
