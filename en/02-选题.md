# 第 2 步 · 选题：三句话、粗扫、最小单元、贡献句

> **一句话**：把"我想研究 X"压成"X 里有一个反常，我要用刚好够的证据证明它"。
> **输入**：第 1 步的类型判定、术语表 v0、手上材料清单
> **产出**：`02-选题/选题卡.md`、`02-选题/粗扫记录.md`
> **耗时**：1–2 天
> **判据**：四问可答；三句话不含"重要 / 意义"；类型唯一；双靶有候选并标【待核】

---

## 一、这一步不做什么

不读全文、不做综述、不写提纲、不定刊。只回答两个问题：**值不值得写、写多大。**

第 1 步的旧版把"找刊"塞进了这里，结果和第 3 步重复了六成。这一步只产出"选题卡"，找刊留给第 3 步。

---

## 二、三句话（选题卡的骨架）

| # | 写什么 | 判据 |
|---|---|---|
| 1 | **我看到的反常** | 一个与常识或既有解释不一致的现象，能指到一个可观察的事实 |
| 2 | **我要问的问题** | 一句疑问句，指向机制、条件或后果，不是"现状与对策" |
| 3 | **我现在的判断** | 一句陈述，**别人可能不同意**；不同意的人能说出他为什么不同意 |

三条禁令：

- 不出现"重要、意义、价值、亟待"；
- 不写"填补空白"——空白不等于值得填；
- 一句只说一件事，超了就是题目太大。

**例子（虚构）**：

```
反常：补贴登记的项目数在涨，实际演出场次在跌。
问题：登记口径与实际运营为何脱节？
判断：以"登记在册"作为政策目标，会系统性高估补贴效果。
```

## 三、粗扫 10 篇（2 小时，不读正文）

### 1. 去哪找

- 目标刊近两年目录（还没定刊，就先圈 2–3 本可能刊）；
- 还没定刊时，用 Crossref 按 ISSN 拉这 2–3 本刊的近两年题录，题名直接过（做法见 `03-定刊.md` 第三节），比翻官网目录快；
- 三个种子作者（你手上材料的作者、被引最多的作者）；
- Google Scholar 的"被引"与"相关文章"。

没有机构库不影响这一步：题名与摘要都是公开的。

### 2. 只读三处

1. **题名**：对象 + 问题；
2. **摘要第一句**：它研究什么对象；
3. **摘要最后一句**：它主张什么。

不读引言、不读方法、不记笔记、不评价好坏。这一小时的目的只有一个：**看这个题有没有人做过、做到哪。**

### 3. 记录四列（`粗扫记录.md`）

| 题名 | 对象 | 它主张什么（一句中文） | 与我同题吗 |
|---|---|---|---|
| … | 某县非遗补贴 | 补贴提高了项目存活率 | 近似 |
| … | 全省登记数据 | 登记数与演出场次脱钩 | 是 |

"它主张什么"自己用中文写，不抄英文摘要。

### 4. 语言不够怎么办

三步，够用：

1. 机翻题名 + 摘要首末句；
2. 只回答三个"是 / 否"：同一对象？同一问题？同一结论？
3. 不读全文、不评价质量、不判断期刊档次。

**不要**在这一步试图"读懂这篇文献"——那是第 4 步的事，而且第 4 步只读你要引的那几句。

### 5. 什么时候停

- **有 3 篇同题**：题有先例，可以写；接着做第 3 步定刊；
- **0 篇同题**：可能太新、太窄，或刊不对。回第 1 步换问法，不要硬写"没人研究过"；
- **10 篇全不同题**：你的关键词有问题，换词再扫一轮（最多两轮）。

## 四、最小可发表单元

**定义**：一个判断 + 刚好够的证据 + 一条边界。

按 8,000 词的刊型，一个单元大约是：

- **1 条核心判断**（三句话里的第 3 句）；
- **3–5 条支撑判断**（每条将来是一个 P 号）；
- **2–3 类证据**（政策文本、统计数据、案例、访谈，任选）；
- **1 条边界**："本文不主张……"。

**三个测试**：

1. **一句话测试**：能不能用一句话说出"本文主张什么"？说不出来＝单元没成形。
2. **抽一条测试**：删掉任意一条支撑判断，核心判断是否还站得住？站得住＝这条是冗余，删。
3. **加一条测试**：再加一条支撑判断，字数是否超契约？超了＝题目太大，砍一个分支。

**边界句必须写**：不写边界，审稿人会替你写——通常写成"作者过度声称"。

## 五、贡献句与双靶

### 1. 贡献句：三截，缺一不可

```
本文主张【X】，因为【Y】，在【Z 条件】下成立。
```

- 只有 X＝观点；只有 X+Y＝没有条件；三截齐了才是可检验的贡献。
- 不许写"本文填补了……空白""本文具有重要理论意义"。

### 2. 双靶：两个候选，都标【待核】

| 靶 | 问什么 | 写什么 |
|---|---|---|
| **靶 A：最近的同题研究** | 他们做到哪、漏了什么 | 一句："他们解释了 A，但没解释 B" |
| **靶 B：最强的反对解释** | 如果我错了，最可能是因为什么 | 一句："若 X 由规模而非机制导致，本文判断不成立" |

**为什么标【待核】**：这时你只粗扫了题名与摘要，没读全文。第 4 步用文献卡回填，改成"已核"，并写上 文号。**不许在这一步假装已经读过。**

靶 B 不是走过场：第 5 步的"命题-反例-回应"直接从这里长出来；靶 B 写不出，说明这个判断还不值得写。

## 六、四问（答不出就不进第 3 步）

| # | 问 | 合格答案长什么样 |
|---|---|---|
| Q1 | **反常是真的吗** | 能指到一个数据、条文、事件或案例；不是"我感觉" |
| Q2 | **别人做到哪** | 三篇同题各做到哪、我比他们多什么（一句） |
| Q3 | **我凭什么能做** | 材料、位置、方法、语言，至少一条别人短期拿不到 |
| Q4 | **谁在乎** | 哪本刊的哪群读者，会在哪个具体问题上引用我 |

每问不超过两句。答不出的写【待核】＋"打算怎么补"，不许空着。

Q4 最容易答成"大家都会关心"——那不是答案。写成"研究中国非遗政策的学者，在讨论政策指标替代时"才算。

## 七、选题卡长什么样（`选题卡.md`）

| 字段 | 内容 |
|---|---|
| 题目（临时） | 一句话，可后改 |
| 类型 | 概念型 / 比较型 / 对策型 / 小调查型（只选一个） |
| 三句话 | 反常 / 问题 / 判断 |
| 四问 | Q1–Q4，各 ≤2 句 |
| 最小单元 | 核心判断 + 3–5 条支撑判断 + 2–3 类证据 + 边界 |
| 贡献句 | X / Y / Z 三截 |
| 双靶 | 靶 A、靶 B，各一句，标【待核】 |
| 不做什么 | 边界：本文不主张…… |
| 待核清单 | 哪几处第 4 步必须回填 |

**关键词**同时写五个（中英各一版，英文先用机翻再核）——第 3 步找刊要用。

## 八、判据与"该停"信号

- [ ] 三句话齐全，无"重要 / 意义 / 价值"；
- [ ] 判断句可以被反驳（能说出反方理由）；
- [ ] 四问有答案，或【待核】＋补法；
- [ ] 类型唯一；
- [ ] 双靶各一句，标【待核】；
- [ ] 关键词五个，中英各一版。

**该停**：

| 信号 | 说明 |
|---|---|
| 反常指不出任何事实 | 这是感想，不是研究 |
| 三篇同题都已做过你说的事 | 回第 1 步换问法，或换对象 |
| Q3 一条都答不出 | 你拿不到材料，写不动 |
| Q4 答成"大家都会关心" | 没有具体读者，就没有具体刊 |

## 九、三条坑

| 症状 | 动作 |
|---|---|
| 把"没人研究"当缺口 | 写成"已有两类解释，但都没解释 X"。没人研究，多半是没人关心 |
| 三句话写成摘要 | 反常不是背景，判断不是综述。三句话里不出现"随着……的发展" |
| 题目过大 | 用"删一条支撑判断就塌"测试；塌不了就砍，砍到能塌为止 |

> 完整故事见 `C-失败模式库.md`（打标签 `#2`）。

## 十、交给第 3 步什么

- 题目（临时）、类型；
- 五个关键词（中英）；
- 四问里的 Q4（谁在乎）——它决定找哪一类刊；
- 双靶候选（第 4 步回填）；
- 最小单元的字数预估（3–5 条支撑判断）。

第 3 步**不要求**你已经读过全文；它要求你能说清"这本刊的哪群读者会在乎"。
