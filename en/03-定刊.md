# 第 3 步 · 定刊：前提、双路径、候选池、指南、近刊、字数契约

> **一句话**：先确认「这本刊会不会收这种稿」，再让它的硬约束倒推你的字数和结构。
> **输入**：选题卡（题目、类型、关键词、Q4 谁在乎）、术语表
> **产出**：`03-定刊/` 六件 —— 筛选前提、候选池、顺位表、指南硬约束、近刊对标、字数契约；外加 `原文/`（官方指南存档）
> **耗时**：3–5 天
> **判据**：每刊有匹配原句；指南每条可指第几段、有来源 URL 与抓取日期；三档字数 ≤ 上限；中文换算留 10%
> **硬门禁**：没有官方《作者指南》原文、并经人逐条核对，不许开始写正文（见第六节）。
> 可调用单元：`skills/S1a_找刊/SKILL.md`（找刊）、`skills/S1b_锁定/SKILL.md`（取指南与规格）。判据仍以本文件为准。

## 一、筛选大前提（标准不定，不许找刊）

> 不先画好筛子，找出来的刊是「一堆没用的名字」。开始检索前逐条答完（`skills/S1a_找刊/SKILL.md` 第 4.1 节）。

| 维度 | 要问的问题 | 备注 |
|---|---|---|
| 收录类型 | SSCI / SCIE / AHCI / ESCI / Scopus？ | 第一硬筛；口径写进锚点，不照搬别人的门槛 |
| 预警名单 | 目标刊是否在预警名单？ | 必查；进了预警刊＝白投 |
| 分区口径 | 单位认哪一套？（JCR / 中科院 / 其他） | 口径必须标清，不同口径结果不同 |
| 经费 | 有无 APC 预算？上限多少？ | 决定可否投 OA 刊 |
| 论文类型 | 概念型 / 比较型 / 对策型 / 小调查型 | 决定哪些刊根本不收 |
| 周期 | 多久要见刊？ | 决定冲刺刊与保底刊配比 |
| 语言 / 人称体例 | 只投英文刊？ | 一般到第六节细查 |

产出 `筛选前提.md`，逐条有答案后才进第二节。

## 二、七项前提（任一为「否」，换刊，不改稿）

| # | 前提 | 怎么查（没有机构库也能查） | 通过标准 |
|---|---|---|---|
| 1 | **学科归属** | 期刊官网 Aims & Scope | 能抄出一句含你关键词的原句 |
| 2 | **近作** | Crossref 按 ISSN 拉近两年题录（见第四节），题名人工过 | 近 2 年 ≥3 篇同主题 |
| 3 | **类型** | 同上，看题名里的类型词；再加「先例检索」 | 有同类型先例（概念 / 比较 / 对策 / 小调查） |
| 4 | **语境** | Aims 与投稿说明 | 收中国 / 东亚单国案例；明确「不收单国案例」的，排除 |
| 5 | **方法** | 近三年论文的方法段（只看标题与摘要） | 收你这类证据（政策文本、小样本、案例） |
| 6 | **容量** | 字数上限 vs 你的最小单元 | 上限装得下：中文换算后不超 1.1 倍 |
| 7 | **门槛** | 投稿说明 | 非邀稿；APC 能承担；语言要求可达到 |

**一条否决**：第 3 项找不到同类型先例，不是改标题能解决的 —— 这本刊不收这种稿。

**先例检索（补第 3 项）**：不靠类型清单猜，拿先例文章证 —— 翻 2–3 期样刊的全部研究论文，数其中「0 图 0 表」的纯概念稿有几篇；若你要投概念型而该刊 0 篇纯概念稿，视为无先例。

## 三、双路径与权威源分级：两类论文，两条找刊路

| | 甲类：累积型 | 乙类：材料型 |
|---|---|---|
| 起点 | 已有判断链或在研项目 | 一批自己的材料 |
| 检索词 | **框架词**：机制、维度、条件的英文表达 | **对象词**：对象 + 政策 + 地域 |
| 先做什么 | 先用选题卡的判断链（准框架）找刊；完整结构留到第 5 步 | 先定刊，再按刊调框架 |
| 风险 | 学科归属错（投到不认这个框架的刊） | 材料太多，字数删不掉 |

两条路走**同一张候选池**，只是检索词不同。甲类用 3–5 个框架词组合；乙类用「对象 + 政策工具 + 地域」三词组合。

**双路径匹配**（`00-总览.md` 第五节的三证在这里落地）：

| 路径 | 含义 | 怎么找 |
|---|---|---|
| **A：专业对口刊** | 期刊本身就是这个领域 | 领域关键词 → 直接定位 |
| **B：专业不对口但能发此方向** | 期刊属别的领域，但接受该主题 / 方法 | **已发表文献反查**：拿 3–5 篇最像的文章 → 看它们发在哪 → 那些刊进池 |

路径 B 最易被忽略、也最值钱：它常常有更快的周期与更友好的主题包容度，却不在「专业第一反应」里。**两条路都走过**才算这一节做完。

**权威源效力分级**（收录与分区必须在权威源核实，不得凭印象）：

| 级 | 源 | 能定什么 | 能不能当判据 |
|---|---|---|---|
| ⭐⭐⭐⭐⭐ | WoS Master Journal List | 收录状态（SSCI/SCIE/AHCI/ESCI） | ✅ 收录判定金标准 |
| ⭐⭐⭐⭐⭐ | JCR | IF、JCR 分区 | ✅ 官方 IF 源 |
| ⭐⭐⭐⭐⭐ | 中科院分区表 / 新锐分区 | 分区 | ✅ 但**必须标口径**，与 JCR 不同 |
| ⭐⭐⭐⭐⭐ | 预警名单 | 排除项 | ✅ 必查 |
| ⭐⭐⭐⭐⭐ | 期刊官网 Aims & Scope | 能否发这个主题 | ✅ 主题匹配最终看这里 |
| ⭐⭐⭐⭐⭐ | 已发表文献反查 | 我这个主题最近发在哪 | ✅ 路径 B 的唯一可靠方法 |
| ⭐⭐⭐ | Scimago（SJR）/ Scopus（CiteScore） | 补充参考 | ❌ 不作收录判定依据 |
| — | 出版社 journal finder | 线索 | ❌ 只作参考，不作依据 |

## 四、候选池：只留能投的，8–12 本

**用 Crossref 批量核刊（最省时间的一步）**

Crossref 有公开 API，按 ISSN 一次拉出近两年全部题录，不用机构库、不用翻页：

```
https://api.crossref.org/journals/{ISSN}/works?filter=from-pub-date:2024-01-01&rows=100&select=DOI,title,published,abstract&cursor=*
```

- `{ISSN}` 填目标刊的 **online ISSN**（官网 About 页有；两个 ISSN 时用电子版那个）；
- 返回的 `total-results` 是该刊近两年**总量**，先看规模；`title` 用来数「同题数」和「类型先例」；
- `abstract` 很多出版社不给；给了也常是带 JATS 标签的 XML，去掉标签再看；没有就用题名判断「对象 + 问题」，别停在这里找全文；
- 想再窄一点加 `&query.title=关键词`，但这是模糊匹配，**只能粗筛、不能当精确计数** —— 最终人工过前 20–30 条题名；
- 要翻页，首个请求加 `cursor=*`，再把返回的 `next-cursor` 填回 `cursor=`；别用 `offset`（深翻页会漏）；
- Crossref 只给元数据，**不给影响因子、分区、审稿周期** —— 这三项回第三节的权威源看；
- 一个 ISSN 打错，拉回来的是另一本刊的题录。先在官网核对刊名，再复制 ISSN。

**每刊一行，六列**：

| 刊名 | 学科 | 近 2 年同题数 | 类型先例 | 匹配原句（Aims 里那句） | 结论 |
|---|---|---|---|---|---|
| … | 公共政策 | 4 | 有（概念型） | "…local governance and policy implementation…" | 可投 |
| … | 区域研究 | 2 | 无 | "…comparative area studies…" | 排除（不收单国） |

**池子规则**：8–12 本，不追求全；每刊必须有「匹配原句」，抄原话，不写「感觉合适」；排除的也留一行写清为什么 —— 换刊时不再重查。

## 四·补、AI 自动资料获取路径（检索 / 核对 / 筛选共用）

> 人工逐刊翻官网、逐条核文献，范围太大、容易漏，也容易把「没查到」当成「没有」。下面四类源可安排 AI 自动获取，用来**快速聚焦**；不同源效力不同，不许混用。对应提示词卡 `S6-自动资料获取.md`。

**来源效力分级（先记这一条）**

| 级 | 源 | 能用来做什么 | 能不能当判据 |
|---|---|---|---|
| **A · 官方硬约束源** | 期刊官网 Instructions for Authors / Aims & Scope / 出版社 journal home | 字数、摘要、关键词、匿名、AI 声明、APC、投稿系统 | ✅ **唯一判据源**（见第六节） |
| **B · 可核验元数据 / 题录源** | Crossref API、OpenAlex API | 题录批量拉取、DOI 实测与题名反查、同题数粗筛、文献筛选漏斗、引用关系 | ✅ 可作「真 / 对」判据，但须留原始响应 |
| **C · 探索性线索源** | Wikipedia 镜像、期刊官方 RSS / 静态目次页 | 主题背景、期刊定位、近刊题名与栏目、把检索词收敛为学界通用词 | ❌ **不作判据性事实源**；只用来缩小人工查阅范围 |
| **D · 兜底** | Google Scholar `site:` 检索、本人文献的参考文献反查 | 路径 B 的补漏 | ❌ 线索级 |

**四类源怎么用**

1. **Crossref API（B 级）** —— 除第四节的按 ISSN 拉题录外，扩展到核对与筛选：
   - 单条 DOI 实测：`curl https://api.crossref.org/works/{DOI}`；
   - 题名反查 DOI：同一端点加 `?query.bibliographic=题名`；
   - 翻页用 `next-cursor`；`total-results` 只看规模，**不当同题数**（`C-失败模式库.md` #3）；
   - Windows 环境若 `python urllib` 因 SSL 证书失败 → 改用 `curl`。
2. **OpenAlex API（B 级 · 新增）** —— 用于「主题 → 相关 Works / 来源期刊 / 作者」的粗筛与文献筛选漏斗记数；每个检索阶段留「命中数 → 纳入 / 排除 / 去重 → 入库数」三列（`S6` 卡）；只取可回查的 ID / DOI / 题名，不取「AI 认为相关」的二手结论。
3. **期刊官方 RSS / 静态目次页（C 级 · 新增）** —— 快速拿到近刊题名、栏目名、文章类型（Article / Review / Essay），支撑「类型先例」与第七节近刊对标；凡要写进 `指南硬约束.md` 的数字，必须回 A 级官方指南原文核。
4. **Wikipedia 镜像（C 级 · 新增）** —— 只用于主题背景、概念谱系、机构 / 地名初筛；**禁止**用它判定收录、分区、机构官方英文名、指南数字（依据 `skills/S7_投稿/SKILL.md` 第 3 节、`10-投稿件.md` 的 2C）。

**闭环（三步，缺一步不算完成）**

```
AI 取数 → 留证（URL / 抓取时间 / 原始响应或存档路径 / 命中数） → 人拍板（顺位、纳入排除、口径）
```

留证三列写进 `03-定刊/候选池.md` 或 `04-两库/四查报告.md`；「C 级线索 → B 级核验 → A 级定判」的升级路径必须能在留证里看出来。检索式与纳入排除标准须人确认后才执行；算不出来的数字不许进论文（`00-总览.md` 三条禁令）。

## 五、顺位表：A / B / C

| 档 | 含义 | 数量 |
|---|---|---|
| **A** | 现在投 | ≤3 本 |
| **B** | A 拒了转 | ≤3 本 |
| **C** | 备选 / 观察 | 其余 |

**排序依据**（依次比，前者优先）：匹配度（Aims 原句与关键词重合多少）→ 类型先例 → 字数余量 → 审稿周期（官网或近期论文 received–accepted 间隔）→ APC 与门槛。

写一句「**为什么 A 在第一位**」。换刊时重排，不复制旧表 —— 旧表的排序理由对新刊不成立。顺位由人拍板，AI 不代定。

## 六、作者指南获取与硬约束

### 6.1 作者指南获取（AI 主动取数 + 人工核对门禁）

期刊的《作者指南 / Instructions for Authors》与 Aims & Scope 一般都是公开的，不必等人工提供，也不必只靠 AI 转述。分三层做（对应提示词卡 `D3c-定刊-作者指南获取.md`）：

**① 取数层（AI 可做）**
1. 按刊名 + ISSN 主动搜索并打开**期刊官网**的 Instructions for Authors / Guide for Authors / Aims & Scope 页面；出版社 journal home 亦可，但须落到**官方页面**，不采第三方整理稿。
2. 下载或另存原文（PDF / 网页完整存档），放进 `03-定刊/原文/`，文件名带刊名与抓取日期。
3. 官方页若给出「投稿系统」「APC」「匿名要求」「AI 政策」「字数口径」等分点链接，逐点一并存档。
4. 官网找不到时：先查出版社 journal home → 再查该刊近期论文里的指南链接 → 仍找不到才标【未载明】并请人补；**不许用记忆或第三方转述填表**。

**② 核对层（人必须做，硬门禁）**
- 逐条对照**官方原文**核 6.2 的硬约束表，每条写「第几段 / 哪一句」；
- 指南与近期实刊冲突时，按更严的执行并在 Cover Letter 说明；
- 人拍板：字数口径（含不含参考文献 / 摘要 / 脚注）、目标刊顺位、取舍。

**③ 留证层（双方）** —— 每条要求登记三列：来源 URL / 抓取日期 / 原文存档路径。换刊时整表重做，不把旧刊数字抄到新刊头上。

> **自动获取 ≠ 替代人工核对**。AI 抓取只用于「把原文找齐、把清单预填好」；期刊事实属硬约束事实，以官方原文为准。历史教训：凭转述写错摘要词数、关键词数、投稿系统名，写完才返工（`C-失败模式库.md` #3）。
> **硬门禁**：`03-定刊/原文/` 有官方原文存档、且人对照原文逐条核完之前，不许开始写正文。

### 6.2 指南硬约束：只摘数字与硬要求

读作者指南的方法：机翻 + 只找**数字**与 **must / should**，其余不读。

| 项 | 要求 | 位置（第几段） | 来源 URL | 抓取日期 |
|---|---|---|---|---|
| 字数上限（含 / 不含参考文献？） | 8,000 words | 第 2 段 | 〔官方指南 URL〕 | 〔YYYY-MM-DD〕 |
| 摘要 | 200 words，结构化 / 非结构化 | 第 3 段 | 〔〕 | 〔〕 |
| 标题 | ≤15 words | 第 3 段 | 〔〕 | 〔〕 |
| 关键词 | 4–6 个 | 第 3 段 | 〔〕 | 〔〕 |
| 图表 | ≤6 个，分辨率 ≥300dpi | 第 5 段 | 〔〕 | 〔〕 |
| 参考文献 | APA 7 / 作者-年；≤60 条 | 第 6 段 | 〔〕 | 〔〕 |
| 匿名 | 正文与文件属性均匿名 | 第 7 段 | 〔〕 | 〔〕 |
| AI 声明 | 是否要求、放在哪 | 第 8 段 | 〔〕 | 〔〕 |
| 数据可用性 | 是否要求声明 | 第 8 段 | 〔〕 | 〔〕 |
| Cover Letter | 是否要求、写什么 | 第 9 段 | 〔〕 | 〔〕 |
| 补充材料 | 是否允许、格式 | 第 10 段 | 〔〕 | 〔〕 |
| **投稿系统** | 系统全名（不凭印象） | 〔〕 | 〔〕 | 〔〕 |
| **字符限制字段** | 标题 / running head / 推广摘要按 character 计 | 〔〕 | 〔〕 | 〔〕 |

**三条规则**：
1. 每条标「第几段」，不许写「大概 / 好像」；找不到就写【未载明】并去邮件问。
2. 指南与实刊不一致时（例如指南写 8,000，近期论文都 9,000），**按更严的执行**，并在 Cover Letter 说明。
3. 字数上限要确认「含不含参考文献、脚注、摘要」—— 同一个 8,000，写作量能差 2,000 字。

投稿系统与字符限制两行前移到这一步核（`11-投递与返修.md` 第二节的教训）：系统名误记会找错入口，100 字符按 100 词写会被系统退回。

## 七、近刊对标：3 篇，四栏

取**近 2 年、同类型**的论文，不取综述与书评；优先开放获取（OA）。这些近刊可由第四·补的 RSS / 静态目次页快速定位线索，再由 AI 取 OA 全文。

| 栏 | 看什么 | 用途 |
|---|---|---|
| 摘要词数 | 实际多少词 | 第 8 步写摘要 |
| 结构惯例 | 有没有独立文献综述 / 理论节；几节 | 第 5 步定章节 |
| 语域与人称 | we / I / 被动；句长 | 第 8 步定人称 |
| 引用条数 | 参考文献多少条 | 第 4 步定取文献量 |

**不要**把近刊当模板照抄结构 —— 只看**惯例**，不看内容。三篇的共性才是惯例，一篇的特例不是。**取指南 + 近刊精读 = 定刊当天做**，都在写正文之前；写完 / 译完才下载近刊，是紧急压缩返工的根源（`C-失败模式库.md` #3）。

## 八、字数契约：从英文上限倒推中文写作量

### 8.1 三档契约（判据所指的「三档」在这里）

| 档 | 组成 | 用途 |
|---|---|---|
| **A · 正文** | 正文（不含摘要、参考文献、表注、附录） | 最低口径，写作时的主目标 |
| **B · +文献 +表注** | A ＋ 参考文献 ＋ 表注 ＋ 图注 | 常见投稿口径 |
| **C · +附录 +声明** | B ＋ 附录 ＋ 声明 | 保守口径（投稿填表用） |

三档都要 ≤ 指南上限，并在 `字数契约.md` 里各写一行实数；换刊时三档全部重算（`11-投递与返修.md` 第七节）。报字数同时报「Word 式」与「逐词」双计数，取两者都达标为准。

### 8.2 折算表

| 场景 | 系数 | 例（上限 8,000 词） |
|---|---|---|
| 学术正文 | ×2.0 | 中文 1.4–1.6 万字（留 10% 余量） |
| 摘要 | ×0.6 | 200 词 ≈ 330 字 |
| 含 / 不含参考文献 | 差 1,700–2,000 字 | 同一 8,000 词，中文写作量差约 2,000 字 |

系数取 2.0 不是 1.6：中文学术句的信息密度低于英文，按 1.6 折算，写完译出来会短一截，只能靠加废话补。**系数是实测估算，每篇按自己的稿子校准一次，不沿用固定值。**

### 8.3 按节分配

| 节 | 占比 | 中文上限（以 1.5 万字计） |
|---|---|---|
| 摘要 | 2% | 300 字 |
| 引言 | 16% | 2,400 字 |
| 文献与框架 | 26% | 3,900 字 |
| 材料与方法 | 12% | 1,800 字 |
| 发现 | 22% | 3,300 字 |
| 讨论 | 14% | 2,100 字 |
| 结论 | 8% | 1,200 字 |

合计 100%。概念型可把「材料与方法」并入「发现」，占比不变；**没有独立文献综述节的刊**，把「文献与框架」并进引言，占比也不变。摘要按目标刊 **200 词 ≈ 330 字**取 300 字，不按正文比例给 —— 按比例给会写出 750 字的摘要，译成英文 450 词，超目标刊一倍。

占比按近刊对标的实际结构微调；调完写进 `字数契约.md`，并登记到 `00-锚点.md`。字数契约一旦写进锚点，第 6 步不许「边写边超」。超 15% 就回这一步重算或换刊，不在第 6 步硬砍 —— 硬砍砍掉的通常是证据，不是废话。
