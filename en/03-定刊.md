# 第 3 步・定刊：前提、双路径、池与顺位、指南、近刊、字数契约

> **一句话**
>
> ：先确认 "这本刊会不会收这种稿"，再让它的硬约束倒推你的字数和结构。
> **输入**
>
> ：选题卡（题目、类型、关键词、Q4 谁在乎）、术语表
> **产出**
>
> ：
>
> `03-定刊/`
>
>  六件：筛选前提、候选池、顺位表、指南硬约束、近刊对标、字数契约
> **耗时**
>
> ：3–5 天
> **判据**
>
> ：每刊有匹配原句；指南每条可指第几段；三档字数 ≤ 上限；中文换算留 10%



***

## 一、七项前提（任一为 "否"，换刊，不改稿）



| # | 前提       | 怎么查（没有机构库也能查）                    | 通过标准                          |
| - | -------- | -------------------------------- | ----------------------------- |
| 1 | **学科归属** | 期刊官网 Aims & Scope                | 能抄出一句含你关键词的原句                 |
| 2 | **近作**   | Crossref 按 ISSN 拉近两年题录（见三），题名人工过 | 近 2 年 ≥3 篇同主题                 |
| 3 | **类型**   | 同上，看题名里的类型词（概念 / 比较 / 对策 / 调查）   | 有同类型先例（概念 / 比较 / 对策 / 小调查）    |
| 4 | **语境**   | Aims 与投稿说明                       | 收中国 / 东亚单国案例；明确 "不收单国案例" 的，排除 |
| 5 | **方法**   | 近三年论文的方法段（只看标题与摘要）               | 收你这类证据（政策文本、小样本、案例）           |
| 6 | **容量**   | 字数上限 vs 你的最小单元                   | 上限装得下：中文换算后不超 1.1 倍           |
| 7 | **门槛**   | 投稿说明                             | 非邀稿；APC 能承担；语言要求可达到           |

**一条否决**：第 3 项找不到同类型先例，不是改标题能解决的 —— 这本刊不收这种稿。



***

## 二、双路径：两类论文，两条找刊路



|      | 甲类：累积型                       | 乙类：材料型               |
| ---- | ---------------------------- | -------------------- |
| 起点   | 已有判断链或在研项目                   | 一批自己的材料              |
| 检索词  | **框架词**：机制、维度、条件的英文表达        | **对象词**：对象 + 政策 + 地域 |
| 先做什么 | 先用选题卡的判断链（准框架）找刊；完整结构留到第 5 步 | 先定刊，再按刊调框架           |
| 风险   | 学科归属错（投到不认这个框架的刊）            | 材料太多，字数删不掉           |

两条路走**同一张候选池**，只是检索词不同。甲类用 3–5 个框架词组合；乙类用 "对象 + 政策工具 + 地域" 三词组合。



***

## 三、候选池：只留能投的，8–12 本

**来源**（按可靠性排序）：



1. 期刊官网 Aims & Scope 与近两年目录；

2. **Crossref API 批量拉题录**（见下，找刊阶段最省时间的一步）；

3. Google Scholar `site:期刊域名 关键词`；

4. 你手上文献的参考文献里反复出现的刊；

5. 出版社的 journal finder（只作参考，不作依据）。

### 用 Crossref 批量核刊（最省时间的一步）

Crossref 有公开 API，按 ISSN 一次拉出近两年全部题录，不用机构库、不用翻页：



```
https://api.crossref.org/journals/{ISSN}/works?filter=from-pub-date:2024-01-01&rows=100&select=DOI,title,published,abstract
```



* `{ISSN}` 填目标刊的 **online ISSN**（官网 About 页有；两个 ISSN 时用电子版那个）；

* 返回的 `total-results` 是该刊近两年**总量**，先看规模；`title` 用来数 "同题数" 和 "类型先例"；

* `abstract` 很多出版社不给；给了也常是带 JATS 标签的 XML，去掉标签再看；没有就用题名判断 "对象 + 问题"，别停在这里找全文；

* 想再窄一点加 `&query.title=关键词`，但这是模糊匹配，**只能粗筛、不能当精确计数**—— 最终人工过前 20–30 条题名；

* 要翻页，首个请求加 `cursor=*`，再把返回的 `next-cursor` 填回 `cursor=`；别用 `offset`（深翻页会漏）；

* Crossref 只给元数据，**不给影响因子、分区、审稿周期**—— 这三项回官网看。

> 一个 ISSN 打错，拉回来的是另一本刊的题录。先在官网核对刊名，再复制 ISSN。

**每刊一行，六列**：



| 刊名 | 学科   | 近 2 年同题数 | 类型先例   | 匹配原句（Aims 里那句）                                 | 结论       |
| -- | ---- | -------- | ------ | ---------------------------------------------- | -------- |
| …  | 公共政策 | 4        | 有（概念型） | "…local governance and policy implementation…" | 可投       |
| …  | 区域研究 | 2        | 无      | "…comparative area studies…"                   | 排除（不收单国） |

**池子规则**：



* 8–12 本，不追求全；列 30 本等于没筛；

* 每刊必须有 "匹配原句"，抄原话，不写 "感觉合适"；

* 排除的也要留一行，写清为什么排除 —— 换刊时不再重查。

## 四、顺位表：A / B / C



| 档     | 含义      | 数量   |
| ----- | ------- | ---- |
| **A** | 现在投     | ≤3 本 |
| **B** | A 拒了转   | ≤3 本 |
| **C** | 备选 / 观察 | 其余   |

**排序依据**（依次比，前者优先）：



1. 匹配度（Aims 原句与你的关键词重合多少）；

2. 类型先例（近三年有没有同类型）；

3. 字数余量（你的中文换算后离上限多远）；

4. 审稿周期（官网或近期论文的 received–accepted 间隔）；

5. APC 与门槛。

写一句 "**为什么 A 在第一位**"。换刊时重排，不复制旧表 —— 旧表的排序理由对新刊不成立。



***

## 五、指南硬约束：只摘数字与硬要求

读作者指南的方法：机翻 + 只找**数字**与 **must / should**，其余不读。



| 项            | 要求                       | 位置（第几段） |
| ------------ | ------------------------ | ------- |
| 字数上限         | 8,000 words（含 / 不含参考文献？） | 第 2 段   |
| 摘要           | 200 words，结构化 / 非结构化     | 第 3 段   |
| 标题           | ≤15 words                | 第 3 段   |
| 关键词          | 4–6 个                    | 第 3 段   |
| 图表           | ≤6 个，分辨率 ≥300dpi         | 第 5 段   |
| 参考文献         | APA 7 / 作者 - 年；≤60 条     | 第 6 段   |
| 匿名           | 正文与文件属性均匿名               | 第 7 段   |
| AI 声明        | 是否要求、放在哪                 | 第 8 段   |
| 数据可用性        | 是否要求声明                   | 第 8 段   |
| Cover Letter | 是否要求、写什么                 | 第 9 段   |
| 补充材料         | 是否允许、格式                  | 第 10 段  |

**三条规则**：



1. 每条标 "第几段"，不许写 "大概 / 好像"；找不到就写【未载明】并去邮件问。

2. 指南与实刊不一致时（例如指南写 8,000，近期论文都 9,000），**按更严的执行**，并在 Cover Letter 说明。

3. 字数上限要确认 "含不含参考文献、脚注、摘要"—— 同一个 8,000，写作量能差 2,000 字。



***

## 六、近刊对标：3 篇，四栏

取**近 2 年、同类型**的论文，不取综述与书评。



| 栏     | 看什么                | 用途         |
| ----- | ------------------ | ---------- |
| 摘要词数  | 实际多少词              | 第 8 步写摘要   |
| 结构惯例  | 有没有独立文献综述 / 理论节；几节 | 第 5 步定章节   |
| 语域与人称 | we / I / 被动；句长     | 第 8 步定人称   |
| 引用条数  | 参考文献多少条            | 第 4 步定取文献量 |

**不要**把近刊当模板照抄结构 —— 只看**惯例**，不看内容。三篇的共性才是惯例，一篇的特例不是。



***

## 七、字数契约：从英文上限倒推中文写作量

### 1. 折算表



| 场景         | 系数              | 例（上限 8,000 词）              |
| ---------- | --------------- | -------------------------- |
| 学术正文       | ×2.0            | 中文 1.4–1.6 万字（留 10% 余量）    |
| 摘要         | ×0.6            | 200 词 ≈ 330 字              |
| 含 / 不含参考文献 | 差 1,700–2,000 字 | 同一 8,000 词，中文写作量差约 2,000 字 |

系数取 2.0 不是 1.6：中文学术句的信息密度低于英文，按 1.6 折算，写完译出来会短一截，只能靠加废话补。

### 2. 按节分配



| 节     | 占比  | 中文上限（以 1.5 万字计） |
| ----- | --- | --------------- |
| 摘要    | 2%  | 300 字           |
| 引言    | 16% | 2,400 字         |
| 文献与框架 | 26% | 3,900 字         |
| 材料与方法 | 12% | 1,800 字         |
| 发现    | 22% | 3,300 字         |
| 讨论    | 14% | 2,100 字         |
| 结论    | 8%  | 1,200 字         |

合计 100%。**概念型**可把"材料与方法"并入"发现"，占比不变；**没有独立文献综述节的刊**，把"文献与框架"并进引言，占比也不变。

摘要按目标刊 **200 词 ≈ 330 字**取 300 字，不按正文比例给——按比例给会写出 750 字的摘要，译成英文 450 词，超目标刊一倍。

占比按近刊对标的实际结构微调；调完写进 `字数契约.md`，并登记到 `00-锚点.md`。

### 3. 冻结

字数契约一旦写进锚点，第 6 步不许 "边写边超"。超 15% 就回这一步重算或换刊，不在第 6 步硬砍 —— 硬砍砍掉的通常是证据，不是废话。

## 八、判据



* [ ] 七项前提逐条有结论（可 / 不可 / 待问）；

* [ ] 候选池 8–12 本，每刊有 "匹配原句"；

* [ ] 顺位表 A ≤3 本，有一句 "为什么 A 第一"；

* [ ] 指南硬约束每条能指到第几段，字数口径（含不含参考文献）已确认；

* [ ] 近刊对标四栏都有数据，样本是近 2 年同类型；

* [ ] 字数契约三档 ≤ 上限，中文留 10%，每节有上限。

## 九、三条坑



| 症状          | 动作                                         |
| ----------- | ------------------------------------------ |
| 摘要按记忆写      | 先查近刊均值。真实代价：自写 191 词，目标刊均值 168，只能压到 177 硬塞 |
| 关键词数量不查     | 指南常写 4–6 个；写 8 个会被系统退回或编辑手改                |

## 十、交给第 4 步什么



* **目标刊**（A 档第一本）与 B/C 备选；

* **指南硬约束**：字数上限及口径、摘要词数、图表数、引用风格；

* **近刊对标**：结构惯例、语域与人称、引用条数；

* **字数契约**：每节中文上限；

* **关键词**（中英），第 4 步检索与第 9 步元数据都要用。

第 4 步不再改刊。要换刊，回这一步重跑七项前提 ——**不要在写作中途换刊**，那是整篇返工。
