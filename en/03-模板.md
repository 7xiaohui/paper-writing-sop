# 表 2 · 文献卡（一行一篇）

| 编号 | 作者(年) | 它研究什么 | 它主张什么 | 概念工具 | 证据类型 | 用途 | 我能用它干什么 | 拟引句 | 强度 |
|---|---|---|---|---|---|---|---|---|---|
| L01 |  |  |  |  |  | 定义/机制/情境/方法/政策/反例 |  |  | 全文/摘要/题录 |
| L02 |  |  |  |  |  |  |  |  |  |

**填法**：后四列最重要。

- **用途**：决定它进哪一组；
- **我能用它干什么**：支持 / 对照 / 反驳；
- **拟引句**：**写不出来 = 这篇对你没用，删**；
- **强度**：决定你能写 "proves" 还是只能写 "suggests"。

**强度与措辞对照**：全文→"X 证明/显示"；摘要→"X 认为/提示"；题录→**不许引**。

| R1.2 |  |  |  |  |  |  |

**处理三式**：

| 式 | 措辞 | 用于 |
|---|---|---|
| 承认 + 限定 | "We agree that X is a limitation; we have therefore added…" | 意见部分成立 |
| 证据 + 异议 | "We respectfully note that… (evidence). We have clarified this in…" | 审稿人读错 |

# 表 12 · 材料与数字台账（防编数据）

| 编号 | 事实/数字（原句） | 类型 | 来源（文件全称+文号/版本+页） | 时间 | 可得性 | 用在哪 |
|---|---|---|---|---|---|---|
| M01 | 例：X 产值 __ 亿元 | 统计数据 |  |  | 全文/摘要/二手 | 第 X 节 |

**三条铁律**：
1. **任何进论文的数字，必须能说出"分子是什么、分母是什么、出自哪一栏/哪张表"**；算不出来的数字不许进论文；
2. 同一个数字只在本表登记一次，正文只引用，不重算；
3. 二手转述的数字必须标"二手"，并在正文用"据…转引"措辞，不得当一手。

**非实证声明（若本文不是实证研究，摘要或方法处必须有一句）**：

```
本文为理论推演/文献分析，不含问卷、访谈或实验数据；所用材料限于公开文本与已发表统计。
```
> 这句话必须与正文实际材料一致。写了"非实证"却出现"本研究发现 62% 的受访者"，等于自证造假（`07` #53）。

| 编号 | 日期 | 来源（自审批次/审稿人编号） | 问题 | 等级 | 动作 | 位置（节/段） | 受影响文件 | 回勾 | 状态 |
|---|---|---|---|---|---|---|---|---|---|
| C01 |  | 批次01 / R1.2 |  | 致命/重要/次要 | 已改/部分改/未改 |  | 摘要、结论、表3 | ☐ | 开放/关闭 |

**为什么要"受影响文件"这一列**：改一处会连锁（编号、数字、摘要、结论、图表引用、英文对应段）。**列出受影响文件并逐个回勾**，是唯一能防"改了这处忘了那处"的办法。

**判据**：状态为"开放"的行 = 0，才能进下一步。

# 表 14 · 版本与决策记录（单一事实源）

| 日期 | 决策/版本 | 内容 | 受影响文件 | 已同步 | 依据 |
|---|---|---|---|---|---|
|  | v1.0 → v1.1 | 例：主攻刊由 A 改为 B | 表 5、表 9、字数契约、摘要 | ☐ |  |

**三条规矩**：
- **一切数字回成品文件数**，日记、聊天、记忆都不算证据；
- 决策一落，立刻写"受影响文件"，否则下游永远不知道（真实病例：主攻刊换了、概念弃用了、主体数 48/50/55 三个值并存）；
- 文件名带状态后缀：`_working` / `_submitted` / `_R1`，不许叫"投稿稿"却已不是最终版。
