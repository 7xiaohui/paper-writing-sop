# 检查清单（打印出来，照着勾）

> 四张：**文献四查**（第 4 步末）、**译文五查**（第 7 步末）、**交稿前两查**（第 8 步初）、**投稿前四查**（第 9 步初），后附**成稿十八项终检**。
> 规则：**改过就重跑。** 不重跑 = 没查。

---

# 一、文献四查（第 4 步末，**串行，不许并**）

> **四查的关系**：查一查二防"假"，查三防"多或少"，查四防"歪"。
> **串行纪律**：上一查没过，不许开下一查；四查共用一个会话，出来的结论一定互相迁就。

---

## 查一 · 真不真（存在 + 字段）——**三档判定，不做二值**

### 1-0 先分档（决定核不核）

| 档 | 来源 | 处理 |
|---|---|---|
| **甲档** | 本人从数据库/期刊官网导出的题录（字段齐全） | 视为可信，只做格式规范化，**不另找来源推翻** |
| **乙档** | AI / 他人联网检索回填 | 必须核，且必须披露渠道、检索式、命中页、检索时间；未经作者确认，结论最高写"待用户核" |

> 分档不明归乙档。宁可多披露一次，不可把检索所得冒充自己的题录。

### 1-1 渠道（英文线以 Crossref 为核心）

| 渠道 | 定位 | 注意 |
|---|---|---|
| **Crossref** | 核心比对源，**DOI 优先解析** | — |
| 期刊官网 / 出版商页 | 权威兜底 | 目标刊当期目录优先级最高 |
| Scopus 公开页 | 免费题录摘要 | 不需机构订阅 |
| Google Scholar | 辅助兜底 | **不能推翻 Crossref 结果** |
| arXiv | 预印本独立核 | Crossref 常不收录预印本 |

> **中国注册的 DOI 走 doi.org 会重定向到 chndoi.org，属正常，不是错误。** 这一条被误判过。

### 1-2 三档判定

| 档 | 判据 | 动作 |
|---|---|---|
| **可信** | 2 个及以上独立权威源，核心字段（作者/题名/刊名/年份/卷期）一致 | 通过。**著录格式差异不算事实错误**（有无卷号、页码取舍、标点全半角） |
| **存疑** | 仅单一弱源可检出；权威源之间冲突；增刊/内刊/早期未数字化；预印本、学位论文、小众专著、会议摘要、灰色文献 | **降级使用 + 人工核**，不删 |
| **疑似伪造** | 全渠道检索不到 **且** 刊名或刊号不存在 / 年份早于创刊 / 卷期页码违背常理 | 人工确认后删 |

> 🔴 **查不到 ≠ 伪造。** 英文线上老文献、预印本、会议摘要、小众专著"查不到"是常态。用二值判断（查到/查不到）会把正常文献误杀一半。

### 1-3 字段与页码

- [ ] 作者 / 年份 / 标题 / 期刊 / 卷 / 期 / 页 / DOI 逐项与实体一致
- [ ] DOI **实测可解析**（不是"看着对"）
- [ ] 他人标题里的异体拼写**保留不改**（改引文 = 篡改）
- [ ] 自引年份后缀（2024a/b/c）有**真值表**（哪一条对应哪篇合作），不混
- [ ] **页码以 PDF 页脚 / 文章编号 / 官方题录为准，禁止按位置估算**，不得把阅读器页码当刊页
- [ ] 取不到页码的写 `【待补页码】` 并记补核路径

## 查二 · 对不对（题录闭合，**交给脚本**）

- [ ] 跑 `工具/scripts/check_refs.py`，贴输出（不贴 = 没查）
- [ ] 正向：正文每条引用，文献表都有条目（悬空引用 = 0）
- [ ] 反向：文献表每条，正文至少引用一次（冗余文献 = 0）
- [ ] 同一文献在正文出现 ≤ 3 次（超过说明靠它撑全场）
- [ ] 同句重复标引、跳号、编号重复 = 0
- [ ] **条数对账**：实际条数 ____ vs 选题阶段承诺区间 ____–____；低于下限须写理由
- [ ] **不引清单**已建：明确写出"这篇最多引 1 次""这一系列一律不引"，防文献表臃肿

> 脚本是保守判法（宁可漏报），报告里的"疑似未引用"仍需逐条搜姓氏人工确认。**不要让 AI"数一遍"**。

## 查三 · 该不该（语义）——**L1/L2 分层，另开会话**

### 3-0 相关性红线（先看四条，再看语义）

- [ ] 每条文献能说出"它跟本文哪个论点有关"；说不出的删（**离题文献比缺文献更伤**）
- [ ] 中文文献占 **10–15%**（能证明"中国学界怎么看"，不能证明"国际学界怎么看"）
- [ ] 没有"（A, 2020; B, 2021; C, 2022）"三连堆撑一句常识
- [ ] 没有拿读不懂的文献撑核心论点（最危险的一类）

### 3-1 L1 摘要级初筛（全部引用）

- [ ] 每条引用给【匹配良好】/【疑似错配】+ 置信度（高/中/低）
- [ ] 错配的写清类型：主题偏离 / 层级错位 / 删了原文的限定条件 / 把综述当实证

### 3-2 L2 全文级复核（只打高风险）

- [ ] L1 中低置信度的引用，逐条回原文定位比对
- [ ] 涉及**关键数据、方法、定义**的引用，不论置信度一律 L2
- [ ] 判定只用三档：支撑成立 / 支撑不足 / 明显不支撑
- [ ] 拿不到全文的停在 L1，标"人工复核"（**不许硬判**）

### 3-3 补检甲 · 无编号转述扫描（**漏引的唯一防线**）

- [ ] 用转述词表机械筛出"含转述却无引用"的句子（`argues / notes / proposes / finds / shows / reports / according to / scholars / existing research / 有学者 / 学界 / 据统计 / 相关研究`）
- [ ] 逐句判：是转述（→ 补引并占号）还是作者自述（→ 写理由放行）
- [ ] **凡正文引述文献，不论是否承担论证，一律占号进表**；转述型与论点型共用同一套编号

### 3-4 补检乙 · 引号内容审计（**清稿前必做**）

- [ ] 全文引号（中文 “”‘’ + 英文 "" ''）逐处归类，只许三类：①文献原文直引 ②自建概念 ③政策/材料原文
- [ ] 出三列表：引号内容 | 类型 | 出处；并给各类处数与字数
- [ ] 算**直引占正文比例**（分子=直引字数，分母=正文字数，不含文献表；口径写出来）
- [ ] **直引 = 0 → 不得进清稿**；目标 **1%–5%**；**>10% 必压**（先压背景、意义、保障措施，不动核心论证）
- [ ] "加引号但不是原话"的，逐条改成原文或去引号改转述
- [ ] 补引**只从现有文献表里挑**，不新增条目

### 3-5 冲突汇总（三查合并后按风险处理）

| 组合 | 等级 | 处理 |
|---|---|---|
| 疑似伪造 **且** 正文引用 | 最高 | 人工优先核，必要时删改 |
| 存疑 **且** 正文引用 | 高 | 人工核真实性后再定 |
| 悬空引用 / 冗余文献 | 中 | 修标号（脚本可定位） |
| 低置信度引用 | 中 | 进 L2 |
| 直引为 0 / 含改写引号 | 中 | 清稿前补或改 |

**判据**：四查全过，且每条文献都有结论（可信/存疑/疑似伪造/待用户核）+ 核验来源。**未引用 = 0；离题 = 0；疑似伪造 = 0。**

# 二、译文五查（第 7 步）

### 查一 · 术语

- [ ] 术语表里的词 100% 照表（不自创）
- [ ] 同一概念全篇一个译法
- [ ] 禁用词 = 0
- [ ] 拼写体系统一（英式 / 美式，他人标题除外）

### 查二 · 回译

- [ ] 抽 10 段英→中回译，语义漂移 = 0
- [ ] 中文的模糊处没有被"顺手写通顺"（改了就标出来给作者）

### 查三 · 数字

- [ ] 英文数字与中文 100% 一致（含百分比、倍数、样本量）
- [ ] 每个数字能复算（分子 / 分母 / 来源）

### 查四 · 格式

- [ ] 摘要词数 ≤ 近刊样本最大值
- [ ] 关键词个数符合指南
- [ ] 标题 / 小标题层级与指南一致
- [ ] 引用体例统一

### 查五 · 通畅

- [ ] 抽读 3 段，无翻译腔（"play an important role in"类）
- [ ] 一句不超过 40 词
- [ ] 主动句 ≥ 50%
- [ ] 人称唯一（this study / this paper / I，不混用；单作者不出现 we）

**判据**：五查全过。**不过不进第 8 步。**

# 三、交稿前两查（第 8 步）

### 查一 · 工作痕迹（六类，必须是 0）

- [ ] 待定/中间态：回填、待补、待核、TBD、XXX、存疑
- [ ] 内部工作语：本稿暂、另列、供核对、投稿时删除
- [ ] 投稿策略：主攻、备选、保底、冲刺（**不许向期刊暴露备选刊策略**）
- [ ] 版本尾注：v9.8、修订说明、变更记录
- [ ] 回迁/编辑过程语："已按要求回迁""原附录撤销"
- [ ] 审稿痕迹：审稿人模拟、意见已落地、第 X 批

### 查二 · 学术声明（五类，必须还在）

- [ ] 审慎声明（"本文不主张…""须说明…"）
- [ ] 方法说明（抽样、口径）
- [ ] 附录导读 / 数据可用性 / 补充材料指引
- [ ] 工作稿专属记录**只在工作稿**，投稿稿为 0
- [ ] 匿名化没有误删附录 / 参考文献 / 图表

> **判定心法**：这句话是写给**读者**看的，还是写给**我们自己**看的？写给读者 → 留；写给自己 → 删。

# 四、投稿前四查（第 9 步）

### 甲 · 内容层

- [ ] 重跑"交稿前两查"（翻译和排版可能重新引入痕迹）
- [ ] 工作稿 / 投稿稿分层正确

### 乙 · 文件层

- [ ] docx 无生成器名 / 生成器日期 / 缩略图
- [ ] 无修订痕迹 / 批注 / 人员信息
- [ ] 图片已去 EXIF
- [ ] **四份文件都能正常打开**（清完必开）

### 丙 · 作者信息

- [ ] 姓名用字与投稿系统一致
- [ ] **机构英文名 = 官方规定名**（查章程 / 科研处文件，不查百科）
- [ ] ORCID 可解析
- [ ] 基金名称与编号与立项文件逐字一致
- [ ] 匿名稿：姓名/单位/致谢/基金/邮箱/ORCID = 0 处
- [ ] 匿名前后词数差 ≈ 被删身份信息的词数（防止误删正文）

### 丁 · 事实层

- [ ] DOI 全部实测可解析
- [ ] 摘要词数实测 ≤ 上限
- [ ] **字符限制字段**（标题／running head／推广摘要／tweet）按系统单位实测 ≤ 上限
- [ ] 关键词数符合
- [ ] AI 声明与刊型匹配（详述 / 声明 / 禁止）
- [ ] 利益冲突声明（无也要写"无"）
- [ ] 数据可用性声明
- [ ] Cover Letter：日期、期刊名、主编姓名正确
- [ ] 主题分类已选

# 五、成稿十八项终检（并入"丁"，逐项机械查）

> 这十八项都是**能数出来**的，能脚本化的先脚本，不能的照单勾。
> 前十四项管"一致性"，后四项管"防线在不在"。

| # | 查什么 | 判据 |
|---|---|---|
| 1 | 摘要词数 | ≤ 近刊最大值 |
| 2 | **标题 ↔ 摘要 ↔ 正文 ↔ 结论 四处数字/发现数/承诺** | 完全一致；标题每个名词承诺都有落点 |
| 3 | **结论总起句唯一** | 计数 = 1（不许两段各来一次"以下三点结论"） |
| 4 | 人称唯一 | 单作者不出现 we |
| 5 | 交叉引用自洽 | 有 "Section X" 就必须有编号；否则改 |
| 6 | **摘要里每个概念，正文有落点** | 0 个悬空概念 |
| 7 | 缺口 ↔ 发现 ↔ 结论 三处编号对应 | 一一闭合 |
| 8 | 术语一致 | 脚本 0 命中 |
| 9 | 文献四查 | 全过（三档判定 + 脚本闭合 + 语义分层） |
| 10 | 中英摘要/标题/关键词同译 | 词数与关键句对应 |
| 11 | 外观：整段加粗 = 0；脚注是真脚注；图注齐全 | 0 例外 |
| 12 | AI 披露位置唯一且口径一致 | 只出现在声明段 |
| 13 | **字符限制字段**（标题／running head／推广摘要／tweet） | 按系统单位数：character 含空格；word 才数词 |
| 14 | **数据-主张覆盖率** | 凡"全量／所有"主张，覆盖率 100%，或已改口径 |
| 15 | **段落型分布** | 论证/描述/推演各占多少段；**描述段无料评价 = 0**；描述段每段至少 1 条材料 |
| 16 | **命题处置闭合** | `03` 表 11 每条命题都有处置，"改/限定/补"的已落地，状态全"关闭" |
| 17 | **引号审计** | 直引占正文 1%–5%；含改写引号 = 0；三类归类齐全 |
| 18 | **中英同步** | 中文改动英文都有；英文只动语言层；docx 由真源生成，无手改 |

**执行时点**：

```
去痕迹后   → 3、4、5、10、12
译完后     → 1、2、6、7、8、10、17、18
导出后     → 9、11、12、15，再全部复跑
投稿前     → 全部复跑（含 16）
```
