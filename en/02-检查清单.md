# 检查清单（打印出来，照着勾）

> 四张：**文献四查**（第 4 步末）、**译文五查**（第 7 步末）、**交稿前两查**（第 8 步初）、**投稿前四查**（第 9 步初）。
> 规则：**改过就重跑。** 不重跑 = 没查。

---

# 一、文献四查（第 4 步）

> 前两查防"假"，后两查防"多余"。

### 查一 · 真不真（存在）

- [ ] 每条都有实体证据（PDF / 知网导出 / 官网页面）
- [ ] DOI 实测能打开（国际 DOI 走 Crossref；中国 DOI 走 doi.org，重定向 chndoi.org 属正常）
- [ ] 查不到的已删除（不硬凑、不"待补"）

### 查二 · 对不对（字段）

- [ ] 作者 / 年份 / 标题 / 期刊 / 卷 / 期 / 页 / DOI 逐项与实体一致
- [ ] 中文文献以知网官方导出为准
- [ ] 他人标题里的异体拼写**保留不改**（改引文 = 篡改）
- [ ] 自引年份后缀（2024a/b/c）有真值表，不混

### 查三 · 引没引（闭合）

- [ ] 正文每条引用，文献表都有条目
- [ ] 文献表每条，正文至少引用一次（**未引用的删**）
- [ ] 同一文献在正文出现 ≤ 3 次（超过说明靠它撑全场）

### 查四 · 该不该（相关性）

- [ ] 每条文献能说出"它跟本文哪个论点有关"
- [ ] 说不出的**删**（离题文献比缺文献更伤）
- [ ] 中文文献占 10–15%
- [ ] 没有"（A, 2020; B, 2021; C, 2022）"三连堆撑一句常识

**判据**：四查全过；未引用 = 0；离题 = 0。

---

# 二、译文五查（第 7 步）

### 查一 · 术语

- [ ] 术语表里的词 100% 照表（不自创）
- [ ] 同一概念全篇一个译法
- [ ] 禁用词 = 0
- [ ] 拼写体系统一（英式 / 美式，他人标题除外）

### 查二 · 回译

- [ ] 抽 10 段英→中回译，语义漂移 = 0
- [ ] 中文的模糊处没有被"顺手写通顺"（改了就标出来给作者）

### 查三 · 数字

- [ ] 英文数字与中文 100% 一致（含百分比、倍数、样本量）
- [ ] 每个数字能复算（分子 / 分母 / 来源）

### 查四 · 格式

- [ ] 摘要词数 ≤ 近刊样本最大值
- [ ] 关键词个数符合指南
- [ ] 标题 / 小标题层级与指南一致
- [ ] 引用体例统一

### 查五 · 通畅

- [ ] 抽读 3 段，无翻译腔（"play an important role in"类）
- [ ] 一句不超过 40 词
- [ ] 主动句 ≥ 50%
- [ ] 人称唯一（this study / this paper / I，不混用；单作者不出现 we）

**判据**：五查全过。**不过不进第 8 步。**

---

# 三、交稿前两查（第 8 步）

### 查一 · 工作痕迹（六类，必须是 0）

- [ ] 待定/中间态：回填、待补、待核、TBD、XXX、存疑
- [ ] 内部工作语：本稿暂、另列、供核对、投稿时删除
- [ ] 投稿策略：主攻、备选、保底、冲刺（**不许向期刊暴露备选刊策略**）
- [ ] 版本尾注：v9.8、修订说明、变更记录
- [ ] 回迁/编辑过程语："已按要求回迁""原附录撤销"
- [ ] 审稿痕迹：审稿人模拟、意见已落地、第 X 批

### 查二 · 学术声明（五类，必须还在）

- [ ] 审慎声明（"本文不主张…""须说明…"）
- [ ] 方法说明（抽样、口径）
- [ ] 附录导读 / 数据可用性 / 补充材料指引
- [ ] 工作稿专属记录**只在工作稿**，投稿稿为 0
- [ ] 匿名化没有误删附录 / 参考文献 / 图表

> **判定心法**：这句话是写给**读者**看的，还是写给**我们自己**看的？写给读者 → 留；写给自己 → 删。

---

# 四、投稿前四查（第 9 步）

### 甲 · 内容层

- [ ] 重跑"交稿前两查"（翻译和排版可能重新引入痕迹）
- [ ] 工作稿 / 投稿稿分层正确

### 乙 · 文件层

- [ ] docx 无生成器名 / 生成器日期 / 缩略图
- [ ] 无修订痕迹 / 批注 / 人员信息
- [ ] 图片已去 EXIF
- [ ] **四份文件都能正常打开**（清完必开）

### 丙 · 作者信息

- [ ] 姓名用字与投稿系统一致
- [ ] **机构英文名 = 官方规定名**（查章程 / 科研处文件，不查百科）
- [ ] ORCID 可解析
- [ ] 基金名称与编号与立项文件逐字一致
- [ ] 匿名稿：姓名/单位/致谢/基金/邮箱/ORCID = 0 处
- [ ] 匿名前后词数差 ≈ 被删身份信息的词数（防止误删正文）

### 丁 · 事实层

- [ ] DOI 全部实测可解析
- [ ] 摘要词数实测 ≤ 上限
- [ ] 关键词数符合
- [ ] AI 声明与刊型匹配（详述 / 声明 / 禁止）
- [ ] 利益冲突声明（无也要写"无"）
- [ ] 数据可用性声明
- [ ] Cover Letter：日期、期刊名、主编姓名正确
- [ ] 主题分类已选

# 五、成稿十二项终检（并入"丁"，逐项机械查）

> 这十二项都是**能数出来**的，能脚本化的先脚本，不能的照单勾。

| # | 查什么 | 判据 |
|---|---|---|
| 1 | 摘要词数 | ≤ 近刊最大值 |
| 2 | **摘要 ↔ 正文 ↔ 结论 三处数字/发现数** | 完全一致 |
| 3 | **结论总起句唯一** | 计数 = 1（不许两段各来一次"以下三点结论"） |
| 4 | 人称唯一 | 单作者不出现 we |
| 5 | 交叉引用自洽 | 有 "Section X" 就必须有编号；否则改 |
| 6 | **摘要里每个概念，正文有落点** | 0 个悬空概念 |
| 7 | 缺口 ↔ 发现 ↔ 结论 三处编号对应 | 一一闭合 |
| 8 | 术语一致 | 脚本 0 命中 |
| 9 | 文献四查 | 全过 |
| 10 | 中英摘要/标题/关键词同译 | 词数与关键句对应 |
| 11 | 外观：整段加粗 = 0；脚注是真脚注；图注齐全 | 0 例外 |
| 12 | AI 披露位置唯一且口径一致 | 只出现在声明段 |

**执行时点**：

```
去痕迹后   → 3、4、5、10、12
译完后     → 1、2、6、7、8、10
导出后     → 9、11、12，再全部复跑
投稿前     → 全部复跑
```

```
投稿：内容 → 文件 → 作者 → 事实（含十二项）
```
