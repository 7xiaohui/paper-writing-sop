# 英文论文写作 SOP（SSCI · 九步）

> **给谁用**：中文母语、英文不强、没有机构库的独立研究者。论文多为概念型、比较型、对策型，或少量调查 / 平台数据。
> **解决什么**：不教你英语，也不替你写论文。它解决的是**一篇英文论文从「有个方向」到「返修回来」，中途不脱轨**。
> **不解决什么**：不保证录用。决定录用的是选题与证据，不是方法。

> 本目录是 [`paper-writing-sop`](../README.md) 的英文线，可单独使用：在 `en/` 下工作时，文中命令直接可用；在仓库根目录运行时，命令路径前加 `en/`。

## 五分钟上手

1. 读 [`00-总览.md`](00-总览.md) —— 九步各做什么、每次开工用哪份文件。
2. 手上是什么状态，就从哪一步进：

| 你的状态 | 从哪进 | 用哪份 |
|---|---|---|
| 有个方向，不确定能不能写 | 第 1 步 | [`01-主流程.md`](01-主流程.md) §1 |
| 想写，但不知道投哪 | 第 2–3 步 | §2、§3 |
| 要开始找文献，英文读不透 | 第 4 步 | [`04-文献选读法.md`](04-文献选读法.md) |
| 文献有了，不知道怎么下笔 | 第 5–6 步 | [`05-初稿生成法.md`](05-初稿生成法.md) |
| 中文定稿了，要出英文 | 第 7–8 步 | `01` §7、§8 |
| 要投稿 / 被拒 / 要返修 | 第 9 步 | [`06-返修与转投.md`](06-返修与转投.md) |

## 公开版说明

这是个人工作流的公开版，不是产品：

- **不含任何真实论文**。`工具/samples/` 里的稿件是虚构的，只用于验证脚本；
- **不含作者信息**。要生成投稿件，先把 `工具/docx_config.example.txt` 复制为 `工具/docx_config.txt`，再填自己的信息；`docx_config.txt` 已被 `.gitignore` 排除，不会误传；
- **文档与代码分开授权**：文档 CC BY-NC-SA 4.0（禁止商业使用，改编须以同样许可共享），脚本 MIT，见仓库根目录的 [`LICENSE`](../LICENSE) 与 [`LICENSE-docs`](../LICENSE-docs)；
- `05-初稿生成法.md` 里的例子是虚构的（垃圾分类两社区对比），与任何真实论文无关。

## 命名规则（**不再用字母编号**）

旧版有一堆代号：K1–K6、S0–S9、M0–M9、T0–T17、「三闸」「两道关卡」「五道关」。这一版全部取消，只留三种：

| 类型 | 写法 | 例 |
|---|---|---|
| **步骤** | 1–9 | 「第 4 步 读文献」 |
| **动作卡** | 步骤号-序号 | `4-3 三十秒判生死` |
| **检查** | 用「查」字，四查 / 五查 / 两查 | 「文献四查」「译文五查」 |

> **为什么要简化**：代号的好处是短，坏处是**半年后记不住它指什么**。而这份东西是给你自己在半年后用的。
> **不用「闸/关」的理由**：这两个字暗示「过不去就死」，但实际上它们只是检查项，不通过就补，不是审判。所以统一叫「查」。

## 五条铁律（全篇只有五条）

1. **中文是源，英文是派生**。英文稿里不许出现中文稿没有的论点。
2. **没有期刊原文，不许写正文**。硬性要求只认官网《作者指南》。
3. **无靶子不改稿**。禁止「通读一遍提提意见」。
4. **一句话只有一个答案**。同一问题在全仓出现两个结论，等于没有结论。
5. **拿不到全文，不许当核心证据**。拿不到就降级使用，不能硬引。

## 三条使用纪律

- **先删后加**：改这份 SOP 时，先删一条旧的，再加一条新的。只加不删，半年后又回到 6 万字。
- **一个数字一处**：词数、样本数、文献数，只在 `03-模板.md` 的表里算一次，别处只引用。
- **每篇回填三条**：写完一篇，往 `07-失败模式库.md` 加三条（新坑 / 新句式 / 新判据）。不回填，这份东西就停在 v1.0。
