# 英文论文写作 SOP · 11 步（v2 样张）

> **一句话**：不教你英语，也不替你写论文。它保证一篇英文论文从"有个方向"到"返修回来"不脱轨。
> **English**：A gate-based, 11-step workflow for non-native researchers submitting to SSCI/AHCI journals without institutional library access.

---

## 给谁

- 中文母语、英文不强、没有机构库的独立研究者；
- 论文多为**概念型、比较型、对策型**，或少量小调查 / 平台数据；
- 手上已有一篇中文稿，或打算直接写英文。

## 不给谁

- 不保证录用。决定录用的是**选题与证据**，不是流程；
- 不保证"母语级自然"。这套方法能到"清晰、规范、可读"，再往上只有付费母语润色；
- 不适用于大样本实证。统计设计与检验要另配方法书，本流程只保留"数据-主张对账"。

---

## 30 分钟上手

1. 读 [`00-总览.md`](00-总览.md)，看清 11 步与"该停"的信号；
2. 建工作区：

```bash
python E-工具/init_workspace.py ..\paper-01
```

3. 读 [`01-起步.md`](01-起步.md)，填 `00-锚点.md`、`01-起步/术语表.csv`、`01-起步/类型判定.md`；
4. 看进度：

```bash
python E-工具/check_workspace.py ..\paper-01
```

它只回答一件事：**你现在在第几步，下一步缺哪个文件。**

## 六件别处没有的

| # | 是什么 | 解决什么 |
|---|---|---|
| 1 | **目录即进度** | 产物是固定文件名；有文件=做完，缺文件=没做。进度不靠记忆 |
| 2 | **两库编号契约** | 学库 W 与材库 料 从编号到正文标记一一对应，每句话都能回原件 |
| 3 | **清稿关卡在译前** | 中文标记不会被译进英文；清稿只做一次，不重复劳动 |
| 4 | **中英字数折算** | 用英文上限倒推中文写作量，避免"写完再砍两万字" |
| 5 | **换刊解冻** | 换刊后中文改不改、改哪几段、怎么版本化，有规则可循 |
| 6 | **AI 分工与声明** | 每步写清 AI 可做/人必须做/怎么留证/怎么声明，不做规避检测 |
