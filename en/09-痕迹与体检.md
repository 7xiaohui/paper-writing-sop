# 第 9 步 · 痕迹与体检：只改语言层，声明如实写

> **一句话**：把"一眼 AI"的句式改掉，但一个字不改内容；然后按刊物档位如实写使用声明。
> **输入**：`08-英译/英文-v1.md`、`07-清稿/中文-冻结-v1.md`、`03` 的语域与人称惯例、`01` 的合规档位
> **产出**：`09-体检/体检报告.md`（含改写记录、回归记录、AI 使用声明草稿）
> **耗时**：2–4 天
> **判据**：高危句式 0；改写段漂移 0；声明与档位匹配；未使用任何"绕过检测"技巧

---

## 一、先把规矩立在前面

这一步只做两件事：**改语言层**，**写声明**。不做第三件事：

- **不刷检测分数**。任何"AI 检测"分数只作提示，不作判决；把分数当目标，文章会改成没人味也没人读的样子；
- **不教规避技巧**。本仓库不提供任何"绕过检测"的改法。我们做的是**提高原创表达 + 如实披露**——这两件做得对，检测分数自然不是问题；
- **声明写宽不写窄**。用了什么、用在哪、谁负责，照实写。写得比实际使用窄，是隐瞒，不是合规。
- **英文阶段只做复查型，不做发现型**。发现型审稿（找逻辑漏洞、论证缺口、概念层级）只在第 5 步的中文稿做；本步的「体检」只查落地复查、英文专有维度（词数 / 术语 / 拼写 / 长句）与通畅，**不得提「新增论据 / 调整论证结构 / 改结论」这类内容级建议** —— 英文侧打补丁会让中文源头仍是错的，且触发全稿重译。

## 二、高危句式清单（命中即改）

不是所有 AI 痕迹都要清，但下面这一批在英文学术写作里属于"一眼 AI"，命中就改。

| 类 | 典型 | 问题 |
|---|---|---|
| 大词动词 | `delve into`、`navigate`、`leverage`、`harness`、`foster` | 不具体 |
| 抽象名词 | `tapestry`、`landscape`、`realm`、`paradigm` | 空 |
| 套话连接 | `it is important to note`、`it is worth noting`、`in conclusion`（段中重复）、`moreover`、`furthermore` 连用 | 不增加信息 |
| 高调动词 | `shed light on`、`play a pivotal role`、`revolutionize` | 强主张无证据 |
| 万能形容 | `ever-evolving`、`robust`、`seamless`、`holistic` | 可删 |
| 元话语 | `this paper aims to`、`this section will discuss` | 学术写作不需要指路 |
| 人称模糊 | 被动语态叠三层、`one`、`the authors argue that it is argued` | 不清 |

**改法只有一条**：换成具体说法。

- "This paper delves into the governance of X" → 直接写问题："Under X, registration counts rose while actual output fell."
- "plays a pivotal role" → 写出 role 是什么："determines whether a project receives funding."
- "robust dataset" → 写出规模："data from 1,247 projects over eight years."

**中文源侧的 9 类指纹**（若走「中文源」分支，在清稿前先查；提示词卡 `D9b-体检-AI消毒指纹.md`）：

| 指纹 | 检索词 / 特征 | 处理 |
|---|---|---|
| 「不是 A，而是 B」对偶句式 | 「不是 / 而是 / 不仅 / 更是 / 而非 / ≠」 | 改正面陈述或拆句，全文 ≤5 处 |
| 机械枚举 | 「其一 / 其二 / 第一 / 第二」 | 改连贯行文，只留有实质分析的枚举 |
| 破折号「——」 | 连续出现 | 削减；英译会变成大量 em dash |
| 空泛过渡 / 拔高 | 「值得注意的是 / 更关键的是 / 这揭示了」 | 删 |
| 段末强行升华 | 每段最后一句拔高 | 删 |
| 空洞修饰词 | 「系统性 / 根本性 / 极具」 | 改具体限定或删 |
| 修辞性设问连发 | 连续问句 | 研究问题改陈述式 |
| 加粗滥用 | 大量 `**…**` | 只留关键术语首现 |
| 冒号长串并列 / 顿号堆叠 | 一句里四个以上并列 | 改表格或拆分 |

**消毒顺序**：先清对偶句式（收益最高）→ 再清枚举 + 破折号（翻译可行性）→ 最后清过渡句与修饰词。**不写「降 AI 率」承诺**：这里做的是提高原创表达与如实披露，不是规避检测。

**别整段重写**。只改命中的那一句；改完做回归（见第四节）。

## 三、体检三步

### 第 1 步：自检

- 逐节搜第二节清单，命中的记进体检报告：位置、原句、改后句；
- 额外扫三样：连续两个 `Moreover / Furthermore`、句首重复 `However`、一句超过 40 词；
- 不掌握英语也能做：清单是固定词表，搜词，不是赏析。

### 第 2 步：改写（只改语言层）

| 允许改 | 不许改 |
|---|---|
| 句式长短 | 主张（P 号对应的那句话） |
| 连接词 | 数字、年份、样本量 |
| 大词换具体词 | 限定词（多数 / 在……条件下 / may） |
| 被动换主动（按近刊人称惯例） | 引文、术语 |

**人称**：按 `03` 近刊对标的语域写——该刊用 `we` 就用 `we`，用被动就用被动，不自创。

### 第 3 步：回归抽检

每一处改写，回译成中文，与 `中文-冻结-v1.md` 逐句比：

- 主张、范围、条件三者有一处变了 = **漂移**，回退改法，换一种写法；
- 措辞不同不算漂移。

改写 30 段以上的，抽 10 段回归；不足 30 段的，全部回归。记录在体检报告。

## 四、AI 使用声明：按刊型三档写

先看两件事：`01-起步.md` 里登记的 **AI 使用深度**（只润色 / 翻译＋润色 / 生成初稿），以及目标刊的**要求档位**：

| 档位 | 刊物态度 | 你要写什么 |
|---|---|---|
| **详述档** | 要求说明 AI 用途 | 写清：用了什么工具（全名 + 版本号）、用在哪个环节、人做了什么、人对全文全责 |
| **声明档** | 要求一句话声明 | 一句话："本稿在写作过程中使用了 AI 辅助翻译与语言校对，作者对全部内容负责。" |
| **禁止档** | 不允许使用 | 那 `08` 的 AI 翻译成果必须人工重写或换用不违规的工具，并在体检报告里写明怎么处理的 |

声明**中英两版都写**（英文投稿用英文版，中文版留档）：

```text
中文（留档）：本稿使用 AI 工具进行辅助翻译与语言校对。
所有学术主张、证据与结论均由作者本人确定并负责。
工具与版本：【全名 + 版本号】。用途：【辅助翻译 / 语言润色 / 文献整理】。
```

```text
English (submission): This manuscript used AI assistance for translation and
language proofreading. The author is solely responsible for all claims,
evidence, and conclusions. Tools and versions: [name, version]. Use:
[translation / language editing / literature organisation].
```

三条硬规矩：

1. **工具写全名和版本号**，不写"AI 工具"；
2. **用途不夸大也不缩小**：用了翻译就写翻译，用了润色就写润色；
3. **必须写"作者全责"**——这是声明的核心。
