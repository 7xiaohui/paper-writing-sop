# 工作区模板

本目录只放说明，不放空目录。

原因：git 不跟踪空目录，复制粘贴也不可靠。工作区由脚本生成，幂等（反复运行不会覆盖已写内容）：

```bash
python ../E-工具/init_workspace.py ..\paper-01 --title "临时题目"
python ../E-工具/check_workspace.py ..\paper-01
```

生成的树：

```
paper-01/
├─ README.md
├─ 00-锚点.md
├─ 01-起步/     类型判定.md、术语表.csv
├─ 02-选题/     选题卡.md、粗扫记录.md
├─ 03-定刊/     筛选前提、候选池、顺位表、指南硬约束、近刊对标、字数契约、原文/
├─ 04-两库/     学库/、材库/、文献卡、主张-出处表、材料台账、四查报告
├─ 05-结构/     论证表、句串、命题-反例-回应
├─ 06-初稿/     中文-v1.md
├─ 07-清稿/     中文-冻结-v1.md
├─ 08-英译/     英文-v1.md
├─ 09-体检/     体检报告.md
├─ 10-投稿包/
├─ 11-投递/     投稿记录.md
├─ _来源/
└─ _存档/
```

**三条规矩**（详见 `../01-起步.md`）：

1. 目录号 = 步骤号；
2. 产物名固定，不出现"最终版""新建文档"；
3. 版本后缀只加在稿子上（`-v1`、`-v2`、`-冻结-v1`）。

**脚本只补不改**：目录缺就建，文件缺就写空模板，已存在的跳过。所以可以放心反复运行。
