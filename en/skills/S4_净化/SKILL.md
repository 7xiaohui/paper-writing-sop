# S4 · 净化（内容层 · ★关卡 1）

> 档位：L1+L2 ｜ 定位：第 7 步，中文冻结前；第 10 步 2A 复查时引用此处 ｜ 前置：第 6 步中文初稿完成

## 1. 目标（Goal）

产出 `07-清稿/中文-冻结-v1.md`：**六类过程性表述 = 0，五类学术性声明未被误删**，工作稿与投稿稿分层正确，字数比初稿只减不增（±2%）。

## 2. 输入（Input）

| 输入 | 来源 | 必需？ |
|---|---|---|
| `06-初稿/中文-v1.md` | 第 6 步 | ✅ |
| 六类扫描清单 + 反误删五类 | 本单元 4.1 / 4.2 | ✅ |
| 字数三档口径参数 | `S1b_锁定` 的 0-C / `03-定刊/字数契约.md` | ✅ |
| `check_freeze.py` | `E-工具/` | ✅ |

## 3. 约束（Constraints）

- 🔴 **清稿不改论证**：清的过程中发现缺 P / 缺证据 / 命题站不住，停，回第 5 或第 6 步；不在清稿阶段顺手改判断。
- 🔴 **判定心法**：删任何一句前先问「这句话是写给审稿人 / 读者看的，还是写给我们自己看的？」写给读者 → 保留；写给自己 → 删。
- 🔴 **`[P#]` 全删，`（文N-M）` `（料N-M）` 全留**（第 8 步要靠它转正式引文）。
- 🔴 **净化改动中英同步**（若已开始翻译）；涉及删改 → 必重跑字数三档计数。
- 🔴 内部修订说明 / 决策记录只留工作稿 `_清理记录.md`，不进投稿稿。

## 4. 步骤（Procedure）

### 4.1 K5 · 六类净化扫描（逐项 grep，寄生于本单元，S7 2A 引用此处）

| # | 类别 | 关键词示例 | 处置 |
|---|---|---|---|
| ① | 待定 / 中间态 | 待补、待核、待定、待确认、TBD、XXX、未完成、存疑 | 补上或删句，不许留着等以后 |
| ② | 内部工作语 | `[P7]`、见上表、如前述、本表、第 4 步、按锚点第 3 条 | 改成读者能懂的话或删 |
| ③ | 投稿策略 | 这本刊偏好、审稿人可能会、为迎合、字数快超了 | 全删，写 Cover Letter 或 `11-投递/` |
| ④ | 版本尾注 | v1、第二稿、改于 X 月 X 日、上一版删了 | 全删，版本信息只在文件名与锚点 |
| ⑤ | 回迁语 | 回到前面、如前所述、前面提到、上文已述 | 前文说清就删，没说清补一句 |
| ⑥ | 审稿痕迹 | 已按意见修改、response to reviewer、返修稿 | 全删 |

### 4.2 反误删核验（最关键一步）

以下 5 类**看着像过程语，其实是论证的一部分，必须保留**：⑦ 审慎声明（「本文不主张 X 在所有地区成立」）、⑧ 方法说明（「编码由两人独立完成」）、⑨ 附录导读 / 数据可用性、⑩ 补充材料指引、⑪ 工作稿专属记录（只须确认投稿稿中为 0）。

### 4.3 执行顺序
```
① 明确本次净化对象（哪个文件 / 版本）
② 逐类跑 4.1（①–⑥），每处命中先过 4.2 心法再定删 / 改
③ 跑 4.2 反向核验（⑦–⑪ 必须仍在）
④ 删改影响字数 → 跑 4.4 重算三档
⑤ 若已开始翻译 → 中英同步删改
⑥ 记录净化结果，存 `_清理记录.md`
```

### 4.4 K2 · 字数三档 + 双计数（寄生于本单元，S7 / S5 引用此处）

| 档 | 组成 |
|---|---|
| A · 正文 | 正文（不含摘要 / 参考文献 / 表注 / 附录） |
| B · +文献+表注 | A + 参考文献 + 表注 + 图注 |
| C · +附录+声明 | B + 附录 + 声明（投稿填表用） |

双计数：Word 式 + 逐词，取两者都达标为准。**任何删改 / 增写之后必须重算** —— 「审稿落地后忘做字数联动回收」是踩过的坑。工具：`E-工具/check_freeze.py`（六类机检）；三档实数写进 `字数契约.md`。

### 4.5 触发时机
① 翻译启动前（强制）；② 生成投稿稿 / 匿名稿前；③ 任何对外发送版本定稿前；④ `S7` 投稿体检 2A 子关卡（复查翻译 / 排版后未重新引入）。
