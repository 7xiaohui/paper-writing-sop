# skills · 英文线可调用单元（v5.0 · 6 份起步）

> **SOP 是宪法，skill 是法条 + 操作手册**：`en/00`–`11` 讲「为什么 / 判据」，本目录只讲「怎么做 / 门禁 / 交接」，不复制正文。
> 每份 SKILL.md 固定七要素：**目标 / 输入 / 约束 / 步骤 / 检查 / 迭代 + 调用（Invokes）**；第 7 项写死「调哪几个内核 / 脚本」，用户永远不必记「K 在哪个阶段用」。
> **内核先寄生、后独立**：不单独建 K1–K6 文件夹；确定性动作写进宿主 skill 的一节，别的阶段用一行引用，≥3 处引用且描述开始不一致时才提成独立单元。
> **档位**：L1 纯文档 / L2 文档+脚本 / L3 全自动。本版先做 L1，确定性高的挂 `E-工具/` 脚本升 L2；**不追求 L3**。

## 六份起步（硬下限）

| 单元 | 对应步骤 | 关口 | 一句话职责 |
|---|---|---|---|

> **为什么是 6 份而不是 3 份**：S7 的四道子关卡分别引用 S4（净化 K5/K2）、S2（三道闸 K1）、S5/S6 的脚本承接。删任一宿主，S7 的子关卡就悬空。因此 S0/S1a/S1b/S2/S4/S7 是下限。

## 三处历史内部矛盾（本版已统一，别再带回来）

1. S6 档位：统一 **L2**（文档 + 脚本），不追求 L3。
2. `t9_consistency.py` 归属：统一表述为「术语一致性扫描寄生于 `S5_翻译` 第 5.1 节」；脚本名与 `E-工具/` 对齐后，索引里只出现一次。
3. S9（降 AI 率）：**不独立建**，并入 `S5` / `S7`；本版按「提高原创表达 + 如实披露」，不写「降 AI 率」承诺。

## 怎么用

1. 不知道下一步 → 先看 `S0_总控/SKILL.md` 的播报模板。
2. 12 份步骤文档每份末尾有「可调用单元」一行，指向这里的 `SX`。
3. 判据以步骤正文为准；skill 只负责怎么动手，不代替判据。
4. 每篇论文结束，把新踩的坑回写进对应 skill 的「迭代」表与 `C-失败模式库.md`。
