# 30 · 英译与成稿

## 1. 什么时候用

"中文定稿了，译成英文""英文稿出来了，做成投稿文件""匿名稿怎么处理""元数据要不要清"。

## 2. 输入

- 中文定稿（**冻结后**）
- 术语表（中文 / 英文 / 禁用写法）
- 图件源文件
- 期刊硬约束清单

## 3. 动作

```
7-1 冻结快照 → 7-2 分块翻译（摘要→正文→声明→文献→附录，不并行）
→ 7-3 术语对齐 → 7-4 回译抽检 10 段 → 7-5 对照稿确认
→ 7-6 抽英文单行稿（机械抽取，不重写）+ 反向清点
→ 7-7 五查
→ 8-1 去工作痕迹 → 8-2 匿名化 → 8-3 四份 docx → 8-4 属性清理 → 8-5 十二项终检
```

## 4. 输出

- 英文稿（md）
- 五查报告
- 匿名主稿 / 标题页 / Cover Letter / 图注表（4 份 docx）
- 300dpi 图件
- 终检报告

## 5. 判据

- [ ] 术语 100% 照表；禁用词 0；拼写体系统一
- [ ] 回译漂移 0；数字 100% 一致
- [ ] 反向清点：标题数 / 表数 / 图数 / 关键句都在
- [ ] 过程语 6 类 = 0；学术声明 5 类还在
- [ ] 匿名稿 0 处身份信息；匿名前后词数差 ≈ 被删信息词数
- [ ] 四份文件都能打开；无生成器痕迹；无修订痕迹

## 6. 失败处理

| 情况 | 怎么办 |
|---|---|
| 边译边改中文 | 停止，回中文冻结；否则永远译不完 |
| 术语漂移 | 回 7-3，先补表再译 |
| 抽取后内容缺失 | 反向清点：数标题/表/图；缺的补 |
| 删缩略图后打不开 | 补 `.rels` 关系；删部件必须删关系 |
| 匿名后词数差对不上 | 说明误删了正文，回滚重做 |
