# S1a · 找刊（候选池）

> 档位：L1 ｜ 定位：11 步流程第 2/3 步的真正起点 ｜ 前置：一句话研究主题 + 五个关键词
> 与 S1b 的分工：**S1a = 发散**（能投哪些刊）；**S1b = 收敛**（就投这本，取指南）。没定刊之前不要跑去下载指南。

## 1. 目标（Goal）

产出一份**可决策的《候选期刊池》**：每刊一行（收录 / 分区标口径 / IF / APC / 审稿周期 / **主题匹配证据** / 初筛结论），形成主攻 / 冲刺 / 保底初步顺位，**交用户拍板**。

## 2. 输入（Input）

| 输入 | 来源 | 必需？ |
|---|---|---|
| 研究主题（一句话）+ 五个关键词（中英） | `02-选题/选题卡.md` | ✅ |
| 筛选大前提（收录 / 预警 / 分区口径 / 经费 / 类型 / 周期） | 用户逐条回答 | ✅ |
| 3–5 篇「最像你论文的文章」 | `04-两库/学库/` 或用户提供 | 路径 B 用，强烈建议 |

## 3. 约束（Constraints）

- 🔴 **先定筛选大前提，再找刊** —— 标准不定，找出来的池子是「一堆没用的名字」。
- 🔴 **收录与分区必须在权威源核实，不得凭印象**：WoS Master Journal List 是收录判定金标准；分区必须标口径（JCR / 中科院 / 其他），Scimago / Scopus 仅补充不作判定。
- 🔴 **必查预警名单**；🔴 **每刊必须有「主题匹配证据」**（Aims 原句或某年发了类似主题），无证据的刊不进池。
- 🔴 **双路径 A、B 都走过**：A 专业对口刊（领域关键词）；B 专业不对口但能发此方向（拿 3–5 篇最像的文章 → 看它们发在哪）。路径 B 最易被忽略、最值钱。
- 🔴 **四级效力源不许混用**：A 官方硬约束源（唯一判据源）/ B Crossref+OpenAlex API（可核验元数据，可作「真/对」判据）/ C Wikipedia 镜像 + 期刊官方 RSS 静态页（**探索性线索，不作判据性事实源**）/ D 兜底。
- 🔴 **顺位由用户拍板**，AI 不代定；不输出「建议投某刊」。

## 4. 步骤（Procedure）

### 4.1 填《筛选大前提表》
七维逐条有答案（收录类型 / 预警 / 分区口径 / 经费 / 论文类型 / 语言 / 周期），写进 `03-定刊/筛选前提.md`。口径是本项目参数，不照搬别人的门槛。

### 4.2 权威源与取数
按 `03-定刊.md` 第三节的权威源效力表核收录 / 分区 / IF；按「四·补」安排 AI 自动取数：
- Crossref 按 ISSN 拉近两年题录（URL 模板 / cursor 翻页 / total-results 只看规模，见 `S1` 卡）；
- OpenAlex 做主题粗筛与漏斗记数（命中 → 排除含理由 → 去重 → 入库）；
- Wikipedia 镜像 / 期刊官方 RSS 静态页只用来收敛检索词、拿近刊题名与栏目 / 文章类型；
- 每条 B 级结论留「URL / 抓取时间 / 原始响应或存档路径」，C 级线索给「回哪一级源复核」。

### 4.3 双路径六步
```
① 填大前提 → ② 路径 A 领域关键词逐刊记录 → ③ 路径 B 反查 3–5 篇最像文章的发表刊
→ ④ 汇总《候选期刊池》（去重，每刊一行）→ ⑤ 初筛打分（收录/主题/费用/周期）
→ ⑥ 排序成主攻/冲刺/保底，交用户决策
```

### 4.4 先例检索（补类型判据）
不靠类型清单猜：翻 2–3 期样刊的全部研究论文，数其中「0 图 0 表」的纯概念稿有几篇；概念型论文投到 0 篇纯概念稿的刊，视为无先例。

## 5. 检查（Checks）

- [ ] 筛选大前提七维逐条有答案；
- [ ] 每刊收录状态在权威源核实过、分区标了口径、预警名单已查；
- [ ] 路径 A、路径 B 都走过；每刊有「主题匹配证据」；
- [ ] 8–12 本，排除项也留一行写清为什么；
- [ ] 自动取数留三列留证；**C 级线索未直接进候选池作判据**；升级路径（C→B→A）在留证里看得出来；
- [ ] 顺位由用户拍板，非 AI 代定。
