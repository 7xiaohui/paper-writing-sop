# 10 · 选题与文献

## 1. 什么时候用

"这个方向能不能写""帮我看看投哪本""要开始做文献了""文献怎么选""综述写不出来"。

## 2. 输入

- 三句话（现象 / 问题 / 判断）——**没有就先写，不许跳过**
- 材料清单（数据 / 案例 / 政策文本）
- 已有的中文文献 3–5 篇（用来造词表）

## 3. 动作（按序，不许跳）

```
1-1 三句话 → 1-2 学科定位三证 → 1-3 文献可及性 → 1-4 合规档位
→ 2-1 最小可发表单元 → 2-2 判类型 → 2-3 题目三版
→ 3-1 筛选大前提 → 3-2 双路径 → 3-3 三证锁定 → 3-4 指南原文 → 3-5 近刊对标 → 3-6 字数契约
→ 4-1 词表 → 4-2 滚雪球 → 4-3 三十秒判 → 4-4 六信号 → 4-5 分诊 → 4-6 六组 → 4-7 精读 → 4-8 四查
```

## 4. 输出

- 学科定位卡（见 `01` 1-2，三证）
- 词表（三列）
- 文献卡（`03` 表 2，≥15 张，每张有"拟引句"）
- 六组表（六行，每组三句）
- 指南硬约束清单（`03` 表 5）

## 5. 判据

- [ ] 三句话里没有"很重要/意义重大/值得研究"
- [ ] 三证齐全（Aims 摘句 / 近刊 3 篇 / 类型清单）
- [ ] 指南每行能指到原文段落
- [ ] 文献卡 ≥15，六组每组 ≥2 篇，三句写得出
- [ ] 四查 0 错

## 6. 失败处理

| 情况 | 怎么办 |
|---|---|
| 三证缺二 | 换刊，不要硬写 |
| 某组 <2 篇 | 用该组代表篇滚雪球；滚不到 = 选题太窄 |
| 文献卡写不出"拟引句" | 这篇对你没用，删 |
| 拿不到全文 | 降级为摘要级，不许撑核心命题 |

## 7. 交接

→ `20`（把三句话、六组表、类型判定带过去）
