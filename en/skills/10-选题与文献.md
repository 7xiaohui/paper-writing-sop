# 10 · 选题与文献

## 1. 什么时候用

"这个方向能不能写""帮我看看投哪本""要开始做文献了""文献怎么选""综述写不出来"。

## 2. 输入

- 三句话（现象 / 问题 / 判断）——**没有就先写，不许跳过**
- 材料清单（数据 / 案例 / 政策文本）
- 已有的中文文献 3–5 篇（用来造词表）

## 3. 动作（按序，不许跳）

```
1-1 三句话 → 1-2 学科定位三证 → 1-3 文献可及性 → 1-4 合规档位
→ 2-1 最小可发表单元 → 2-2 判类型 → 2-3 题目三版 → 2-4 贡献定位（三句 + 双靶）
→ 3-1 七项前提 → 3-1b 权威源分级 → 3-2 双路径 + 先例检索 → 3-3 候选池与顺位
→ 3-4 指南原文 → 3-5 近刊对标 → 3-6 字数契约
→ 4-1 词表 → 4-2 滚雪球 → 4-3 三十秒判 → 4-4 六信号 → 4-5 分诊 → 4-6 六组 → 4-7 精读 → 4-8 四查（串行）
```

**第 3 步三条不许省**：① 3-1b 每个收录/分区判断都要落到具体权威源；② 3-2 必须**两条路都走**，且"这刊收不收这个概念稿"要**拿先例文章证**，不靠类型清单；③ 3-3 顺位要有依据（初审周期 / 录用率 / 试错成本），不是感觉。

## 4. 输出

- 学科定位卡（见 `01` 1-2，三证）
- 贡献三句（见 `01` 2-4）
- 词表（三列）
- **候选池表**（`03` 表 9：每刊一行，含"主题匹配证据"列与初筛结论）
- **近刊对标笔记**（`03` 表 10：四栏提取）
- 文献卡（`03` 表 2，≥15 张，每张有"拟引句"）
- 六组表（六行，每组三句）
- 指南硬约束清单（`03` 表 5）

## 5. 判据

- [ ] 三句话里没有"很重要/意义重大/值得研究"
- [ ] 三证齐全（Aims 摘句 / 近刊 3 篇 / 类型清单）
- [ ] **收录与分区判断都能指到权威源**（MJL 字段 / JCR / 分区表口径 / 预警名单），不用 Scopus-SJR 当判定依据
- [ ] **候选池每刊有"主题匹配证据"**（不只写"很合适"）
- [ ] **"这刊收概念稿"由先例文章证明**（近刊里有同类 0 图 0 表的文章），不是只读类型清单
- [ ] **顺位有依据**（初审周期 / 录用率 / 试错成本三项至少两项有数）
- [ ] 指南每行能指到原文段落
- [ ] 文献卡 ≥15，六组每组 ≥2 篇，三句写得出
- [ ] 四查 0 错（真实性"存疑"档的文献已处置：降级或删，不是一律删）

## 6. 失败处理

| 情况 | 怎么办 |
|---|---|
| 三证缺二 | 换刊，不要硬写 |
| **只在"收稿类型清单"里找证据** | 清单是必要条件不是充分条件；回 3-2 找一篇同类型先例，找不到就换刊 |
| **审稿周期查不到** | 用"该刊近期文章 received→accepted 的天数"估；仍查不到就按最长排，别当保底 |
| 某组 <2 篇 | 用该组代表篇滚雪球；滚不到 = 选题太窄 |
| 文献卡写不出"拟引句" | 这篇对你没用，删 |
| 拿不到全文 | 降级为摘要级，不许撑核心命题 |
| 文献"查不到" | **先判是哪一档**：仅弱源可检 = 存疑（降级使用）；全渠道无 + 刊名刊号不存在 = 疑似伪造（删）。不许一删了之 |
