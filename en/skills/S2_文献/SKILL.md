# S2 · 文献地图（K1 三道闸寄生）

> 档位：L1+L2 ｜ 定位：第 4 步「建库 + 验证」 ｜ 红线：**不编造任何文献**

## 1. 目标（Goal）

1. **文献地图**：检索式、数据源、纳入排除标准、筛选漏斗 —— 每个阶段的条数必须留证（导出文件 / 原始响应）；
2. **文献验证**：全部文献过**三道闸**（实体存在 / 字段一致 / 双向闭合），并完成 `04-两库.md` 第五节的四查三步串行。

产出：文献地图 + 三重核验报告 + 骨架题录库 + 四查报告。

## 2. 输入（Input）

| 输入 | 来源 | 必需？ |
|---|---|---|
| 主题关键词（用户确认口径） | `02-选题/选题卡.md` | ✅ |
| 文献实体（PDF / 题录） | AI 自动检索下载并留证，或用户提供 | ✅ |
| 已有参考文献表（核验场景） | 稿件 md | 按需 |
| 四级效力源与自动取数 | `03-定刊.md`「四·补」/ `S6` 卡 | ✅ |

## 3. 约束（Constraints）

- 🔴 **不编造任何文献** —— 查不到按三档判定（可信 / 存疑 / 疑似伪造），「存疑」降级使用而非删除；「疑似伪造」交人处置。
- 🔴 **AI 可自动检索下载并留证**；但文献实体必须能打开全文，只有摘要的标【仅摘要】不得当支撑。
- 🔴 **条数留证** —— 筛选各阶段数字可溯源（命中 → 排除含理由 → 去重 → 入库），「数字必须可追溯」是防幻觉铁律。
- 🔴 检索式与纳入排除标准**须用户确认**后才执行；同一数字全文一致。
- 🔴 **C 级线索（Wikipedia 镜像 / RSS 静态页）不作判据性事实源**；B 级（Crossref / OpenAlex）结论须留原始端点与抓取时间。
- 🔴 引文标题原文不改（改动即属篡改引文）。

## 4. 步骤（Procedure）

### 4.1 文献地图（T2）
```
① 设计检索式（数据源 + 关键词组合）→ 用户确认口径
② 跑检索 → 各阶段条数留证（导出 / 原始响应存 04-两库/）
③ 纳入排除标准筛选 → 每阶段记数
④ 汇总：骨架题录库（作者/年/题名/刊/卷期页/DOI）
```

### 4.2 K1 · 三道闸（寄生于本单元，S7 2D 引用此处，不另写）

| 闸 | 验什么 | 通过标准 |
|---|---|---|
| 第一闸 · 实体存在 | 文献真实存在 | 每条有实体证据；DOI 实测解析 |
| 第二闸 · 字段一致 | 标题/作者/年/卷期页/DOI 与实体一致 | 字段 0 差异（格式差异不算事实错误） |
| 第三闸 · 双向闭合 | 正文引用 ↔ 文献表 | 双向 0 悬空；自引真值表防年份映射错乱 |

**DOI 实测双通道**：

| 通道 | 适用 | 说明 |
|---|---|---|
| Crossref | 国际 DOI | `curl https://api.crossref.org/works/{DOI}`；题名反查 `?query.bibliographic=` |
| doi.org → chndoi.org | 中国 DOI（CNKI 系） | 由 ISTIC 注册，**Crossref 404 属正常**，以 doi.org 解析（HTTP 200）为准 |

Windows 环境 `python urllib` 若因 SSL 证书失败 → 改用 `curl`。见 `S7` 卡。

### 4.3 四查三步串行（顺序不可倒）
① **真**：真实性三档（见 4.2）；② **对**：标号映射 + 条数对账（正文 ↔ 文献表双向、条数 vs 选题承诺区间、格式转换后重跑）；③ **该 + 漏**：语义 L1/L2、**无编号转述扫描**（漏引唯一防线）、**引号内容审计 + 直引比例 1%–5%**（文献直引为 0 不得进清稿）、页码以 PDF 页脚为准禁止估算。

### 4.4 中文文献英文条目改式
`中文原题 [English translation]. 期刊, 卷(期), 页码. DOI`；删结尾 `(in Chinese)`；期刊名用**官方英文译名**（逐刊查证，不凭印象音译）。

### 4.5 P0 定向抽验
AI 产出「人工只需核参考文献 + 数字」两页纸清单，用户执行；人工不必逐字读全稿。

## 5. 检查（Checks）

- [ ] 检索式经用户确认；各筛选阶段条数有原始留证；漏斗四阶段记数可复跑；
- [ ] 每条文献过三道闸；DOI 全部实测（双通道）；
- [ ] 四查三步串行全跑，四查报告 0 错；
- [ ] 无编号转述扫描 0 漏引；引号审计三列表齐，文献直引占比 1%–5%；
- [ ] 正文引用与文献表双向 0 悬空；无一条「AI 编造」的文献；
- [ ] 自动取数留三列留证；C 级线索未直接进文献卡作判据。
