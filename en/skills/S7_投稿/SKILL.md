# S7 · 投稿（★关卡 2 · 2A–2D）

> 档位：L1+L2 ｜ 定位：第 10/11 步，上传前最后一道关 ｜ 前置：`S4` 关卡 1 已过、英文定稿已冻结

## 1. 目标（Goal）

产出可上传的材料包与体检表：`10-投稿包/` 四份 docx + 图，十八项终检全过，投稿记录留证（稿件号 / 日期 / SHA256 / 系统口径字数）。

## 2. 输入（Input）

| 输入 | 来源 | 必需？ |
|---|---|---|
| 英文定稿 + 体检报告 | 第 9 步 | ✅ |
| 指南硬约束 + 字数三档口径 | `S1b_锁定` / `03-定刊/` | ✅ |
| 作者信息（含官方机构英文名） | 用户，以官方文件为准 | ✅ |
| 四份 docx + 300dpi 图件 | `E-工具/build_docx.py` | ✅ |

## 3. 约束（Constraints）

- 🔴 **每一项都必须「实测」，不凭感觉** —— 字数用工具数、DOI 逐条解析、元数据用脚本扫。「以为没问题」不等于没问题。
- 🔴 **机构英文名这类硬约束事实必须以官方文件为准**，不得凭印象、不得靠百科 / Wikipedia 镜像 / ORCID 历史用法。
- 🔴 **修订痕迹在匿名评审中会暴露身份** —— docx 内修订 / 批注 / 人员信息必须清零。
- 🔴 **体检不过不上传** —— 2A–2D 任何一项未过，停止提交，先修。
- 🔴 **每次重建 docx 后必须重新清理元数据并重新过 2B**（生成器痕迹会随重建写回）。
- 🔴 前刊未终结，绝不投他刊；不用出版社「自动转投」。

## 4. 步骤（Procedure）

### 4.1 2A · 内容层复查
重跑 `S4_净化` 4.1 / 4.2 的六类扫描与反误删核验，确认翻译 / 排版后**没有重新引入**过程语；工作稿与投稿稿分层正确。

### 4.2 2B · 文件层清理复查
- docx 元数据七项无生成器痕迹（`E-工具/scrub_meta.py`）；
- 无修订痕迹 / 批注 / 人员信息；图件 EXIF 已清；
- 四份 docx 都能打开；**产出物反向清点**：段落数 / 表数 / 图数非 0，关键句在（防机械抽取静默丢内容）；
- 删缩略图必须同时删 `.rels` 悬空关系，否则 docx 打不开。

### 4.3 2C · 作者信息核验（硬复选框）

| 核验项 | 查什么 |
|---|---|
| 姓名 | 英文拼写与投稿系统一致 |
| 单位英文名 | **官方规定**的英文名（章程 / 科研处文件），不得凭印象、不得靠百科 |
| ORCID | 已填且可解析 |
| 基金编号 | 与立项文件一致 |
| 匿名稿 | 0 处姓名 / 单位 / 致谢 / 基金 / 声明 / 邮箱 / ORCID |
| 文档完整性 | 附录 / 参考文献 / 图表**未被匿名化误删** |

### 4.4 2D · 事实性核验
- 全部 DOI 实测可解析（Crossref 或 `doi.org→chndoi.org` 双通道，见 `S2_文献` 4.2）；
- 摘要字数、关键词数、字数三档按指南**实测**（含不含参考文献 / 摘要 / 脚注）；
- AI 使用声明完整（工具全名 + 版本号 + 用途 + 全责）；竞争利益声明「即使无也必须写无」；数据可用性声明；
- 基金信息、Cover Letter 日期与刊名、主题分类、Highlights / 推广要点按**字符数**上限压缩（「字符」≠「单词」）；
- 系统隐藏字段（第二个摘要框 / running head / CRediT / 推荐审稿人）已填，按系统口径。

### 4.5 提交与留证
投递当天记 `11-投递/投稿记录.md`：稿件号、日期、目标刊 + ISSN、文件名 + SHA256（`Get-FileHash`）、系统口径字数、状态。**24 小时内不改任何文件**；要改走系统 Withdraw 或邮件编辑部。

## 5. 检查（Checks）

- [ ] 2A–2D 四组、十八项全过；未通过项 0；
- [ ] 主稿与匿名稿除匿名处理外逐字一致（抽 3 段对）；
- [ ] 匿名稿文内 + 属性，作者痕迹 0；元数据七项清零；
- [ ] 图 300dpi、能打开、图注齐；文件命名符合指南，无 "final" / "最终" / "草稿"；
- [ ] 投稿记录有稿件号 / 日期 / 目标刊 / 文件名 SHA256 / 系统口径字数；
- [ ] 前刊已终结才转投；没在 Under review 时投他刊。
