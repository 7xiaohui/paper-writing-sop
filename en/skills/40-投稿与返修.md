# 40 · 投稿与返修

## 1. 什么时候用

"要投稿了""被拒了""给意见了""转投哪本"。

## 2. 输入

- 材料包（4 份 docx + 图 + 终检报告）
- 期刊硬约束清单（含 AI 政策、系统字段）
- 前刊状态（转投时必须已终结）

## 3. 动作

```
9-1 投稿前四查（内容/文件/作者/事实）
→ 9-2 系统填写（摘要+简要摘要两处、关键词、作者信息、推荐审稿人、AI 声明、Cover Letter）
→ 9-3 记投稿号与状态
→ 收到决定：
   · 桌拒无意见 → 换刊（不改稿）
   · 有意见     → 返修五步
   · 拒绝       → 分诊 + 转投
```

**返修五步**：48 小时冷静 → 编号 + 三级分类（必改/可辩/误读）→ 逐条回应表 → 只改必要处 → 二次终检。

## 4. 输出

- 投稿号 + 状态记录（`03` 表 7）
- 返修稿 + Response Letter（`03` 表 6）
- 或：转投差异清单

## 5. 判据

- [ ] 四查全过；四份文件可打开
- [ ] 系统两个摘要框都已填（简要摘要现场压缩即可，不回改正文）
- [ ] 匿名稿 0 处；附录/文献/图表未误删
- [ ] Cover Letter 日期、刊名、主编姓名正确
- [ ] 前刊未终结时，绝不出现下一行投稿记录

## 6. 失败处理

| 情况 | 怎么办 |
|---|---|
| 桌拒无意见 | **不改内容**，48 小时内换刊，重做第 1 步 |
| 想全盘照改 | 先判"这条成立吗"；不成立的要辩 |
| 未改但没理由 | 必给"理由 + 替代动作"，否则编辑视为敷衍 |
| 想用自动转投 | 不用（会传旧版），从零投 |
| 审稿意见超范围 | 承认 + 限定，或转未来研究 |

## 7. 交接

→ 换刊回第 1 步；返修完成后回 `30` 重生成文件。
