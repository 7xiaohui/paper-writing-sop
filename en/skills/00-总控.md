# 00 · 总控

## 1. 什么时候用

- 开工第一句（与 `50-AI执行协议` 一起读）；
- 不知道下一步做什么；
- 怀疑自己跳步了。

## 2. 输入

| 项 | 从哪来 |
|---|---|
| 工作区文件现状 | 扫目录（**看文件，不看记忆**） |
| 九步定义 | `01-主流程.md` |
| 判据 | `02-检查清单.md` |
| 对抗审查 | `08-对抗审稿法.md`（第 5 步末、第 8 步） |
| 执行卡 | `提示词/` 12 份，按动作卡号取 |
| 三个事实源 | `numbers.md` / `terms.csv` / `decisions.md` |
| AI 协议 | `50-AI执行协议.md` |

## 3. 动作

1. 扫工作区，找"上一步的硬产出"是否存在。
2. 按下表定位当前步。
3. 只播报**一个**下一步。

| 步 | 完成标志（必须找得到文件） |
|---|---|
| 1 | 学科定位卡 + 三句话 |
| 2 | 选题卡 |
| 3 | 指南硬约束清单 + 近刊对标 + 字数契约 |
| 4 | 文献卡 ≥15 + 六组表 |
| 5 | 论证表 + 标题句串 + 字数分配 + **命题-反例-回应表（5-5 过）** |
| 6 | 中文定稿 |
| 7 | 英文稿 + 五查报告 |
| 8 | 4 份 docx + 终检报告 + **对抗审查记录（编号/分级/状态）** |
| 9 | 投稿号 / 返修稿 / 转投方案 |

## 3.5 决策闸门（命中即停，问用户）

- 收录集未在 MJL 核实；
- 字数上限或口径未知；
- 正文有"全量／所有"主张，覆盖率 < 100%；
- 核心概念定义 > 证据；
- 比较单位不可比（主体构成／计数口径／样本量）；
- 系统字段单位不明（word / character）；
- 参考文献 DOI 核不到，或仅单一弱源可检（存疑档）；
- 要改标题或摘要里的"承诺"；
- **5-5 命题反例检验未做完就想过第 5 步**（处置未选四选一：改命题／限定范围／补论据／写进局限）；
- **在英文阶段提内容级建议**（英文只做复查，发现型审查必须在中文稿上做完）；
- **对抗审查有未处置的致命/重要意见**（改命题须回第 2 步返工并重跑受影响检查）。

## 3.6 三个事实源（只从这里取数）

`numbers.md`（值／定义／来源／核验日）｜`terms.csv`（术语）｜`decisions.md`（决策／受影响文件）。
正文只引用，不重算；日记与记忆不算。

## 3.7 每步三行

【闸门】命中 3.5 → 停｜【命令】本步要跑什么｜【证据】每个判断给文件 + 行号。

## 4. 输出（固定格式）

```
你现在在：【第 X 步 · 名称】
   证据：{存在的文件}
上一步判据：{过 / 未过（缺什么）}
下一步：{一个动作}
用：{动作卡号}
做完的标志：{可验证的产出}
```

## 5. 判据

- [ ] 播报有文件证据（不许凭记忆说"做完了"）
- [ ] 只给一个下一步
- [ ] 上一步没过就明说，不许放行
- [ ] 数字（词数/样本数/文献数）回查文件，不凭印象

## 6. 失败处理

| 情况 | 怎么办 |
|---|---|
| 声称做完但找不到文件 | 直接说"没有证据，可能是记错了" |
| 两个文件数字不一致 | 以成品为准；记录层不算 |
| 用户说"我很乱" | 只做一件事：定位 + 一个下一步 |

## 7. 交接

- 选题/文献 → `10`
- 结构/初稿 → `20`
- 英译/成稿 → `30`
- 投稿/返修 → `40`
- 对抗审查 → `08`（方法）+ `提示词/03`（命题反方）、`提示词/11`（三角色）
- 执行约定 → `50`
