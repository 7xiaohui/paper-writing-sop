# 00 · 总控

## 1. 什么时候用

- 开工第一句；
- 不知道下一步做什么；
- 怀疑自己跳步了。

## 2. 输入

| 项 | 从哪来 |
|---|---|
| 工作区文件现状 | 扫目录（**看文件，不看记忆**） |
| 九步定义 | `01-主流程.md` |
| 判据 | `02-检查清单.md` |

## 3. 动作

1. 扫工作区，找"上一步的硬产出"是否存在。
2. 按下表定位当前步。
3. 只播报**一个**下一步。

| 步 | 完成标志（必须找得到文件） |
|---|---|
| 1 | 学科定位卡 + 三句话 |
| 2 | 选题卡 |
| 3 | 指南硬约束清单 + 近刊对标 + 字数契约 |
| 4 | 文献卡 ≥15 + 六组表 |
| 5 | 论证表 + 标题句串 + 字数分配 |
| 6 | 中文定稿 |
| 7 | 英文稿 + 五查报告 |
| 8 | 4 份 docx + 终检报告 |
| 9 | 投稿号 / 返修稿 / 转投方案 |

## 4. 输出（固定格式）

```
你现在在：【第 X 步 · 名称】
   证据：{存在的文件}
上一步判据：{过 / 未过（缺什么）}
下一步：{一个动作}
用：{动作卡号}
做完的标志：{可验证的产出}
```

## 5. 判据

- [ ] 播报有文件证据（不许凭记忆说"做完了"）
- [ ] 只给一个下一步
- [ ] 上一步没过就明说，不许放行
- [ ] 数字（词数/样本数/文献数）回查文件，不凭印象

## 6. 失败处理

| 情况 | 怎么办 |
|---|---|
| 声称做完但找不到文件 | 直接说"没有证据，可能是记错了" |
| 两个文件数字不一致 | 以成品为准；记录层不算 |
| 用户说"我很乱" | 只做一件事：定位 + 一个下一步 |

## 7. 交接

- 选题/文献 → `10`
- 结构/初稿 → `20`
- 英译/成稿 → `30`
- 投稿/返修 → `40`
