# 50 · AI 执行协议

## 1. 什么时候用

每次让 AI 动笔、改稿、填表、投稿前。与 `00-总控` 一起读。

## 2. 开工三件事

1. 读三个事实源（没有就先建）：`numbers.md` / `terms.csv` / `decisions.md`。
2. 读当前步对应的 skill。
3. 报一句："我在第 X 步｜上一步判据过没过｜今天只做哪张卡。"

## 3. 决策闸门

**见 `00-总控` §3.5。命中任一条 → 停，问用户，不猜。**

## 4. 单位（最常错）

| 字段 | 单位 |
|---|---|
| 摘要、关键词、正文 | word |
| 标题、running head、推广摘要、tweet、图摘要说明 | character（含空格） |
| 系统没写单位 | 两个都数，取严 |

## 5. 证据与事实源

- 每个判断给"文件 + 行号/单元格"；不给"我记得／之前说过"。
- 数字只从 `numbers.md` 取，术语只从 `terms.csv` 取，决策只从 `decisions.md` 取。
- 日记、聊天、记忆都不算证据。

## 6. 四条禁止

1. 不许把"账号级编码"说成"逐条编码"。
2. 不许把概念定义写得比证据大。
3. 不许把"主体构成差异"说成"平台差异"。
4. 不许在未核 MJL 前断言"这是 SSCI"。

## 7. 交接

每做完一步，写一行到 `decisions.md`：日期 / 动作 / 受影响文件 / 回勾。
下游文件只认这一行，不认口头说明。
