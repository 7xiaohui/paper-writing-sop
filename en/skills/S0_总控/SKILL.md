# S0 · 总控（流程导航）

> 档位：L1 ｜ 定位：整个 skill 体系的唯一入口 ｜ 前置：无

## 1. 目标（Goal）

在任意时刻准确回答三件事：**你在这里 / 下一步做什么 / 该用哪个单元**。产出一句状态播报 + 一个明确的下一步指令（最多 3 个候选）。

## 2. 输入（Input）

| 输入 | 来源 | 必需？ |
|---|---|---|
| 当前工作区文件状态 | `python E-工具/check_workspace.py <工作区>` 的输出 | ✅ |
| SOP 现行版本 | `en/00-总览.md`（v5.0） | ✅ |
| 项目锚点 | `<工作区>/00-锚点.md` | 建议 |
| 上一步判据结论 | 对应步骤正文的「判据」节 | ✅ |

## 3. 约束（Constraints）

- 🔴 **不得凭空判断阶段** —— 必须以实际存在的文件为证据；「翻译完成」必须能找到英文定稿文件。
- 🔴 **不得跳阶段** —— 前一关未过，明确指出「卡在哪、为什么」。
- 🔴 **不得一次播报超过 3 个候选下一步**。
- 🔴 **状态判断以 11 步 SOP 为主线**；skill 只是执行单元，不改变阶段定义。
- 🔴 **用户声称「做完了 X」但证据文件不存在 → 明确指出「没有证据，可能是记错了」**。这是防幻觉第一道防线。

## 4. 步骤（Procedure）

### 4.1 阶段状态表（每次播报前核对）

| 步 | 阶段 | 硬产出（判断完成的证据） | 关口 | 对应单元 |
|---|---|---|---|---|
| 1 | 起步 | `00-锚点.md` / `01-起步/类型判定.md` / `术语表.csv` | 术语 ≥10 条且每条有来源 | S0 |
| 2 | 选题 | `02-选题/选题卡.md` / `粗扫记录.md` | 四问可答、双靶标【待核】 | S1a |
| 3 | 定刊 | `03-定刊/` 六件 + `原文/` 官方指南存档 | ❗无指南原文 + 人核对，不写正文 | S1a / S1b |
| 4 | 两库 | `04-两库/` 六件 | 四查三步串行 0 错 | S2 |
| 5 | 结构 | `05-结构/` 三件 | ★关卡 1：命题过不了反例不进第 6 步 | S2 |
| 6 | 初稿 | `06-初稿/中文-v1.md` | 字数 ±5%、段首连读＝句串 | S4 |
| 7 | 清稿 | `07-清稿/中文-冻结-v1.md` | 六类 0、五类在、三脚本 0 命中 | S4 |
| 8 | 英译 | `08-英译/英文-v1.md` | 五查全过、10 段回译漂移 0 | （D8/D8b 卡） |
| 9 | 体检 | `09-体检/体检报告.md` | 高危句式 0、声明与档位匹配 | S5 |
| 10 | 投稿件 | `10-投稿包/` 四份 docx + 图 | ★关卡 2：十八项 2A–2D 全过 | S7 |
| 11 | 投递 | `11-投递/投稿记录.md` | 四查过、冻结留证、前刊终结才转投 | S7 |

### 4.2 播报模板（固定格式）

```
📍 你现在在：第【N】步 ·【阶段名】
   证据：{存在的关键文件 / check_workspace 输出}
✅ 上一关：{已过 / 未过（原因）}
👉 下一步：{一个明确动作}
   用：{SX skill 或 DX 卡}；做完的标志：{可验证的产出}
```

### 4.3 证据表（反幻觉核心）

声称的进度必须能找到对应产物文件；**只认文件，不认记忆**。文件路径见 `00-总览.md` 第三节「目录即进度」与 `check_workspace.py` 的 PRODUCTS 列表。

## 5. 检查（Checks）

- [ ] 播报里的「当前阶段」有证据文件支撑；
- [ ] 只给一个下一步（最多 3 候选）；
- [ ] 若上一关未过，已指出原因；
- [ ] 提到的单元名与 `skills/README.md` 实际的文件夹一致；
- [ ] 未凭记忆报数字（字数 / 条数 / 主体数须回查 `00-锚点.md` 单一事实源）。

## 6. 迭代（Iteration）

| 日期 | 发现 | 修正 |
|---|---|---|
| 2026-11-11 | 初版建立（从 11 步 SOP 与 v5.0 分析提炼） | — |

**迭代规则**：每完成一篇论文，回看「阶段定义是否还准确」「证据表是否需要补行」。

## 7. 调用（Invokes）

| 方向 | 对象 | 说明 |
|---|---|---|
| 调度 | S1a / S1b / S2 / S4 / S7 | 按第 4.1 节阶段状态表 |
| 被引用 | 全部单元 | 任何单元开始时先读本文件的「证据表」 |
| 工具 | `E-工具/check_workspace.py` | 唯一允许判断「文件在不在」的机器口径 |

> S0 本身**不执行工序**，只做导航与调度；内核（净化 / 三道闸 / 字数 / 元数据）寄生在 S2 / S4 / S7，本单元不直接调。
