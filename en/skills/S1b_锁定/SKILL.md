# S1b · 锁定与规格（指南 + 近刊）

> 档位：L1 ｜ 定位：第 3 步收敛环节，决定后面所有工作的规格 ｜ 前置：S1a 已产出候选池（或用户直接指定刊名，可跳过 S1a）

## 1. 目标（Goal）

定刊当天完成四件事，产出两份文件 + 一份存档：
1. 官方《作者指南》与 Aims & Scope **原文存档**（AI 抓取，留 URL / 日期 / 路径）；
2. **《硬性要求清单》**（字数 / 摘要 / 关键词 / 必含章节 / 图规格 / 引用体例 / 评审制 / 投稿系统 / 字符限制字段 / APC）；
3. **《近刊对标笔记》**（四栏：摘要词数 / 结构惯例 / 语域人称 / 引用条数）；
4. **写作规格**（字数三档 A/B/C 实数、摘要目标、关键词数、拼写体系）。

> 🔴 **铁律：没有官方指南原文、且人未对照原文逐条核完，不许开始写正文。**
> 🔴 **自动获取 ≠ 替代人工核对**：AI 取数只用于「把原文找齐、把清单预填好」；期刊事实属硬约束事实，以官方原文为准，不采第三方整理稿 / 记忆 / AI 转述。

## 2. 输入（Input）

| 输入 | 来源 | 必需？ |
|---|---|---|
| 已锁定刊名 + online ISSN | S1a 候选池或用户直接指定 | ✅ |
| 官方《作者指南》原文（PDF / 网页完整存档） | **AI 主动搜索下载**（`D3c` 卡） | ✅ |
| 3–5 篇近 2 年同主题近刊（优先 OA） | AI 取 OA 全文（RSS 静态页可作线索） | ✅ |
| 候选池的「匹配证据」原句 | S1a | ✅ |

## 3. 约束（Constraints）

- 🔴 **只认官方页面**：期刊官网 / 出版社 journal home 的 Instructions for Authors / Aims & Scope；Wikipedia / 百科 / 期刊评价站点 / 第三方汇总不得作为硬约束来源。
- 🔴 **取指南 + 近刊精读 = 定刊当天做**，都在写正文之前；写完 / 译完才下载近刊，是紧急压缩返工的根源。
- 🔴 **清单逐条可核**：每条写「第几段 / 哪一句 + 来源 URL + 抓取日期」，找不到写【未载明】并去邮件问。
- 🔴 指南与实刊冲突时**按更严的执行**，并在 Cover Letter 说明。
- 🔴 近刊对标发现规格冲突（如摘要均值 168 而我方 191）**就地改中文字数 / 摘要**，不留到投稿前；摘要目标词数 ≤ 近刊样本最大值。
- 🟡 若「先写好再分刊适配」→ 走备用模式：按一个基准刊写，明确标注字数 / 摘要 / 关键词口径**是临时的**，投稿前必须重新对照目标刊指南改造。

## 4. 步骤（Procedure）

### 4.1 四件事（定刊当天，写正文之前）

| 顺序 | 动作 | 产出 | 谁做 |
|---|---|---|---|
| 0-A | 搜索并下载官方《作者指南》原文存档 | `03-定刊/原文/`（带刊名 + 日期） | **AI 抓取**，人核对 |
| 0-B | 逐条抄成硬性要求清单 | `03-定刊/指南硬约束.md` | AI 预填，**人对照原文逐条核** |
| 0-C | 据此定写作规格（字数三档） | `03-定刊/字数契约.md` + 锚点登记 | AI 列，人确认 |
| 0-D | 取 3–5 篇近刊精读 | `03-定刊/近刊对标.md` | AI 精读，人确认 |

### 4.2 两种规格来源的分工（缺一不可）

| 来源 | 给你什么 | 性质 | 违反后果 |
|---|---|---|---|
| 作者指南 | 字数上限、摘要词数、关键词数、格式、声明要求、投稿系统 | **硬边界** | 被退稿 / 要求返修 |
| 近刊精读 | 实际语域、摘要习惯、章节惯例、引用密度、编者口味 | **软对标** | 不至于被退，但「不像本刊」→ 初审印象差 |

### 4.3 近刊对标四栏
① 摘要：每篇词数 + 均值 + 上限 + 结构；② 结构惯例：章节编号、结论段写法；③ 语域 / 术语：人称、时态、高频概念词；④ 引用密度：平均参考文献条数、自引情况。四栏结论**回写 0-C 写作规格**。

### 4.4 高价值副产品
① 顺带发现必引文献；② **补引红线**：近刊用了与我方相近的术语，不得把该术语的发明权归给它，须核先行归属并写差异化声明。

## 5. 检查（Checks）

- [ ] `03-定刊/原文/` 有官方指南原文（非转述）存档，文件名带刊名 + 抓取日期；
- [ ] 硬性要求清单每条能指到原文段落，有 URL / 抓取日期；投稿系统名与字符限制字段已核（不凭印象）；
- [ ] 【未载明】项已去邮件问；人已对照原文逐条核完并拍板字数口径；
- [ ] 近刊 3–5 篇为近 2 年该刊同主题（优先 OA），且与取指南同日做；
- [ ] 四栏笔记已填、结论已回写写作规格；摘要目标词数 ≤ 近刊样本最大值；
- [ ] 字数三档（A 正文 / B +文献表注 / C +附录声明）≤ 上限，中文留 10%，已登记锚点。
