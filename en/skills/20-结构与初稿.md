# 20 · 结构与初稿

## 1. 什么时候用

"可以开始写了吗""怎么定框架""写出来像综述""字数超了删不掉""初稿怎么生成"。

## 2. 输入

- 六组表（第 4 步产出）
- 类型判定（概念 / 比较 / 对策 / 小调查）
- 字数契约（第 3 步产出）

## 3. 动作（四级生成，禁止跳级）

```
5-1 论证表（每节一句"要让读者相信什么"）
→ 5-2 标题句串（20–40 句，连读）
→ 5-3 字数到段
→ 5-4 六缝预检（理论并置/概念落点/承诺兑现/概念空转）
→ 6-1 逐段扩写（主张+证据+解释+回扣）
→ 6-2 段落四问 → 6-3 节三问 → 6-4 连接词通读 → 6-5 冷却复读
```

**乙类（材料型）改走倒推**：摊材料 → 并模式 → 问机制 → 倒推 3 个 RQ → 回论证表。

## 4. 输出

- 论证表（`03` 表 3，5–7 行）
- 标题句串（编号 1…N）
- 字数分配（`03` 表 4，到段）
- 中文定稿

## 5. 判据

- [ ] 论证表每行可被反驳；"依据"全是编号；"反驳"列无空
- [ ] 只读句串能复述全文论证
- [ ] 字数合计 = 目标 ±5%
- [ ] 每段都有主张和证据；每段 4–6 句
- [ ] 字数在预算 ±10%
- [ ] 没有"正确的废话"（删了不影响论证的句子）

## 6. 失败处理

| 情况 | 怎么办 |
|---|---|
| 句串读不通 | 改结构，不许写正文 |
| 写成了罗列 | 回 5-2，每句问"所以呢" |
| 字数超 15% 且砍不动 | **砍一个发现或换刊**，不要抠字 |
| 两个发现重复 | 改成递进（结构→规范），不要并列 |
| AI 扩写时加了论点/数字 | 该段作废重写；不许"圆一下" |

## 7. 交接

→ `30`（中文冻结后）
