# 20 · 结构与初稿

## 1. 什么时候用

"可以开始写了吗""怎么定框架""写出来像综述""字数超了删不掉""初稿怎么生成"。

## 2. 输入

- 六组表（第 4 步产出）
- 类型判定（概念 / 比较 / 对策 / 小调查）
- 字数契约（第 3 步产出）

## 3. 动作（四级生成，禁止跳级）

```
5-1 论证表（每节一句"要让读者相信什么"）
→ 5-2 标题句串（20–40 句，连读）
→ 5-3 字数到段
→ 5-4 六缝预检（理论并置/概念落点/承诺兑现/概念空转/定义-证据/比较单位）
→ 5-5 命题反方检验【硬门禁，不过不许进第 6 步】
→ 定段型（论证/描述/推演 + 导语/小结，逐段标）
→ 6-1 逐段扩写（主张+证据+解释+回扣）
→ 6-2 段落四问 → 6-3 节三问 → 6-4 连接词通读 → 6-5 冷却复读 → 6-6 数据-主张对账 → 6-7 迁移残留扫描
```

**5-5 只做四件事**：写最强反驳 → 判证据强度 → 标正文是否回应 → 处置四选一（改命题／限定范围／补论据／写进局限）。
**发现型审查在中文稿做，英文阶段只做复查**：英文阶段提内容级建议 = 越界，会把已冻结的论证再翻一遍。

**乙类（材料型）改走倒推**：摊材料 → 并模式 → 问机制 → 倒推 3 个 RQ → 回论证表。

## 4. 输出

- 论证表（`03` 表 3，5–7 行）
- **命题-反例-回应表**（`03` 表 11，5-5 的产出，含处置结论）
- 标题句串（编号 1…N）
- 字数分配（`03` 表 4，到段）
- 中文定稿

## 5. 判据

- [ ] 论证表每行可被反驳；"依据"全是编号；"反驳"列无空
- [ ] 只读句串能复述全文论证
- [ ] 六缝全过（尤其定义-证据、比较单位）
- [ ] **5-5 每条致命/重要反驳都已处置**（四选一），"改命题"已回第 2 步返工
- [ ] 字数合计 = 目标 ±5%
- [ ] **每段按自己的段型合格**：论证/推演段有主张+证据；描述段有料（具体对象、数据、来源），不硬造论点
- [ ] 每段 4–6 句；字数在预算 ±10%
- [ ] "全量"类主张的编码覆盖率 = 100%
- [ ] 没有"正确的废话"（删了不影响论证的句子）
- [ ] 描述段里没有"由此可见""充分体现了"这类把事实包装成结论的句子

## 6. 失败处理

| 情况 | 怎么办 |
|---|---|
| 句串读不通 | 改结构，不许写正文 |
| 写成了罗列 | 回 5-2，每句问"所以呢" |
| 字数超 15% 且砍不动 | **砍一个发现或换刊**，不要抠字 |
| 两个发现重复 | 改成递进（结构→规范），不要并列 |
| AI 扩写时加了论点/数字 | 该段作废重写；不许"圆一下" |
| **描述段写不出论点就硬造** | 停：描述段本不承担论证，改问"这段提供了什么可核对的事实"，把料写足即可 |
| **5-5 找到致命反驳，但"改命题"成本太高** | 不许压着不改：要么限定范围（把命题收窄到证据覆盖的部分），要么写进局限并降低措辞强度 |
