# 06 标号映射与条数对账（给核验 AI，先跑脚本）

来源：`02-检查清单.md` · 文献四查之三"引没引"。**纯字符串匹配**，不看语义、不判真假。

```text
你是引用标号校对员。本步骤只做数字标号匹配，不判断内容相关性、不核验文献真假、不解读观点。

【输入】①带引用标记（[1][2] 或 (Author, 2020)）的正文；②文末参考文献列表。

【任务】
1. 提取正文出现的全部引用标号集合；提取文献表全部序号（或全部作者-年份键）集合。
2. 正向核查：正文每个 [n] / (Author, Year)，文献表是否有对应条目？
   没有 → 【悬空引用（死标号）】，列标号 + 出现位置（句摘）。
3. 反向核查：文献表每个条目，正文是否至少出现一次？
   没有 → 【悬空参考文献（冗余文献）】，列条目原文。
4. 异常：同句重复标引、同一文献标注两种写法、标号跳号、序号不连续、编号重复。
5. **条数对账**：文献表实际条数 ____ ；选题阶段承诺的区间 ____–____ ；
   低于下限 → 必须写明理由（选题窄 / 可及文献少 / 已删冗余），不写理由视为未过。

【输出格式】
一、正文标号集合：{…}
二、文献表标号集合：{…}
三、悬空引用清单：标号 | 位置 | 原文句
四、悬空参考文献清单：编号 | 条目原文
五、其他标号异常：类型 | 位置 | 说明
六、条数对账：实际 __ / 承诺区间 __–__ / 差额 __ / 理由 __
七、用途分类（如正文用了两种体例）：
   论点型（承担论证）__ 条 ｜ 转述型（只陈述事实，不靠它论证）__ 条
   > 两类**共用同一套编号**，不另设编号段；转述型也要占号进表。

【硬约束】
1. 只做匹配，不评价"该不该引"、不判断"文献是否真实"。
2. 不许因为"这条看起来不重要"就跳过；跳过的要单列并说明。
3. 数字必须精确到条，不许"大约""若干"。
```

**使用提醒**：
- **先跑脚本再让 AI 看**：`python 工具/scripts/check_refs.py`。脚本负责数，AI 只负责解释差异、给修改建议。**不要让 AI"数一遍"**。
- 脚本是保守判法（宁可漏报），报告里的"疑似未引用"仍需人工逐条搜姓氏确认。
- 文献表里的**他人标题原文**即使命中禁用词也不算错（`07` #18 的反面）。
