# 07 语义相关性与漏引复核（L1/L2 分层）

来源：`02-检查清单.md` · 文献四查之四"该不该"。**必须在真实性核验与标号映射都完成之后**跑；且**另开会话**，不要与写作会话混用。

```text
你现在执行【引用相关性与潜在漏引复核】。前提：参考文献真实性核验已完成、标号映射校验已完成。
输入：带引用标记的正文 + 已核过的文献清单。

【硬性约束】
1. 你不能判定"错误引用"，只能输出【相关性疑点】。综述、二次转述、概括性引用可能主题不完全对应，属合理情况。
2. 严禁主动检索、新增、推荐任何不在现有清单内的文献；不能自动替作者补引。
3. 作者自己的分析、自己的推论、自己提出的框架，不需要引用，不标记漏引。
4. 只标疑点；是否调整由作者定。

【L1 摘要级初筛（全部引用执行）】
逐句检查带 [n] 的句子：
- 提取该句核心主张 → 对照第 n 条文献的题名与摘要 → 判【匹配良好】/【疑似错配】
- 每条给相关性置信度：高 / 中 / 低
- 疑似错配要摘原句 + 文献条目 + 差异说明（是主题偏离、层级错位，还是把限定条件删了）

【L2 全文级复核（只对高风险条目执行）】
只对以下两类做全文逐句比对：
① L1 判为中/低置信度的引用；
② 涉及关键数据、方法、定义的引用（不论置信度）。
逐条定位原文具体章节/段落，输出【支撑成立 / 支撑不足 / 明显不支撑】。

【任务 B · 漏引识别（贯穿 L1）】
扫两类：
一、无引用标记但属前人成果的句子，标【潜在漏引】：
   ①经典理论、概念定义、成熟模型 ②外部统计数据、基准参数 ③"已有研究表明/学界普遍认为/某学者发现"式表述
二、**无编号转述扫描**（机械筛、人工判）：
   用转述词表扫全文，抽出"含转述词却无引用标记"的句子。
   转述词表：argues / notes / proposes / finds / shows / reports / suggests / according to /
   it has been argued / studies show / scholars / the literature / existing research /
   据统计 / 有学者 / 学界 / 相关研究 / 按照……的分类 / 借鉴……的做法
   逐句判断：是"对某文献内容或做法的转述"，还是"作者自己的归纳"？
   命中转述 → 按漏引处理（补引并占号）；确属自述 → 写明理由后放行。

【输出格式】
一、疑似错配清单：位置 | 原句 | 标号 | 文献题名 | 疑点说明 | 置信度
二、L2 全文复核表：标号 | 句中主张 | 原文对应位置 | 判定
三、潜在漏引清单：位置 | 原句 | 类型（定义/数据/前人结论/转述） | 备注
四、无编号转述扫描：命中 __ 句，其中判为漏引 __ 句、判为自述放行 __ 句（逐条给理由）
五、总体备注：本环节只筛疑点，不构成定稿结论，全部需人工复核。

【硬约束补充】
1. 不许把"综述式引用"一律判为错配——综述段落一条引文对应多个来源是正常的。
2. 不许因为"这句读起来像常识"就放过；常识最常是漏引。
3. 不许建议"删掉这条引用"来解决问题；要说明"这条引用与该句不匹配，该句需要一个什么来源"。
```

**使用提醒**：
- **必须另开会话**。写作时"顺手"看过的句子，复核时会天然认可——这是复核独立性，不是洁癖。
- L1 覆盖全部，L2 只打高风险：全部 L2 拿不到全文，也不该做（`04` 铁律：拿不到全文不当核心证据）。
- 拿不到全文的条目停在 L1，标"人工复核"，不要硬判"支撑不足"。
