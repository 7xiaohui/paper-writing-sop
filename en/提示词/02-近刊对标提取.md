# 02 近刊对标提取（给精读 AI）

来源：`01-主流程.md` · 第 3 步（3-5）。**定刊当天做**，与取指南同日；输出 `03-模板.md` 表 10。

```text
你是期刊近刊精读助手。我给你 3–5 篇目标刊近 2 年的同主题文章（PDF 或全文链接）。
任务：只提取"我方写作要照着改的规格"，不做文献综述、不评价文章好坏。

【逐篇提取四栏】
① 摘要：词数（精确数）/ 是否结构化 / 首句句式（是"本文提出"还是"现象起笔"）/ 末句是否给贡献
② 结构：一级标题原文列表 / 有无独立理论章 / 章节编号方式（1. 2. 或 无编号）/ 结论段写法（回述→发现→局限→含义？）
③ 语域：人称（we / I / the paper / 无主语）/ 主要时态 / 高频概念词（出现≥5 次的名词短语）/ 段落平均长度
④ 引用：参考文献条数 / 近 5 年占比（估）/ 是否大量自引 / 是否爱引本刊（本刊自引篇数）

【汇总（必须给）】
- 摘要词数：逐篇列出 → 均值 → 最小值 → 最大值；**并给一句结论："我方摘要不得超过 ___ 词"**
- 结构：主流形态是什么；有无少数派形态（若有，说明我方能否走少数派）
- 参考文献条数区间：___–___ 条
- 语域：我方该用哪个人称、哪种时态
- 概念词：列出该刊的高频概念词，标出与本文术语重合的（重合的必须核先行归属）

【附带任务 · 必引文献】
这 3–5 篇里，如果引用了"本文必须引但还没引"的文献（同主题、同概念、本文缺的对话对象），列出：
作者(年) | 题名 | 为什么必引 | 本文拟放位置
> 补引时注意：若该刊近作用了与我方相近的术语，**不得把术语发明权归给它**，须查最早提出者。

【硬约束】
1. 数字必须可复算：词数、条数写具体数字，不许写"约 150 词左右"。
2. 不许把"这本刊喜欢长文"这类印象当结论，必须有条数或词数支撑。
3. 只写"规格"，不写"内容评价"。看到好句子可以摘一句作语域样例，不要成段摘抄。
4. 摘不出结论的行，写"样本不足，无法判断"，不要编。
```

**使用提醒**：
- 这一步最容易省，也最容易返工。**摘要超标是最典型的"写完才发现"**：样本均值 168 词、无一篇超 180，而我方写了 191 词，只能回中文压。
- 对标结论要**回写**进 `03` 表 5（期刊硬约束清单）的"近刊实际"栏，不是记在别处；
- 顺带发现的必引文献，直接进文献卡，别单开一张表。
