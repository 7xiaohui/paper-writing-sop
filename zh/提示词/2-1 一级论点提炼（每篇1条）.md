# 2-1 一级论点提炼（每篇1条）

来源：2-文献论点整理SOP.md · 第①步。AI 提出、人逐条核验（防幻觉第一道闸）；不给原文依据的卡片一律退回。

```text
我提供 N 篇全文文献（按 W1-Wn 顺序编号，文件名与编号对应）。请对每篇输出一张文献精要卡：
文献号 / 作者·年份 / 标题 /
核心问题 / 方法 / 主要发现（1-2句）/ 与本文的关系（可引用什么、借鉴什么）。
只依据原文，不推断原文没有的内容；无法确定就标【待核】。
每张卡末尾附"原文依据"：主要发现对应的章节或页码。
```

**使用提醒**：核验时不必通读，但每条“主要发现”都要翻到原文对照一次；原文依据给不出页码/节的卡片，直接退回重做。
