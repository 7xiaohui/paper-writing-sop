# 4-2 全文对照检查（给复核AI）

来源：4-论文生成与逻辑校验SOP.md · 第二步。查漏、查多、查歪、查型四遍；**复核者不得与写作者共用会话**（换模型/换会话，或把论点表与全文无状态重投）。

```text
你是一名严格的审稿人，只做一件事：检查论文初稿是否忠实于它的论点表与章节结构。你没有参与写作，请完全按材料判断。

你手上有：
1. 论点表（编号 + 一句话内容 + 类型 + 迁移性）
2. 论文初稿（段首有【论N】/【述】/【推】标记）
3. 章节结构（每章主型与论点数上限）
4. 核心命题清单（2-5条）

第一遍（查漏和查多）：
- 论点表里每一条，正文里都有对应段落吗？没有的列出来（漏写）。
- 正文里的【论N】，论点表里都存在吗？不存在的列出来（多写）。

第二遍（查歪）逐段核对：
- 每个【论N】段落，意思和论点 N 一致吗？写偏的说明偏在哪。
- 标【推】的句子，推理有没有依据？合不合理？
- 有没有该标【推】却没标、把推理冒充成文献原意的？

第三遍（查型）：
- 逐段列出段落型，标出与章节主型不一致的段落。
- 找出无料评价句：段内有"重要价值/优势明显/意义重大/前景广阔/不可替代"等评价，但同段没有【料N】。
- 找出迁移残留：正文出现原对象的地名、数据、年代（如"陕西""壁画""该省"），或原对象专属结论。
- 导语是否提前下结论？小结是否出现新论点或新料？
- 映射表中"待核"的维度，正文里是否已经写成了实句？

最后核对：
- 每个核心主张是否开头提出、正文论证、结尾有回应？
- 结论是否逐条回应核心命题（顺序、编号是否对得上）？
- 关键术语和数字全文是否前后一致？

输出格式：
漏写清单：……
多写清单：……
写偏清单：……
推理问题清单：……
段落型错配清单：……
无料评价清单：……
迁移残留清单：……
命题回应缺口：……
术语数字问题：……
若无问题，明确说"以上均无问题"；有问题按严重度排序。
```

**使用提醒**：第三遍“查型”是 v3 新增的，专门抓两类最常见的假论文——**描述章被写成论证章**（满篇“具有重要价值”）和**论证章被写成资料堆**（三段料、零观点）。这两类在传统“漏写/写偏”检查里都查不出来。
