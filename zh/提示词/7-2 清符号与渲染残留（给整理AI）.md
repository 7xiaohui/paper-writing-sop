# 7-2 清符号与渲染残留（给整理AI）

来源：7-全篇AI与痕迹校验SOP.md · 第二步。程序性痕迹：标点三层、渲染、不可见字符。

```text
请处理论文全文的程序性痕迹。标点部分分三层，逐层报告，不要合并成一句"已统一"：

第一层·字符：英文直引号 " '、半角括号、半角逗号句号 → 换成中文弯引号“”‘’与全角标点。
  注意：从 Markdown 转来的文稿，直引号会原样保留；请按字符逐一统计，给出 ASCII 引号的数量与位置。

第二层·字形（仅 docx）：检查每一处引号、破折号、省略号所在的 run 是否带 w:hint="eastAsia"。
  缺这条属性的 run，中文标点会按西文字体渲染，占位偏窄。请报告：含中文的 run 总数、缺 hint 的数量、其中含标点的数量。

第三层·间距：中文标点前后是否有空格；半角转全角后是否留下空格。

另处理：
1. 渲染残留：Markdown 符号（**、#、-、|）、代码块标记、HTML 标签 → 清除；
2. 不可见字符：零宽空格等 → 清除。

输出：三层的统计与位置清单（字符编码层面的判断，不要凭"看起来一样"下结论），以及需要人工确认的项。
不要改动数字、引文标号、专有名词的中英文混排。
```

## 使用提醒

1. **先跑脚本，再让 AI 动手**：`python 工具/核对脚本.py punct 终稿.docx`，三层一次出结果；没装环境时再让 AI 按上面三层逐查。
2. **改源不改成品**：稿子若由 .md 或生成脚本产出，改源文件再重新导出；在 docx 里逐字手改，问题会留在源里，下次生成照旧。
3. **半角转全角时，`[1]` 这类引文标号必须保持半角**；转换完重跑 6-2 脚本，确认没把标号弄坏。
4. **判定标准要说清**：0 个 ASCII 引号、0 处汉字间半角标点、含中文的 run 100% 带 `eastAsia` hint、引号开合数相等。只说“已统一为中文标点”不算完成——这一层最容易“看着对、其实没改”。

## 为什么单列一层

实测反复出现：字符已经改成中文引号，屏幕上仍是西文占位。原因是 run 缺 `w:hint="eastAsia"`，Word/WPS 会把引号、破折号、省略号按西文字体排。

这类问题的特点是——**文本搜索搜不出来，肉眼也难判断，只有查 run 属性或量占位宽度才认得出来**。多个模型都会漏，且不会主动报告“我只改了字符没改字形”，所以要把它当成一道独立的检查，而不是“顺手改一下标点”。
