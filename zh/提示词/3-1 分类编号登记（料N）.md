# 3-1 分类编号登记（料N）

来源：3-事实资料整理SOP.md · 第②步。AI 分类编号填草稿，人确认后再定稿归档。跨论文共用一个资料库时，料号前加篇代号（如 钧瓷-料5），或每篇各建独立文件夹。

```text
请把资料文件夹里的资料逐份处理：
1. 每份资料给一个材料号（按顺序顺延：料N、料N+1…）；
2. 按内容性质分类：政策法规 / 统计数据 / 媒体报道 / 实地资料；
3. 同一数据或事实有多个来源文件的，编为同一主号，用 -1/-2/-3 区分；
4. 每条填：内容（一句话）/ 类型 / 来源 / 出处（文号或链接）/ 日期；
5. 两份内容重复的，合并保留一份，另一份标"重复"；
6. 拿不准分类或出处的，标【待定】并列出问题，等人工确认。
输出：资料表草稿 ＋ 待定问题清单。
```
