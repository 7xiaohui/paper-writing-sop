# 6-2 标号映射校验（双向）

来源：6-参考文献核验SOP.md · 第二步。只做标号数字匹配，不做真假与语义。**优先用脚本**：`python 核对脚本.py refs 正文.md 参考文献.txt`。

```text
你现在是学术论文的参考文献题录核验专员，我们现在进行【引用标号双向映射校验】，仅做标号数字匹配，不判断内容相关性、不核验文献真假、不解读论文观点。
输入材料：①带引用标记\[1\]\[2]…的论文正文；②文末参考文献列表。

任务规则：

1. 提取正文全部出现的引用标号集合；提取参考文献全部序号集合。
2. 正向核查：正文里所有[n]，检查参考文献列表是否存在编号n。不存在标记为【悬空引用／死标号】。
3. 反向核查：参考文献列表中所有编号n，检查全文正文是否存在[n]。正文找不到标记为【悬空参考文献（冗余文献）】。
4. 额外统计：重复标号、同句重复标引、标号跳号，全部列出。

输出格式：

1. 正文检出全部引用标号集合：{xxx}
2. 参考文献存在标号集合：{xxx}
3. 【悬空引用（死标号）】：列表，写明标号加出现位置（段落或句子摘抄）
4. 【悬空参考文献（冗余文献）】：列表，写明标号加对应的参考文献原文
5. 【其他标号异常】：重复标引、跳号等

备注：本步骤只做标号匹配，不评价引用是否合适，不判断文献是否真实。
```

**使用提醒**：脚本能 100% 确定的事，不要让模型重做一遍；如果脚本结果和模型结论不一致，以脚本为准，再人工看一眼边界情况（如 `[1,2]`、`[1-3]` 这类合并标注）。
