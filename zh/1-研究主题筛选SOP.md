# 1·研究主题筛选——标准操作文件

## 本项工作做什么

把题录库转化为一份《选题报告》：聚类看领域、定位缺口找创新、联网补覆盖、推演论证链、拆出章节结构。全程人机协商，每一轮经人确认后才进入下一轮。

核心原则：**题录驱动 → 领域驱动**。只用你搜到的题录分析会受“你搜了什么”限制，必须由 AI 联网补足题录外视野，才能保证方向可靠。但补充的视野必须**可核验**——AI 说“有 10 篇重要文献”不等于真有，见第 2 轮的硬规则。

## 你手上有（输入）

| 输入 | 说明 |
| -- | -- |
| 题录 N 条（带摘要） | 中文题录优先；范围可能不全，不作为唯一依据 |
| 初步方向 | 你大致想做的方向（如：河南非遗资源开发与利用，以钧瓷为例） |

前提：**论文类型已定**——面向非实证论文（政策性对策/描述分析型），研究数据少，以论证性命题为主线，无统计假设检验。

## 做完交出去（输出）

《选题报告》：

1. 方向与创新点（选定的方向、候选结论、理由与风险）；
2. 研究问题（一句话）；
3. 核心命题（2-5 条论证性主张）；
4. 章节结构（每章标注论证功能、材料来源：学/材/思、**段落主型**：论证型/描述型/推演型/混合、论点数上限、料密度下限）；
5. 学库清单（学术文献编号列表，供文献论点整理用；**进入 SOP-2 之前必须逐条通过 SOP-6 第一步真实性核验**）；
6. 材库清单（原始资料编号列表，供事实资料整理用）；
7. 覆盖度报告（题录外文献清单与缺口处置记录）＋**覆盖度线索表**（附件，格式见下）。

### 覆盖度线索表（第 2 轮产物，必交）

| 序号 | 题名 | 作者·年份 | 可核验要素（DOI/URL/馆藏号） | 建议用途 | 状态 |
| -- | -- | -- | -- | -- | -- |
| C1 | …… | 李XX 2023 | https://doi.org/…… | 补学库 W12 位置 | 可核验 |
| C2 | …… | 王XX 2021 | 无（AI 记忆，未检索到） | 仅作检索方向 | 待验证 |

**硬规则**：`状态`只有两档——**可核验**（给出 DOI、期刊官网链接、出版社页面、图书馆馆藏号，且链接能被打开）和**待验证**（无链接）。**待验证条目不得写入学库清单，只能作为人工补搜的检索方向**；可核验条目并入题录后，仍须逐条过 SOP-6 第一步，通过后才能进学库。

这条规则针对的是本流程最大的幻觉入口：覆盖度检查恰恰发生在真实性核验之前，AI 在这里“回忆”出的经典文献，是整条流水线上最容易被凭空生成的东西。

## 怎么做（五轮，每轮人确认后才进入下一轮）

### 第1轮 · 聚类与缺口（AI 基于题录）

**提示词：**

```
输入：我的题录 N 条（带摘要）。
任务：
1. 按「研究对象/问题＋方法＋结论」三要素聚类成 6-10 簇，每簇给出：
   簇名 / 代表文献 / 核心发现 / 近5年活跃度。
2. 对每簇标注位置：拥挤区(文献多结论趋同)/争议区(结论矛盾)/
   空白区(重要但少人做)/换对象区(框架成熟但未用于我的对象)。
3. 输出创新点候选 2-3 个，各附理由（为什么创新、风险是什么）。
规则：只基于题录分析；无法归入任何簇的文献进"杂簇"并说明原因。
```

**验收**：簇数 6-10 合理；每个创新点候选附了理由与风险；无题录遗漏进“杂簇”的硬伤。

### 第2轮 · 覆盖度检查（AI 联网，质检环节）

**作用**：修正题录不全导致的样本偏差。AI 补出题录外的经典/前沿文献，判断是否存在结构性缺口，决定补搜还是换题。

**提示词：**

```
我提供的题录范围可能不全，请做覆盖度检查：
1. 联网检索本方向近5年的经典与前沿文献（中文为主），列出题录外
   的重要文献 10-20 篇，按相关度排序。
2. 对照检查：我的题录是否存在结构性缺口——某关键概念、某重要
   流派、某近3年关键进展完全没覆盖？
3. 若存在缺口，给两种处置：①建议补搜（扩哪些主题词/加哪个库/
   补哪几年）；②若缺口意味着方向已被证伪或过时，明确建议换主题。
4. 覆盖度确认无致命缺口后，才进入下一步。若需补搜，我等你的新题录。

硬性要求（防编造）：
A. 每条文献必须给出可核验要素：DOI、期刊官网/出版社链接、或图书馆
   馆藏号，三者至少其一；链接必须是你本次真实检索得到的地址。
B. 给不出可核验要素的，不要写进"文献清单"，只写进"待验证线索"，
   并注明"未检索到，仅作方向"。
C. 禁止用"某学者曾指出""有研究认为"代替具体题录。
D. 输出两张表：
   表1 可核验线索（序号/题名/作者·年份/可核验要素/建议用途/状态=可核验）
   表2 待验证线索（序号/题名/作者·年份/线索说明/状态=待验证）
E. 表1 中你无法确认的条目，宁可放进表2，不要凑数。
```

**边界**：AI 联网检索的质量受引擎限制，它的职责是**提示缺口**，不是替你定题。是否补搜、补什么，决定权在人。检索不到就如实记录“检索不到”，这不算失败；编一条假的凑数才是失败。

### 第3轮 · 方向确认（人机协商，无提示词）

- 人从 2-3 个创新点候选中**选定 1 个**；
- 选中即锁定，此后所有步骤只围绕它，不再发散；
- 若候选都不满意，回到第1-2轮重新分析（记录原因，防重复空转）。

### 第4轮 · 论证链推演（先链后章）

**提示词：**

```
创新点已确认。请推演本文论证链，逐环说明，不要直接列章节：
为什么研究（背景→缺口→研究问题，1句）→
用什么看（概念界定→理论工具→分析框架）→
对象怎么展开（现状→问题→原因→对策）。
```

**核心约束**：先有论证链，再拆章节。禁止直接列目录——直接列章节等于“摘凑框架”。

**补充要求**：论证链每一环要写清“这一环由什么材料支撑（学/材/思）”和“上一环到这一环的推进关系（因果/递进/并列）”。**并列关系要单独标出**——整条链如果全是并列，说明它其实不是一个论证，而是几个话题的拼盘，这时应回到第 1 轮换创新点。

### 第5轮 · 章节拆解

**提示词：**

```
按已确认的论证链拆解为章节。每章必须标注：
论证功能（这章在论证链里干什么）/ 材料来源（以学为主/以材为主/思论推理）。
同时给每章定"段落主型"，四选一：
- 论证型：以观点推进为主，论点密集（如理论、机制、综述评价）；
- 描述型：以事实陈述为主，论点很少（如现状、资源、优势、案例）；
- 推演型：以作者分析为主（如原因、对策）；
- 混合：章内分段处理，标明哪几节是哪种。
并给出：论点数上限（论证型 3-6/节；描述型 0-1/节；推演型 1-3/节）
与料密度下限（描述型每 300 字至少 1 个【料N】）。
若某章"以材为主"却挂了 5 条以上论证型论点，说明章节功能没说清，先回来改论证链。
```

- **学** = 学术文献（进参考文献表）
- **材** = 原始资料（政策/文件/报道/数据/访谈，作资料来源，不进参考文献表）
- **思** = 推理分析（借文献概念与维度做演绎，落到研究对象）

## 通过标准

| # | 检查项 | 通过标准 |
| - | -- | -- |
| 1 | 研究问题 | 一句话，对象＋动作明确（例：河南钧瓷非遗资源如何高质量开发与利用） |
| 2 | 核心命题 | 2-5 条论证性主张（非可检验假设），绪论提出→正文论证→结论回应 |
| 3 | 覆盖度 | 覆盖度报告在手；**覆盖度线索表的表1 每条都有可核验要素**；表2 条目未混入学库 |
| 4 | 学库真实性 | 学库清单已交 6-1 核验（或已排入下一步），结论为“可信”的才进 2；存疑的单独标注，不混入 |
| 5 | 章节三问 | 每章有不可替代功能？章间有递进？每章材料有着落（学/材至少一类）？ |
| 6 | 材料分库 | 每章标清以学为主/以材为主/思论推理，杜绝后文混用 |
| 7 | 段落主型 | 每章主型已定（论证/描述/推演/混合），并给出论点数上限与料密度下限；“以材为主”的章不得挂 5 条以上论证型论点 |

7 条全过，本项工作通过。

## 注意事项

1. **人机协商是硬约束**：5 轮按顺序走，每轮人确认后才进入下一轮；AI 不得跳步。
2. **命题≠假设**：本 SOP 面向非实证论文，命题是论证性主张，检验手段是“论证链完整＋材料支撑充分＋结论呼应”，不是统计检验。
3. **学/材分开是强制**：分开的是管理（编号、核验、清单），不是写作。正文段落层面两者必须结合（引述学库文献时，末句落到研究对象，用材库事实）。
4. **覆盖度检查的定位**：提示缺口，不替你定题；它给出的“题录外文献”只有带链接的才算线索，无链接的只是问路。
5. **架构调整纪律**：任何章节增删改，AI 必须说明“动了论证链的哪里”，不许只报目录变化。
6. **不要在这一步追求文献量**：学库 20-30 篇扎实可用，胜于 50 篇凑数；数量在 SOP-2 按需扩充。
