# 工具使用说明

配套 `0-总体SOP` 的“脚本优先”原则：凡是字符串比对、数字比对、标号映射、文档属性清理，先跑脚本，模型只负责解释差异。

## 环境

- Python 3.8 及以上（本机验证版本：3.14）
- 仅 `props` 子命令需要 `python-docx`：`pip install python-docx`
- 其余子命令只用标准库，无需联网、无需安装其他包

## 命令一览

| 子命令 | 用途 | 对应 SOP | 示例 |
| -- | -- | -- | -- |
| `refs` | 引用标号双向映射 | 6 号第二步 | `python 核对脚本.py refs 正文.md 参考文献.txt` |
| `numbers` | 正文数字清单＋底表比对 | 5 号第④步 | `python 核对脚本.py numbers 正文.md 资料表.md` |
| `mats` | 【料N】抽取与计数 | 5 号第①步 | `python 核对脚本.py mats 正文.md` |
| `marks` | 【…】过程标记扫描 | 7 号第一步 | `python 核对脚本.py marks 终稿.md` |
| `props` | docx 文档属性查看/清理 | 7 号第二步、8 号匿名化 | `python 核对脚本.py props 论文.docx --author 张三 --title 标题` |

在文件所在目录打开 PowerShell，路径含空格时用引号包住。

## 各命令的输入要求

**refs**
- 正文：引用写成 `[1]`、`[1,2]`、`[1-3]`（半角方括号、逗号、连字符；全角方括号也能识别）。
- 参考文献：每行以 `[1]`、`［1］`、`1.`、`1、` 或 `1 ` 开头。
- 输出四类：悬空引用／冗余文献／重复标引／跳号。发现任一即退出码 1。

**numbers**
- 正文与底表都用纯文本或 Markdown；docx 请先另存为 txt 或复制到 md。
- 不给底表时，只输出正文全部数字清单（含行号与上下文），用于人工逐条对照。
- 给底表时，输出“正文有、底表无”的差异项。**年份、章节号、编号也会被当作数字**，落到差异清单里属正常，逐条确认即可。

**mats**
- 识别 `【料1】`、`【料2-2】`，按材料号计数并给行号。

**marks**
- 识别全部 `【…】`（30 字以内），列出现次数与位置。
- 交付前应跑到“未发现【…】类标记”为止。

**props**
- 先 `--dry-run` 看当前字段，再正式写入。
- 支持改 `author`、`last_modified_by`、`title`，`--clear-meta` 清空 subject/keywords/comments/category。
- 不处理 Word 的“自定义属性”（自定义属性需在 Word 里手动清）；PDF 元数据也需另用工具。

## 退出码

| 码 | 含义 |
| -- | -- |
| 0 | 未发现问题 |
| 1 | 发现问题（存在悬空引用/冗余文献/跳号，或还有过程标记） |
| 2 | 参数或环境错误（如缺 python-docx） |

## 边界

- 脚本**不做**文献真假判断（6-1）、**不做**引用语义判断（6-3）、**不做**查重——这些仍需要人或联网核验。
- 脚本结果是“差异清单”，不是“判决书”：数字差异可能是合理的年份表述，标号差异可能是合并标注，逐条确认后再改。
- 首次使用建议先拿一份旧稿跑一遍，确认输出格式符合你的写作习惯，再接入正式流程。

## 本机实测记录（2026-10-25）

用样稿验证过：`refs` 正确报出悬空引用 `[4]`、冗余文献 `[5]`、重复标引 `[1]`、跳号 `4`；`numbers` 正确列出 12.5/300/2022 并标出底表缺 2022；`mats` 正确计出 料1、料2-2；`marks` 报出 4 处标记；`props` 成功把作者/最后修改者/标题改掉并回读确认。
