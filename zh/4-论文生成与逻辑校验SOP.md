# 4·论文生成与逻辑校验——标准操作文件

## 本项工作做什么

分三段：先把“每章用哪些论点”写成忠实、通顺的正文；再对照论点表双向检查；最后对核心命题做反方检验。

**核心修正（v3）**：不是每一段都有论点。论文要按**段落型**写——论证段证明判断、描述段陈述事实、推演段推出结论。型写对了，AI 才不会把“描述”写成“论证”（空话），也不会把“论证”写成“资料堆”（没观点）。

本文件自包含，可单独执行；若从中间进入（例如只改一章），先补齐下面“输入”清单再动笔。

## 段落分型（本 SOP 的核心）

| 型 | 段首标记 | 有没有主张 | 靠什么支撑 | 典型章节 | 单段字数 |
| -- | -- | -- | -- | -- | -- |
| 论证段 | 【论N】 | 有，且必须来自论点表（论证型） | 学库转述＋（可选）料＋推 | 理论、机制、综述评价 | ≤300 |
| 描述段 | 【述】 | 无主张，只陈述事实 | 至少 1 个【料N】 | 现状、资源禀赋、优势、案例 | ≤300 |
| 推演段 | 【推】 | 有，但属作者自己的分析 | 前文论点/料＋逻辑 | 原因分析、对策推导 | ≤250 |
| 导语 | 无标记（章首段） | 无 | 复述本章论点与材料清单 | 每章第一段 | ≤150 |
| 小结 | 无标记（章末段） | 无（只回收） | 回收本章论点 | 每章最后一段 | ≤250 |

**一句话判定**：这段是在“证明一个判断”（论证）、“报告一个事实”（描述）、还是“推出一个结论”（推演）？

**命名约定**：章的主型叫“论证型/描述型/推演型/混合”，段的型叫“论证段/描述段/推演段”，两层不要混用，看名字就知道在说章还是在说段。

**三条硬规则**：

1. **描述段禁止无料评价**。“具有重要价值”“优势明显”“意义重大”“前景广阔”这类句子，要么删，要么改成有料的陈述，要么另起推演句标【推】。
2. **论证段必须落到本文对象**。转述完文献就停住，等于替别人写综述。
3. **推演段必须指向前文依据**（“由【论12】与【料5】可知……”），不能凭空推。

**两类特殊段**：

- **导语**只列本章要论证的论点、要用的材料，不新增观点、不提前下结论；
- **小结**只回收本章论点（逐条对应），不外推、不引入新料、不出现“综上所述，本文具有重大意义”。

## 你手上有（输入）

1. **论点表**：编号＋一句话内容＋类型（论证型/工具型）＋迁移性（对象专属/通用维度/通用机制）；
2. **挂载清单**（章节→论点号）；
3. **章节结构**：每章的论证功能、材料来源（学/材/思）、**段落主型**（论证型/描述型/推演型/混合）、论点数上限、料密度下限；
4. **对象映射表**（换对象时必填，见第零步）；
5. **资料表**（料N＋出处）；
6. **本文研究对象说明**；
7. **核心命题清单**（来自《选题报告》，2-5 条）。

## 做完交出去（输出）

- **论文初稿**：逐节写完的正文，段首按型标【论N】/【述】/【推】，事实句末标【料N】；
- **对照检查结果**：漏写、多写、写偏、推理问题、**段落型错配、无料评价、迁移残留**六类清单；
- **命题反例回应表**；
- **对象映射表的填写记录**（含待核清单及其处置）。

## 怎么做

### 第零步：对象映射（换对象时必做；同对象写作可跳过）

换题材的典型场景：原文章写“陕西壁画的优势”，你要换成“钧瓷的优势”。**能搬的只有维度，不能搬结论和证据**。

做法：从原文章中抽出 4-8 个“维度/评价框架”（如历史纵深、视觉辨识度、工艺独特性、产业转化、传承机制），逐个填：

| 维度 | 原对象证据（仅参照，禁入正文） | 本对象对应事实 | 料号 | 可写性 |
| -- | -- | -- | -- | -- |
| 历史纵深 | 汉唐墓室壁画…… | （待填） | 料3 | 待核 |
| 视觉辨识度 | 矿物颜料形成独特色系 | （待填） | 料5 | 待核 |

规则：

- 原对象证据列只用于理解维度，**一个字都不能进正文**；
- 本对象事实必须有料号；没有料就写“待核｜缺什么｜建议来源”，**不许用常识或记忆补**；
- 可写性三档：可写（有料）/ 待核（缺料）/ 无（本对象不适用，写理由）；
- 表经人确认后才允许开写；“无”的维度直接删掉，并在章导语里不出现。

模板：`模板\对象映射表.md`；示例：`示例-陕西壁画迁移到钧瓷.md`。

### 第一步：按型写正文

**先计划，后成文**。每节动笔前先交一张“本节写作计划”：

| 段序 | 段落型 | 锚点（论点号/维度） | 料号 | 一句话内容 |
| -- | -- | -- | -- | -- |
| 1 | 【论12】 | 论点12 | — | 钧瓷釉色的不可复制性 |
| 2 | 【述】 | 视觉辨识度 | 料5 | 铜红釉呈色随窑位变化 |
| 3 | 【推】 | 承上 | — | 由此形成独立审美标识 |

计划确认后再写正文。这样“哪段有论点、哪段只有事实”在一开始就定了，不靠写的时候即兴决定。

**A. 论证段（【论N】）**

1. 只写该论点，不新增、不合并、不偷换；
2. 转述是默认，按文献原意写，不标记号；
3. 段末必须落到本文研究对象，不能停在原文献的例子上；
4. 凡自己加的推理、比较、引申，句子开头标【推】；
5. 每段 3-6 句、≤300 字；一段只证一个论点。

**B. 描述段（【述】）**

1. 只陈述事实，不写主张、不写评价；
2. 全段至少 1 个【料N】，句末标注；同一事实多来源用【料5-1】【料5-2】；
3. 禁止无料评价（见上“三条硬规则”）；
4. 数字与料一致，拿不准标【待核】；
5. 顺序按“对象→事实→（可选）一句限定”，不要写成资料摘抄。

**C. 推演段（【推】）**

1. 开头指向依据：“由【论12】与【料5】可知……”；
2. 一段只推一步，不连环推；
3. 不引入新事实，不把推演写成文献原意。

**D. 导语 / E. 小结**：按上表两条规则写，不新增内容。

**F. 缺料回路（关键）**

映射表是“待核”，或正文需要的料不存在时：

- **不要编、不要联网现搜、不要凭记忆写**；
- 输出占位：`【待核｜缺什么｜建议来源｜检索式】`，例如 `【待核｜钧瓷2023年产值｜许昌市统计年鉴2023｜词=钧瓷 产值 分行业】`；
- 该段不写正文，等三种处理之一：①回 3 号补料；②换一个维度；③删该维度并说明对论证链的影响。

**G. 三个特殊部分**

- **摘要**：目的—方法—结果—结论四句；不得出现正文没有的数字或结论；不写空泛意义句；
- **引言**：末段逐条列出核心命题（编号与命题清单一致），不能只写“从三个方面展开”；
- **结论**：逐条回应核心命题（顺序一致），再写局限与展望；不得引入正文未论证的新主张。

写完一节马上自查：

- 段落型是否与本章主型一致？（描述章里出现【论N】主张，说明写偏了）
- 论证段的【论N】是否都在论点表里？
- 描述段是否都有【料N】、有没有无料评价？
- 推演句是否都标【推】且指向前文？
- 映射表的待核项，是否都变成了占位，而不是被“写得像真的”？

### 第二步：全文对照检查

**第一遍 · 查漏和查多**：

- 论点表里每一条，正文里都有对应段落吗？没有 → 漏写清单；
- 正文里的【论N】，论点表里都存在吗？不存在 → 多写清单。

**第二遍 · 查歪（复核 AI 逐段核对）**：

- 每个【论N】段落，意思和论点 N 一致吗？写偏的说明偏在哪；
- 标【推】的句子有依据吗？有没有该标【推】却没标、把推理冒充成文献原意的？

**第三遍 · 查型（v3 新增）**：

- 段落型与章节主型是否一致？描述章是否被写成了论证章（或反之）；
- 有没有无料评价句（列表见上）；
- 换对象写作时，正文有没有残留原对象的地名、数据、年代（“迁移残留”）；
- 导语有没有提前下结论，小结有没有新论点或新料；
- 映射表里“待核”的维度，正文里是否已被写成实句。

**另外核对**：

- 每个核心主张是否“有头有尾”（提出→论证→回应）；
- 结论是否逐条回应核心命题；
- 关键术语和数字全文是否一致。

**复核独立性（硬要求）**：复核者不得与写作者共享上下文。换模型、换会话，或把论点表＋全文重新完整粘一遍做无状态重投。

### 第三步：命题反方检验（论证强度）

前两步验证“正文是否忠实、型是否正确”，默认论点表是对的。这一步专门攻击这个默认。

对每条核心命题逐条做四件事：

1. **写最强反驳**：反例、竞争解释、范围过宽、因果倒置、“证据只是相关性”；
2. **判断证据强度**：学库转述、材库事实，还是纯推理？纯推理标“弱”；
3. **标注正文是否回应**：有回应给位置；没回应写“未回应”；
4. **给处置结论**（四选一）：改命题（回 1 号）/ 限定范围 / 补论据（回 2、3 号）/ 维持并在局限中明写。

处置由人拍板，AI 只把问题摆出来。允许“维持”，不允许“假装反驳不存在”。

## 通过标准

- 漏写 0 条、多写 0 条；
- 写偏段落已改，推理问题已处理；
- **段落型与章节主型一致**；描述段全部有料、无无料评价；
- **换对象写作时无迁移残留**（无原对象地名/数据/年代）；
- **对象映射表无未处理项**：待核的要么补了料，要么删了维度并记录影响；
- 每个核心主张有头有尾，结论逐条回应命题，术语数字一致；
- 命题反例回应表每条都有反驳、证据强度、处置结论，无“待定”；
- 处置为“改命题/补论据”的，已完成返工并重跑了受影响的检查。

以上全过，本环节通过，初稿进入参考文献核验（6 号后半）与事实校验（5 号）。

## 注意事项

- 本环节**不做** AI 率检测、不做查重；
- 【论N】【述】【推】【料N】是临时夹注，SOP-7 统一清除；
- 遇到对不上的情况（论点互相矛盾、论点与对象无关、对照表缺信息），停下来报告，不要自作主张改论点；
- **复核独立性**：4-2 的“查歪/查型”和 4-3 的反驳，必须由不同会话/模型给出；
- **不要用“描述段”逃避论证**：描述段是“报告事实”，不是“不写观点”的借口；该论证的章如果写满【述】，说明论点表或挂载清单有问题，回 2 号查；
- **不要用“论证段”包装事实**：把两句料塞进“由此可见”，不是论证，是伪装。

## 提示词

### 提示词1 · 逐节扩写（给写作 AI）

```
你是一名学术论文写作者。按"段落分型"逐节写初稿。记住：不是每一段都有论点。

你手上有：
1. 论点表（编号/内容/类型/迁移性）
2. 挂载清单（章节→论点号）
3. 章节结构（每章主型：论证型/描述型/推演型/混合；论点数上限；料密度下限）
4. 对象映射表（维度→本对象事实→料号→可写性）
5. 资料表（事实材料，每条有【料N】和出处）
6. 本文研究对象说明

第一步：先出"本节写作计划"，不要直接写正文。
表格：段序 | 段落型（【论N】/【述】/【推】） | 锚点（论点号或映射表维度） | 料号 | 一句话内容
规则：论证段锚点必须是论点号；描述段锚点写映射表维度、料号必填；推演段写"承上"并说明依据哪一段。
我确认计划后，你再写正文。

第二步：按型写正文
A 论证段（段首【论N】）
1 只写该论点，不新增、不合并、不偷换；
2 转述默认，不标记号；
3 段末落到本文研究对象，不停在原文献例子上；
4 自己加的推理标【推】；
5 每段 3-6 句、不超过 300 字。
B 描述段（段首【述】）
1 只陈述事实，不写主张、不写评价；
2 至少 1 个【料N】，句末标；
3 禁止无料评价："具有重要价值/优势明显/意义重大/前景广阔"等；
4 数字与料一致，拿不准标【待核】。
C 推演段（段首【推】）
1 以"由【论N】/【料N】可知"开头，指向依据；
2 一段只推一步；
3 不引入新事实，不伪装成文献原意。
D 导语（章首）：只列本章论点与材料，不新增、不下结论。
E 小结（章末）：只回收本章论点，不外推、不引入新料。

第三步：缺料处理
映射表"待核"或需要的料不存在时：不要编、不要联网搜、不要凭记忆写。
输出占位：【待核｜缺什么｜建议来源｜检索式】，该段不写正文，等我补料或改维度。

第四步：写完一节自查
1 段落型是否与章节主型一致？
2 论证段的论点号是否都在论点表内？
3 描述段是否都有【料N】、有无无料评价？
4 推演句是否都标【推】且指向前文？
5 映射表待核项是否都变成了占位，而不是被写成实句？
```

### 提示词2 · 全文对照检查（给复核 AI）

```
你是一名严格的审稿人，只做一件事：检查论文初稿是否忠实于它的论点表与章节结构。你没有参与写作，请完全按材料判断。

你手上有：
1. 论点表（编号 + 一句话内容 + 类型 + 迁移性）
2. 论文初稿（段首有【论N】/【述】/【推】标记）
3. 章节结构（每章主型与论点数上限）
4. 核心命题清单（2-5条）

第一遍（查漏和查多）：
- 论点表里每一条，正文里都有对应段落吗？没有的列出来（漏写）。
- 正文里的【论N】，论点表里都存在吗？不存在的列出来（多写）。

第二遍（查歪）逐段核对：
- 每个【论N】段落，意思和论点 N 一致吗？写偏的说明偏在哪。
- 标【推】的句子，推理有没有依据？合不合理？
- 有没有该标【推】却没标、把推理冒充成文献原意的？

第三遍（查型）：
- 逐段列出段落型，标出与章节主型不一致的段落。
- 找出无料评价句：段内有"重要价值/优势明显/意义重大/前景广阔/不可替代"等评价，但同段没有【料N】。
- 找出迁移残留：正文出现原对象的地名、数据、年代（如"陕西""壁画""该省"），或原对象专属结论。
- 导语是否提前下结论？小结是否出现新论点或新料？
- 映射表中"待核"的维度，正文里是否已经写成了实句？

最后核对：
- 每个核心主张是否开头提出、正文论证、结尾有回应？
- 结论是否逐条回应核心命题（顺序、编号是否对得上）？
- 关键术语和数字全文是否前后一致？

输出格式：
漏写清单：……
多写清单：……
写偏清单：……
推理问题清单：……
段落型错配清单：……
无料评价清单：……
迁移残留清单：……
命题回应缺口：……
术语数字问题：……
若无问题，明确说"以上均无问题"；有问题按严重度排序。
```

### 提示词3 · 命题反方检验（给审稿人 AI）

```
你是一名以严苛著称的期刊审稿人。任务不是夸奖，也不是全面评审，只做一件事：
对下面每条核心命题，写出它最可能被推翻的方式。
```
