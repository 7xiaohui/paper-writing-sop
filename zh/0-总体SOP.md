# 0·总体SOP——AI辅助中文论文写作流水线

## 本文件做什么

把 8 份标准操作文件串成一条流水线：回答三件事——**各份的输入从哪来、输出往哪去、用什么编号对接**；哪些步骤必须按顺序、哪些可以单独拧出来用；全体系通用的编号、标记与纪律是什么。每份 SOP 内部已经自包含（单独拿给不了解前情的 AI 也能执行），本文件只负责**环节之间的衔接**，不重复各 SOP 的操作细节。

**本流程不是线性的**：允许从任何一环进入、允许跳跃、允许只跑一段。跳跃时按各 SOP 的“输入”清单补齐前置产物即可（见“单独执行与跳跃执行”）。

适用论文类型：**非实证论文**（政策性对策、描述分析、理论构建类），以论证性命题为主线，无统计假设检验。若写实证论文，可沿用 1/2/3/6/7/8，但 SOP-5 需替换为统计分析核验。

## 八份SOP一览

| 编号 | 名称 | 做什么 | 关键产物 | 关键编号/标记 |
| -- | -- | -- | -- | -- |
| 1 | 研究主题筛选 | 题录 → 选题报告（聚类、覆盖度、论证链、章节拆解＋段落主型） | 《选题报告》 | 学库清单、材库清单、覆盖度线索表 |
| 2 | 文献与论点整理 | 全文文献 → 两张表并挂载到章节（学库线） | 文献精要表、论点表（含迁移性）、挂载清单 | W1-Wn、论点 1-N |
| 3 | 事实资料整理 | 原始资料 → 分类编号登记（材库线，与 2 并列） | 资料表 | 料1、料1-2 |

## 推荐的执行顺序（全流程）

```
1 研究主题筛选（含章节段落主型）
  ↓（选题报告：方向/命题/章节/主型/学库清单/材库清单/覆盖度线索表）
6 参考文献核验 —— 只做第一步·真实性（学库清单逐条过，未通过的不得进 2）
  ↓
2 文献与论点整理（W1-Wn + 论点表含迁移性 + 挂载清单）
3 事实资料整理（料N） ← 与 2 并列，可并行
  ↓
4·第零步 对象映射（换对象时必做）
  ↓
4 论文生成（按段落型：论证/描述/推演）→ 双向检查 → 命题反方检验
  ↓ 反方检验若发现命题立不住 → 回 1 改命题，或回 2 补论点，不硬写
6 参考文献核验 —— 补做第二步·标号映射（用脚本）＋第三步·语义复核
  ↓
5 事实与数据校验（核【料N】每条）
  ↓
7 全篇AI与痕迹校验（清标记、清痕迹、AI语言特征自检、AI率检测、降AI率、回归抽检、查重）
  ↓
8 投稿适配（期刊要求对照、格式落地、匿名化、投稿包）
```

**4-3 是硬门禁，清稿只能做一次（v5 强调）**：4-3 命题反方检验不通过，不得进入 6 号后半、5 号与 7 号。7 号的清标记、清痕迹必须在 **4-3、6-3、5-2 全部结束之后**、且**全程只做一次**；提前清稿会导致改稿后重复清、重复导出，还可能把改前版本误当终稿。4-3 的处置若为“改命题／限定范围／补论据”，必须回 1 号或 2 号返工，并**重跑受影响的 4-2 检查**，不得只在表里打勾。

**6 号为什么拆成两段用**：它的第一步（真实性核验）只需要清单，放在写作前做，保证“要提炼的文献是真的”；第二步（标号映射）和第三步（语义复核）需要带引用标记的正文，只能放在论文生成之后。

**4 号为什么有第零步和分型**：换题材时（如“陕西壁画”→“钧瓷”），能搬的只有维度，搬不动结论和证据。对象映射表把“原对象的证据”挡在门外，把“本对象的事实”逐条挂上料号；段落分型则决定“这段到底该不该有论点”——描述段没有论点不是缺陷，是章节性质。

**顺序逻辑**：1→2→3 是“备料”，4 是“成文”（含映射、分型、反方检验），6 后半→5→7 是“三道校验”，8 收口。

## 全体系通用的编号与标记（接口契约）

**两条材料线，从编号到正文标记全程对应：**

| 材料线 | 入库表 | 编号 | 正文标记 | 作用 |
| -- | -- | -- | -- | -- |
| 学库（学术文献） | 文献精要表（SOP-2） | W1-Wn | 【论N】段首（转述该论点） | 论点可溯源到文献 |
| 材库（事实资料） | 资料表（SOP-3） | 料1、料1-2 | 【料N】句末（事实材料引用） | 事实可溯源到原件 |
| 思论（推理） | 不建表 | 无编号 | 【推】（推理句） | 标出推演过程，供人复核 |

**段落型标记（v3 新增）**：

- 【论N】＝论证段，段首标，N 是论点号；
- 【述】＝描述段，段首标，只陈述事实，段内至少一个【料N】；
- 【推】＝推演段/推理句，句首标；
- 导语（章首）与小结（章末）**不标记**，靠位置识别。

**其他规则**：

- 1 号《选题报告》里的“材料来源（学/材/思）”，到正文就是三类标记：学→【论N】、材→【料N】、思→【推】；
- **论点和文献的关系在论点表内记录**（来源文献＋位置两列），正文只见【论N】，不见 W 编号；
- **临时标记全体系通用**：【待核】＝信息不足禁编造（生成期）；【待定】＝分类等人工确认（资料整理期）；【待补出处】＝校验期存疑但正文必需（SOP-5 通过标准）；【待核｜缺什么｜建议来源｜检索式】＝缺料占位（SOP-4）。全部在 SOP-7 统一清除，清理前用 `工具\核对脚本.py marks` 扫一遍确认零残留；
- 论点表追加式编号（不重排）；料号顺延追加；同一数据多来源用 -1/-2；
- **编号命名空间**：W 号、论点号、料号只在“单篇论文”内唯一。跨论文复用时加篇代号（如 `钧瓷-W7`、`钧瓷-料5`），或为每篇论文建独立文件夹；
- **文件命名**：文献 `W7-王XX-2019-短标题.pdf`；资料 `料5-2.pdf`；稿件 `论文_vN_日期.docx`。
- **凡正文引述文献，一律占号进表（v5 新增）**：不论是否承担论证，转述型与论点型**共用同一套顺序编号**；只做事实陈述的转述不得替代论点。这条是“漏引”的根因所在——纯转述绕过论点映射，最容易整条文献未进表；
- **直引比例 1%–5%（v5 新增）**：正文须有与文献的真实接触面，下限至少 4 处、合计约 70 汉字；每个主要论点至少 1 处关键定义或判断的直引。清稿前做一次“**引号内容审计**”：全文引号逐处归类为①文献原文直引②自建概念／术语③政策材料原文，出三列表；**文献直引为 0 不得进清稿**；超过 10% 会推高查重，须压缩。

## 单独执行与跳跃执行（本流程不是线性的）

**每份 SOP 都是自包含的**：有自己的“输入/输出/通过标准”，单独拿给一个不了解前情的 AI 也能跑。所以可以跳跃，不必从 1 走到 8。

跳跃的规则只有一条：**先补齐该 SOP 的“输入”清单**。缺输入时 AI 不会报错，它会用默认值补——这就是幻觉的来源。

常见跳跃场景：

| 你想做的事 | 直接跑 | 需要先补的输入 |
| -- | -- | -- |
| 只重写某一章 | 4-1（单节） | 2 号论点表＋挂载清单、1-4 章节主型、对象映射表、资料表 |
| 只改换题材（壁画→钧瓷） | 4-0 → 4-1 | 2 号论点表的“迁移性”列、钧瓷的资料表 |
| 文献不够、只补学库 | 6-1 → 2-1/2-2 | 现有题录、选题报告 |
| 数据被质疑、只补事实 | 3-1 → 5-2 | 资料文件夹、资料表 |
| 只查引用规范 | 6-2（脚本）→ 6-3 | 带 [n] 的正文、参考文献清单 |
| 只做投稿前检查 | 7-1 → 7-2 → 8-1 | 定稿、期刊要求 |
| 被拒改投 | 8-1 → 8-2 | 定稿、新刊要求（重做要求清单，不套旧模板） |

**跳跃的代价**：省掉上游环节，就要自己承担上游没做的检查。例如跳过 6-1 直接写，文献可能是假的；跳过 4-0 直接换题材，正文里会残留原对象的地名和数据。

## 可单独拧出执行的工作（不按顺序也能用）

1. **SOP-6 第一步·真实性核验**：任何阶段都能跑——对已下载文献清单、对选题阶段的学库清单、对投稿前终稿都适用；
2. **SOP-4 第零步·对象映射**：换题材前单独跑，产出一张“维度→本对象事实→料号”的表，先看料够不够；
3. **SOP-4 第三步·命题反方检验**：只要核心命题和正文（甚至只有选题报告）就能跑，适合投稿前自审；
4. **SOP-6 第二、三步**：只要有“带引用标记的正文＋文献清单”就能跑；第二步先用 `工具\核对脚本.py` 出差异表；
5. **SOP-5 事实与数据校验**：对任何含【料N】的稿子独立可跑；
6. **SOP-7 全篇AI与痕迹校验**：定稿前必做，也可在初稿阶段先跑“清过程标记”；
7. **SOP-8 投稿适配**：可对任何已成稿的论文独立跑，包括别人写的、改投他刊的稿子；
8. **SOP-2 文献论点整理**：只要有已下载文献和确定的方向就能独立做；
9. **SOP-1 选题成果**：选题报告可跨论文复用，但编号需加篇代号。

**什么时候不建议单独拧**：4-1 必须依赖论点表、主型、映射表和资料表（缺一个就会跑偏）；3 号建议在写作前做；8 号必须在 7 号之后做。

## 提示词速查使用说明

全部提示词在 `提示词\`，命名 `N-序号 名称.md`。每份文件头部标注“来源 SOP 的哪一步、什么时机用”，正文是可直接复制的提示词原文。

**编号与轮次的关系**：1-1/1-2 对应选题第 1、2 轮，1-3/1-4 对应第 4、5 轮——**第 3 轮（方向确认）是纯人工决策，按设计没有提示词**，不是漏文件。同理，4-0 是 4 号的“第零步”，不属于 4-1/4-2/4-3 的序号体系。

| 提示词 | 前置条件 | 产出 | 人是否必须确认 |
| -- | -- | -- | -- |
| 1-1 聚类与缺口 | 题录 N 条（带摘要） | 簇、创新点候选 2-3 个 | 必须：确认簇划分与候选 |
| 1-2 覆盖度检查 | 题录 ＋ 1-1 结果 | 覆盖度线索表（题录外文献＋链接） | 必须：决定补搜或换题 |
| 1-3 论证链推演 | 已确认的方向 | 论证链（先链后章） | 必须：确认后才拆章 |
| 1-4 章节拆解 | 已确认的论证链 | 章节结构＋学/材/思＋主型＋密度 | 必须：确认后进 2、3 |
| 2-1 一级论点提炼 | 全文文献＋选题结果 | 文献精要表草稿（W1-Wn） | 必须：人逐条核验 |
| 2-2 二级论点拆解 | 2-1 核验通过 | 论点表草稿（1-N，含迁移性） | 抽检 10-20% |
| 3-1 分类编号登记 | 已下载的资料原件 | 资料表草稿＋待定清单 | 必须：确认分类、编号、原件 |
| 4-0 对象映射 | 原对象文章＋本对象资料表 | 对象映射表＋待核清单 | 必须：确认可写性 |
| 4-1 逐节扩写 | 论点表＋挂载＋主型＋映射表＋资料表 | 写作计划＋分型正文 | 必须：计划与每节确认 |
| 4-2 全文对照检查 | 4-1 全部完成 | 漏写/多写/写偏/型错配/无料评价/迁移残留 | 必须：按清单修正 |
| 4-3 命题反方检验 | 4-2 通过 | 命题-反例-回应表 | 必须：决定处置 |
| 5-1 材料登记与分类 | 初稿＋资料表 | 材料登记表 | 人确认补登记项 |
| 5-2 分类核验 | 5-1 完成＋可联网 | 核验表＋核验日志 | 必须：存疑、不实由人定 |
| 6-1 真实性核验 | 参考文献清单（或学库清单） | 真实性报告 | 必须：疑似伪造优先处理 |
| 6-2 标号映射校验 | 正文＋清单 | 悬空/冗余/重复/跳号 | 按脚本差异修正 |
| 6-3 语义相关性复核 | 6-1、6-2 完成 | 疑点清单（L1/L2） | 必须：疑点人工定 |
| 6-4 精简快速版 | 同 6-1 | 真实性报告（快速版） | 必须 |
| 7-1 清过程性标记 | 初稿 | 标记清单＋清理稿 | 人逐条看删留 |
| 7-2 清符号与渲染残留 | 7-1 之后 | 替换清单＋清理稿 | 人看无法判断的项 |
| 7-3 降AI率改写 | AI 率检测结果 | 改写后段落 | 必须：人拍板 |
| 7-4 改写后回归抽检 | 7-3 完成 | 抽检记录 | 必须：通过才进查重 |
| 8-1 期刊要求对照 | 定稿＋期刊须知/模板 | R1-Rn＋差异清单 | 必须：确认清单完整 |
| 8-2 投稿前终检与投稿信 | 8-1 差异已处理 | 终检表＋投稿信 | 必须：作者信息定稿 |

**可连跑的组合**：

- 1 系四步：每步确认后继续，协商式，不建议跳步；
- 4 系四步：4-0（换对象时）→4-1→4-2→4-3，4-3 后可能返工，返工完重跑受影响检查；
- 6 系三步：6-1→6-2→6-3 顺序不可颠倒；6-2 先跑脚本；
- 7 系五步：7-1→7-2→**7-2.5（AI 语言特征自检）**→7-3→7-4，之后重测 AI 率、查重；
- 2 系与 3 并行：2-1→2-2 串行；3-1 可同时跑；
- 8 系两步：8-1→8-2，之后才生成最终 PDF。

**必须停下来等人工的门（八道）**：1-2 之后的换题决定；2-1 的逐条核验；**4-0 的映射表确认（换对象时）**；4-1 的写作计划与每节确认；4-3 的命题处置；5-2 的存疑/不实处理；6-3 的全部疑点；7-3 的改写拍板。

**低风险项可批量确认（v5 新增）**：格式、编号、抽检这三类默认通过＋抽检 10%，只把高风险项推到人前。但 **4-3 的命题处置、6-3 的疑点、5-2 的存疑/不实不得批量放行**——这三处一旦放过，后面所有环节都建在错的命题上。

## 轻量路径（时间紧时）

全套跑完，8000-20000 字的论文大约要 20-40 小时人工投入。时间有限时按最小链条跑：

```
1-1 聚类 → 1-2 覆盖度 → 1-3 论证链 → 1-4 章节拆解 → 2-1/2-2 论点
→（换对象时）4-0 映射 → 4-1 逐节写 → 4-2 对照 → 4-3 反方检验
→ 6-2 脚本查标号 → 6-3 只做 L1 → 7-1/7-2 清痕迹
```

省掉的环节及代价：6-1 真实性（文献可能是假的）、5 事实核验（数据可能是错的）、7-3 降 AI 率（检测可能不过）、8 投稿适配（格式返工）。**宁可省 7-3，不要省 4-0、4-3 和 6-2**——后三者是论证和引用的硬伤。

**清稿（7-1／7-2）也不得提前（v5 新增）**：提前清一次，之后每改一次都要重清、重导；更糟的是旧清稿与旧 docx 会被误当终稿。清稿必须等 4-3、6-3、5-2 全部结束，一次做完。

## 使用纪律（贯穿全体系）

1. **每个环节单独验收**：各 SOP 的“通过标准”过了再进下一环节，不欠账；
2. **人机分工不变**：AI 负责检索、整理、生成、检测、报告；人负责确认方向、核验论点、拍板存疑、最终改写；
3. **禁编造**：AI 不得补原文没有的论点（2 号）、不得补资料表外的数据（4/7 号）、不得编造检索结果（6 号）；缺数据写清缺口，不得用占位冒充数据；
4. **标记是过程产物**：全部临时标记在 7 号清除；**投稿稿与送检稿都不得残留任何标记**（不是"剩几个例外"，是 0）；
5. **术语不一致时以本文件为准**；
6. **复核必须独立**：4-2、5-2、6-3、7-4 的复核者不得与写作/整理者共享上下文。分两档——**最低：换会话；推荐：换模型族**；每次复核须在报告里写明实际用了哪一档；
7. **脚本优先于模型**：字符串比对、数字比对、标号映射、属性清理、**标点与字形检查**，先跑 `工具\核对脚本.py`（`punct` 子命令查“字符—字形—开合”三层，肉眼与文本搜索都查不出字形层）；
8. **保密与脱敏**：访谈对象姓名、未公开数据、涉密文件先脱敏；“实地资料”默认不外传；
9. **版本与台账**：每轮升版本号，修改留记录（改了什么、依据哪条意见、影响哪些论点）。一个项目内**同类台账只留一份**：入口与进度日志合一、SOP 缺陷与增补合一；决策台账、进度台账、SOP 修订台账各一份，不得出现第二份同类文件；
10. **检测结果是提示不是判决**：以人判断和目标机构要求为准；
11. **型比字数重要**：描述段写成论证段、论证段写成资料堆，都是“看起来像论文”的硬伤，比文笔差严重得多；
12. **合稿必须过四道硬校验**：① 三方对账（正文段数／引文标号数／参考文献条数）；② 编号连续（首现顺序递增、无缺号重号）；③ 无编号转述扫描（含转述词却无 [n] 的句子逐句判）；④ 标记数逐版比对（推／述／料／待补／待核五项，一变就要说清为什么）。**任一不过，不进下一环节**；
13. **台账锚点用编号，不用段序**：论点号、料号、W 号、[n] 是稳定锚点；段序只作辅助列，且必须与编号并列。删一段、插一段都会让后面几十个段号整体移位，段序台账必须整体重排，不能局部打补丁；
14. **自检数一律标“待复核”**：任何工具或 Bot 自报的数字（缺几个 hint、有几处标记、汉字多少）都只是待复核项；必须由**独立方在文件上重新数一遍**才算结论。宁可多跑一遍，不得把自检数当结果向上汇报；
15. **交付必须带清单与实数**：每次交稿附**改动清单**（段序｜改前｜改后｜理由）与**五数**（汉字、标号、推、述、料，另加占位标记数）；缺清单的稿子不进入下一环节；
16. **产物必须落项目目录**：Bot 私有工作区里的稿子不算交付，当场归档到项目对应目录；出现“稿在 A 处、表指 B 处”即为不合格；
17. **原著不可得时的引用口径**：正文点名（作者＋理论／著作）即可，具体内容由二手文献承载，写“中文学界一般把它概括为……[n]”；**不标一手页码、不加“直接引用”姿态**；若确有原著，再补直引。
