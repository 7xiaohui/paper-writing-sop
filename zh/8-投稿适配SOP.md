# 8·投稿适配——标准操作文件

## 本项工作做什么

把已经干净的定稿变成“能投出去”的稿件：把目标期刊的要求逐条落成清单（R1-Rn），逐条核对差异，完成格式、匿名化与投稿包。**这一步不改论证、不改结论**，只让稿件符合目标刊的规则。

很多稿子的最后一公里卡在这里：内容没问题，因为参考文献格式、图表规范、匿名要求被退修甚至退稿。

## 你手上有（输入）

1. **定稿**（已过 SOP-7，版本号记为 vN）；
2. **目标期刊的投稿要求**：投稿须知、论文模板、近期 3 期目录（看实际排版，须知常与实刊不一致）；
3. **作者信息**：姓名、单位、职称、通讯作者、基金项目、邮箱；
4. **（如有）期刊要求的声明模板**：作者贡献、利益冲突、数据可得性、AI 使用声明。

## 做完交出去（输出）

- **要求清单**（R1-Rn）：每条含“要求原文摘录 / 判定 / 差异 / 处理”；
- **合规稿**：按期刊模板排好的正文（双盲刊另出一份匿名稿）；
- **投稿信**（cover letter）；
- **作者信息表**与各项声明；
- **终检表**：投稿系统逐项打勾。

## 怎么做

### ① 要求清单化

把投稿须知拆成可勾选的条目，至少覆盖十二类：

| 编号 | 类别 | 要提取的内容 |
| -- | -- | -- |
| R1 | 篇幅 | 全文字数/字符数上限，含不含摘要、参考文献 |
| R2 | 结构 | 是否要求“引言/方法/结果/讨论”式，或允许自由结构 |
| R3 | 摘要与关键词 | 字数、是否结构化、关键词个数 |
| R4 | 参考文献 | 格式（GB/T 7714 或期刊自有）、数量上限、是否要求 DOI |
| R5 | 图表 | 三线表、图题位置、分辨率、彩图费用 |
| R6 | 标题层级 | 编号体系（一、（一）1. 或 1/1.1/1.1.1） |
| R7 | 匿名 | 是否双盲、需要删哪些信息 |
| R8 | 文件 | 格式（docx/PDF）、命名规则、是否分正文与附件上传 |
| R9 | 语言与风格 | 中英文、是否要求摘要英文、术语表 |
| R10 | 学术规范 | 查重阈值、AI 使用声明要求、伦理审批 |
| R11 | 版权与声明 | 版权协议、作者贡献、利益冲突、数据可得性 |
| R12 | 投稿系统 | 必填字段、推荐审稿人、附加材料 |

**字数口径（v5 新增）**：篇幅一律按**期刊规定的计数方式**算，不按写作者的直觉算。R1 里必须写清三件事：算什么（汉字数／字符数／Word 字数）、含不含（摘要、参考文献、空格、图表题注）、以哪个工具为准（投稿系统计数还是 Word“字数统计”）。

- 期刊按**汉字数／字符数**卡：写清是否含标点与空格，并注明统计口径来源；
- 期刊按 **Word 字数**卡上限：必须在 R1 里明写“按 Word 字数计”，并预留“**汉字数→Word 字数**”的折算余量——Word 把每个汉字、每个标点、每个英文词都计入字数，实测**汉字 7300 左右对应 Word 字数约 8900，差约 1600**。也就是说汉字稿排到 7300 字，投稿系统可能报 8900；清单要写成“目标汉字 ≤ 7300（≈ Word 8900）”，**按上限反推可写汉字数**，不要拿汉字数直接对标 Word 上限；
- 折算系数随英文摘要、数字、参考文献密度变化，**每篇实测一次再定余量**，不沿用固定系数；实测值与所用口径一并记入清单备注。

**要求冲突时**：以“投稿须知＋近期实刊”为准；两者冲突，按更严的执行，并在投稿信里说明（避免编辑认为你不看要求）。

### ② 逐条核对

每条给三档判定：**符合**（给出稿件中的位置作为证据）／**不符**（写差异与处理动作）／**不适用**（说明理由）。不许出现“大概符合”。

### ③ 格式落地

- 参考文献：按期刊格式逐条重排，重排后**重跑一次 6-2 标号映射**（格式转换最容易碰坏标号）；
- 图表：三线表、图题在图下/表题在表上，按刊要求；分辨率与字体统一；
- 标题层级：与期刊模板一致，不混用两套编号；
- 页眉页脚、行距字号、页码：按模板；
- 数字与单位：全文统一（万/亿、%与百分号、年月日格式）。

### ④ 匿名化（双盲刊才做）

- 删作者、单位、邮箱、致谢、基金编号；
- 清 docx 文档属性（作者/最后修改者/公司）：`python 核对脚本.py props 匿名稿.docx --author 匿名 --title 论文标题`；
- 文件名不含姓名与单位；
- 正文自引改为第三人称（“笔者曾指出”→“已有研究指出”），但**不得删除必要的引用**；
- 图片属性、脚注、页眉中的单位信息一并检查；
- 数据可得性声明、伦理审批号按刊要求保留或匿名。

### ⑤ 投稿包

- 正文（署名版 + 匿名版，如需要）；
- 图表源文件（可编辑格式）；
- 投稿信：研究问题、创新点、与刊物契合度、无重复投稿声明；**不夸大、不承诺无法验证的效果**；
- 作者信息表、贡献声明、利益冲突声明、版权协议；
- AI 使用声明（如刊物要求）：如实写用了哪些工具、用在哪些环节。

### ⑥ 终检

用提示词 8-2 做一遍机械核对；再人工过一遍 PDF 渲染效果（分页、图表位置、公式、参考文献悬挂缩进）。

终检必须**逐项确认**下面五项，缺一项不算终检（v5 新增）：

| 项 | 怎么确认 | 不合格长什么样 |
| -- | -- | -- |
| 占位标记 0 | `python 核对脚本.py marks 定稿.docx`（或先查 .md）零命中；【待补出处】【待核】【待定】【料N】一个不留 | 稿里还留着“【待核】”，到编辑手里就是硬伤 |
| 文档属性已清 | `props` 先 `--dry-run` 看，再正式写入，回读确认作者／最后修改者／公司／标题；自定义属性在 Word 里手清 | 属性里留着写作者姓名或工具名，双盲直接失效 |
| 参考文献编号连续、条数与正文标号一一对应 | `refs` 无悬空、无冗余、无跳号、无重复；格式转换后**再跑一次 6-2 映射** | 正文引到 [12]、文末只到 [11]；或文末多一条正文没人引 |
| 文献直引比例达标（1%–5%） | 用 6-3 的引号内容审计三列表核对：文献直引不为 0，占比落在 1%–5% | 全篇零直引（看不出与文献的接触面）；或直引过半（查重必高） |
| 页码连续 | 通读 PDF 页脚：正文首页到参考文献末页连号，无重号、无断号、无“第X页 共Y页”与实际不符 | 换模板或插分节后页码从 1 重起 |

五项全过，才在终检表上打勾；任一项不过，退回对应环节处理，不在终检表上写“基本可以”。

## 通过标准

- 要求清单 R1-Rn 每条都有判定，无“大概符合”；
- 所有“不符”项已处理，或已在投稿信中说明；
- 匿名稿经检查无作者/单位/基金/属性残留；
- 参考文献格式符合要求，且 6-2 映射重跑后无悬空/冗余；
- 投稿包齐全，文件名规范；
- 终检表全部打勾。

以上全过，本项工作通过，可以投稿。

## 注意事项

- **不改论证、不改结论**：为迎合期刊字数而删内容时，只能删背景与冗余表述，不能删核心论证；删了要回 SOP-4 重跑对照检查；
- 匿名不等于删数据：数据可得性、伦理声明按刊要求保留；
- 投稿信是“说明”不是“吹嘘”：不写“国际领先”“填补空白”这类无法证实的判断；
- 格式转换后必须重跑标号映射——这是最容易出低级错误的地方；
- 一稿一投；被拒改投时，重新做①的要求清单，不要拿上一家模板硬套；
- 定稿后如需再改，升版本号并记入《修改台账》，不要在多份文件上同时改。

## 提示词

### 提示词1 · 期刊要求对照（给整理 AI）

```
你是目标期刊的投稿合规检查员。我给出：①期刊投稿须知/模板原文；②我的论文定稿；
③（可选）该刊近期3期目录或已发表文章。

请完成：
1. 从须知中提取可执行要求，编号 R1-Rn，覆盖：篇幅、结构、摘要关键词、参考文献格式、
   图表规范、标题层级、匿名要求、文件格式与命名、语言风格、查重与AI声明、版权与声明、
   投稿系统字段。每条附"须知原文摘录"。
2. 逐条对照我的定稿，给出判定：符合（给稿件位置）/不符（写差异）/不适用（写理由）。
3. 输出差异清单，按"会被退修"到"仅影响观感"排序。
4. 须知与近期实刊排版冲突时，单独列出冲突项，并给建议（按更严的执行）。

硬约束：不许猜测须知没写的要求；须知没提的，标"须知未规定"，不要自己编标准。
输出：要求清单表（编号/类别/要求原文/判定/差异/处理建议）＋冲突项＋差异排序。
```

### 提示词2 · 投稿前终检与投稿信（给整理 AI）

```
你是投稿前终检员。输入：合规稿全文、要求清单 R1-Rn、作者与基金信息、目标期刊名。

一、终检（逐项打勾或标问题）
1. 字数是否在限内（分别统计含/不含摘要与参考文献）；
2. 标题层级是否统一，有无混用两套编号；
3. 参考文献条数是否合规，格式是否统一，正文标号与文末是否一一对应；
4. 图表是否都有编号、标题、正文提及；
5. 摘要与关键词是否符合字数与个数要求；
6. 匿名稿是否残留作者、单位、基金、文档属性信息；
7. 文件名是否符合要求；
8. 必备声明是否齐全（贡献/利益冲突/数据可得性/AI 使用）；
9. 有无"待补""待核""TODO"等残留。

二、投稿信（300字以内）
- 研究问题与核心发现（各一句，来自正文，不夸大）；
- 与目标期刊的契合点（引用该刊近期一篇相关文章说明）；
- 无重复投稿、全体作者同意投稿的声明。

输出：终检表（项目/结论/问题）＋投稿信初稿＋仍需人工补的字段清单（如通讯作者电话、基金编号）。
不要编造作者信息、基金号、审稿人姓名。
```
