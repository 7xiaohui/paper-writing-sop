# 模板 · 对象映射表（SOP-4 第零步用）

> 用途：换对象写作时（如“陕西壁画的优势”→“钧瓷的优势”），把原文章的**维度**迁过来，把**原对象的事实**留在门外。
> 用法：先让 AI 按 4-0 提示词填草稿，再人工逐行补料号。**“原对象证据”列只作参照，写作时不得进入正文。**

## 一、维度清单（从原文章抽，4-8 个）

| # | 维度 | 原文章怎么论证这个维度（一句话） | 是否通用 |
| -- | -- | -- | -- |
| 1 | 历史纵深 | | 通用 |
| 2 | 视觉辨识度 | | 通用 |
| 3 | 工艺独特性 | | 通用 |
| 4 | 产业转化 | | 通用 |
| 5 | 传承机制 | | 通用 |

> 判定“是否通用”的问句：**把对象换掉，这个维度还成立吗？** 成立＝通用维度；不成立＝原对象专属结论，删掉。

## 二、映射表（核心）

| 维度 | 原对象证据（仅参照，禁入正文） | 本对象对应事实 | 料号 | 可写性 | 备注 |
| -- | -- | -- | -- | -- | -- |
| 历史纵深 | | | 料__ | 可写/待核/无 | |
| 视觉辨识度 | | | 料__ | | |
| 工艺独特性 | | | 料__ | | |
| 产业转化 | | | 料__ | | |
| 传承机制 | | | 料__ | | |

**可写性三档**：

- **可写**：本对象事实有料号，可直接写描述段；
- **待核**：缺料。写清“缺什么＋建议来源＋检索式”，不许用常识补；
- **无**：本对象不适用。删掉该维度，并在章导语里不出现。

## 四、迁移残留自查（写完正文后回看）

| 检查项 | 结果 |
| -- | -- |
| 正文是否出现原对象地名/机构名 | 有/无 |
| 正文是否出现原对象的数据或年代 | 有/无 |
| 是否有只在原对象成立的结论被改主语后沿用 | 有/无 |
| “无”的维度是否已从正文删除 | 是/否 |
