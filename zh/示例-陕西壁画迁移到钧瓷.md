# 示例：从“陕西壁画的优势”迁到“钧瓷的优势”

> 这份示例对应 SOP-4 的第零步与第一步，用来回答一个问题：**换题材时，AI 该加什么、不该加什么。**
> 说明：原文章未提供，四个维度是按常见写法假设的；所有数字用 X/Y 占位，表示“必须有料才填”，不代表真实数据。

## 一、原文章可能在论证什么

假设原文写“陕西壁画的优势”，用了四段：

1. 历史跨度：自汉唐延续千年，形成完整序列；
2. 视觉辨识：矿物颜料形成独特色系；
3. 工艺独特性：绘制工序复杂、技艺门槛高；
4. 产业转化：文旅收入 X 亿元、带动就业。

## 二、先做迁移判定（哪些能搬）

| 原文表述 | 判定 | 处理 |
| -- | -- | -- |
| 自汉唐延续千年，形成完整序列 | **对象专属**：结论和证据都是陕西的 | 作废。只保留“历史纵深”这个维度，钧瓷的年代必须用自己的料重写 |
| 矿物颜料形成独特色系 | **对象专属结论** | 作废。钧瓷的辨识度来自釉，不是颜料，不能改主语 |
| 从色彩/题材/工艺看优势 | **通用维度**（分析框架） | 可迁移。迁移后每个维度都要填钧瓷的事实 |
| 文旅收入 X 亿元 | **对象专属数据** | 作废。换成钧瓷的产值/企业数，并给料号 |

**结论**：能搬的只有“维度”，搬不动“结论”，更不能搬“证据”。把“陕西”换成“钧瓷”、其余照抄，是最典型的跑偏。

## 三、对象映射表（换对象后的产物）

| 维度 | 原对象证据（仅参照） | 本对象对应事实 | 料号 | 可写性 |
| -- | -- | -- | -- | -- |
| 历史纵深 | 汉唐墓室壁画序列 | 【待核：钧瓷始烧年代、宋代五大名窑的文献记载】 | 料3（待补） | 待核 |
| 视觉辨识 | 矿物颜料独特色系 | 铜红釉在还原焰中呈色随窑位与温差变化，“入窑一色、出窑万彩” | 料5 | 可写 |
| 工艺独特性 | 壁画绘制工序 | 【待核：钧瓷烧制工序的权威记载】 | 料6（待补） | 待核 |
| 产业转化 | 某年文旅收入 X 亿 | 神垕镇钧瓷企业 X 家、年产值 Y 亿元 | 料7-1 | 待核 |

（表里“待核”不是失败，是**诚实的空白**。补料前不写，比写错强。）

## 四、两版段落，一眼看出差别

### 坏版本（v2 规则下最容易出现）

> 钧瓷作为中国陶瓷艺术的瑰宝，历史悠久、釉色绚丽、工艺精湛，具有极高的艺术价值和广阔的产业前景。

问题：4 个评价、0 个出处；可以套在汝瓷、建盏、景德镇青花上；属于“描述段里的无料评价”，4-2 会直接命中。

### 好版本（按段落型写，只用有料的部分）

> 【述】钧瓷的釉色辨识度来自铜红釉的呈色特征。还原焰中，釉面呈色随窑位与温差变化，同一窑不同位置可出不同色调，故有“入窑一色、出窑万彩”之说【料5】。
>
> 【论12】这种不可完全复现的呈色，使钧瓷在宋代名窑中形成独立的审美标识。
>
> 【推】由【料5】与【论12】可知，钧瓷的优势首先不在产量或价格，而在呈色工艺带来的辨识度；这为后文讨论品牌化路径提供了依据。

如果料5 还没拿到，第二段不写，改成占位：

> 【待核｜铜红釉呈色记载｜《钧瓷烧制技艺》申报书或《钧瓷志》｜词=铜红釉 窑变】

## 五、4-2 会怎么查这个例子

| 检查项 | 坏版本 | 好版本 |
| -- | -- | -- |
| 无料评价 | 命中（4 处） | 无 |
| 段落型错配 | 命中（描述章写成评价） | 无 |
| 迁移残留 | 可能命中（“历史悠久”沿用壁画论证） | 无 |
| 待核被写成实句 | — | 若把“待核”那句写成肯定句，命中 |
| 论据落对象 | — | 命中（每段都落到钧瓷） |

## 六、一句话

**论点表管“证明什么”，对象映射表管“用什么证明”，段落型管“这段该不该证明”。** 三件事分开，AI 就没有空子可钻——它要么填上有料号的槽，要么留下一个看得见的待核。
