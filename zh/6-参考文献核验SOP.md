# 6·参考文献核验——标准操作文件

## 本项工作做什么

对文末参考文献清单做三步系统核验：**真实性**（条目是否真实、题录信息是否写错）、**标号映射**（正文引用与清单是否一一对应）、**引用语义**（引文是否真正支撑论述、有无漏引）。只输出疑点与报告，修改与补引由人定。

核心结论：真正拉开核验结果差距的不是模型，而是三条——是否制定了明确可执行的校验规则；是否把任务拆成独立串行的步骤；是否约束 AI 禁止脑补文献信息与引用关系（幻觉主要来源于此）。

三个步骤必须**串行执行**、分步拿报告：第一步 真实性校验 → 第二步 标号映射校验 → 第三步 引用语义与相关性复核。

## 你手上有（输入）

1. **参考文献清单**：文末列表，逐条含作者、题名、刊名、年份、卷期、页码、DOI（第一步只需要清单）；**选题阶段的学库清单（W1-Wn）同样适用第一步**，通过后才允许进入 SOP-2 提炼；
2. **论文正文**：带引用标记的正文（第二步、第三步需要）；
3. **公网核验渠道**：见“怎么做·第一步”的渠道表，全程不依赖知网账号。

## 做完交出去（输出）

- 《参考文献清单真实性报告》（第一步）；
- 《引用标号映射报告》（第二步）；
- 《引用相关性复核报告》（第三步，L1/L2 分层）；
- 三份报告合并后的《冲突汇总表》，按组合风险分级处理；
- **文献条数对账**：参考文献条数与选题报告承诺的目标区间（**25–30 条**）逐项对账，单列一行；少于下限须写明理由（选题窄、可用文献少、已删冗余条目等），不写理由视为未过。

## 怎么做

### 第一步 · 参考文献真实性校验

目标：只看清单本身，判断每条文献是否真实存在、题录字段是否写错。

**题录来源两档口径（先分档，再决定核不核）：**

| 档 | 来源 | 处理 |
| -- | -- | -- |
| 甲档 · 用户自 CNKI 导出 | 用户本人检索并导出的题录（.txt／.xls／.ris，字段齐全） | **直接视为可信，不再核对**；只做著录格式规范化（标点、全半角、卷期写法），不改字段值，也不另找来源推翻 |
| 乙档 · 团队联网检索所得 | 团队（含 AI）经 NSTL／NSSD／万方／维普／CALIS／Crossref 等公开渠道查得并回填的题录 | **必须向用户披露来历**：渠道、检索式、命中页面或链接、检索时间；**由用户核**（抽查或逐条），认可后才算可信 |

- 分档不明时归乙档：宁可多披露一次，不可把团队检索所得冒充用户题录；
- 乙档未经用户核的，报告结论栏最高写“待用户核”，不得写“可信”；
- 甲档若发现字段缺漏（如缺页码），仍按第二步补页码规则处理，不算推翻甲档。

**中文文献核验渠道（无知网场景）**——公网可直接检索题录与摘要，无需知网账号或机构 IP，部分平台免费注册即可：

| 渠道                     | 网址                                | 适用场景          | 定位         |

**英文文献核验渠道（以 Crossref 为核心）：**

| 渠道             | 网址                            | 定位                    |
| -------------- | ----------------------------- | --------------------- |
| Crossref       | <https://www.crossref.org/>   | 核心比对源，DOI 优先解析        |
| 期刊官网 / 出版商主页   | 按目标期刊查询                       | 权威兜底                  |
| Scopus 公开检索页   | <https://www.scopus.com/>     | 免费题录摘要，不需机构订阅         |
| Google Scholar | <https://scholar.google.com/> | 辅助兜底，不能推翻 Crossref 结果 |
| arXiv          | <https://arxiv.org/>          | 预印本独立核验               |

**判定规则：**

- **可信**：有 2 个及以上独立权威数据源，核心字段（作者、题名、刊名、年份、卷期）一致；允许不同数据库著录格式差异（有无卷号、页码取舍、标点全半角），格式差异不算事实错误。
- **存疑**：仅百度学术可检出、权威库检索不到；多个权威源核心信息互相冲突；增刊、内刊、早期纸质文献、未数字化文献。明确原则：**查不到不等于判定伪造**。
- **疑似伪造**：所有渠道均检索不到，且刊名或刊号不存在、年份超出期刊创刊时间、卷期页码明显违背常理。

**关于知网的特别说明**：AI 没有知网账号，无法登录知网，也不能绕过权限读取知网付费或机构限定内容。整个核验流程**不把知网作为免费核验源**，改用公开元数据库交叉比对。

### 第二步 · 标号映射校验

目标：核对正文引用标记与文末参考文献列表的对应关系。本步骤完全不看内容语义，只做数字标号匹配。

- **正向核查**：正文出现 `[n]`，文末列表无编号 n → **悬空引用（死标号，无效引用）**；
- **反向核查**：文末第 n 条文献，全文没有任何一处标注 `[n]` → **悬空参考文献（冗余文献）**；
- **其他异常**：同一句话重复标注同一文献、标号跳号、序号不连续（标记提醒即可）；
- **页码规则**：页码以 **PDF 页脚／文章编号／官方题录**为准——能开原文的看 PDF 页脚实际刊页；只有题录的用文章编号（DOI、知网篇名号）反查官方题录页；两者都取不到，写【待补页码】并在底表记补核路径（去哪个库、用什么检索式、找谁）。**禁止按位置估算**，不得按“大概在第几页”推算，也不得把 PDF 阅读器页码直接当刊页；竖排反序页脚等特殊版式须记判读依据。

本步骤是纯字符串匹配，规则写清楚任何模型都能稳定完成，幻觉风险最低。**优先跑脚本**：`python 核对脚本.py refs 正文.md 参考文献.txt`，直接输出悬空引用／冗余文献／重复标引／跳号差异表；模型只负责解释差异、给修改建议，不让它“数一遍”。

### 第三步 · 引用语义与相关性复核（L1/L2 分层）

目标：判断引文是否真正支撑文中论述，识别潜在漏引。**先粗后精，兼顾准确率与成本**：

- **L1 摘要级初筛（批量、低成本）**：对所有引用逐条做题录加摘要级相关性判断与漏引识别，输出疑点清单，并把每条引用的相关性置信度分档（高、中、低）；
- **L2 全文级复核（精准、高成本）**：仅对 L1 中判定为中低置信度的高风险引用，以及所有涉及关键数据、方法、定义的引用，下载全文逐句比对，输出最终判定（支撑成立／支撑不足／明显不支撑）。

多数低风险引用停留在 L1，少数高风险引用进入 L2。**全文获取约束**：英文优先开放获取全文（PMC、出版社 HTML 全文、作者主页、机构知识库）；中文优先 NSSD 免费全文、期刊官网 OA；实在无法获取全文的停留在 L1，标记“人工复核”。

**漏引识别规则**——需要标记【潜在漏引疑点】的句子类型：

1. 经典理论、概念定义、成熟模型；
2. 外部统计数据、基准参数；
3. 表述“已有研究表明、学界普遍认为、某学者发现”等前人成果。

不需要标记的：作者自己的分析、自己的实验结果、自己提出的框架、自己的讨论推论。

> AI 禁止自动检索新增文献、禁止自动推荐“应引用某文献”，只标记句子位置，由人工决定是否补引、补哪一篇。

**补检一 · 无编号转述扫描（机械筛、人工判）：**

- 先机械筛：用正则或脚本扫全文，抽出**含转述词却无 `[n]` 的句子**。转述词表：指出、认为、提出、发现、研究表明、调查显示、据统计、有学者、学界、文献、相关研究、已有研究、某高校、某地实践、按照……的分类、借鉴……的做法；
- 再逐句判断：该句是“对某文献内容或做法的转述”，还是“作者自己的归纳”。命中者按漏引处理——补 `[n]` 并进参考文献表；确属作者自述的，在复核表写明理由后放行；
- **凡正文引述文献，不论是否承担论证，一律占号进表**；转述型与论点型**共用同一套顺序编号**，不另设编号段，也不因“只是个事实陈述、不靠它论证”就不占号；
- 第二步的映射报告**增设“转述型引用”专节**：逐条列该句、对应文献、编号，并注明“本段不靠它论证”；该专节与论点型引用同表同号，只多一列用途说明。

**补检二 · 引号内容审计（清稿前必做）：**

- 遍历全文所有引号内容（“”‘’与英文 "" ''），**逐处归类**，只许三类：①**文献原文直引**（逐字照录某条参考文献，须带 `[n]`）；②**自建概念／术语**（作者自造的概念、框架名、缩写，不占号）；③**政策材料原文**（法规、文件、规划的原句，按【料N】核，不进参考文献编号）；
- 出**三列表**：引号内容原文｜类型（①②③）｜出处（`[n]`／无／【料N】）；同时给各类处数、汉字数；
- **统计文献直引占正文汉字的比例**（直引汉字数 ÷ 正文汉字数，不含参考文献表），比例须连口径写；
- 判定线：**文献直引为 0，不得进清稿**；目标 **1%–5%**（下限至少 4 处、约 70 汉字）；**超过 10% 须压缩**，优先压非论证段（背景、意义、保障措施），不动核心论证；
- 补引优先用**已在用的文献**（在清单内挑，不新增条目）；直引格式为中文引号＋`[n]`，逐字照录，不改字、不拼接两句、不加省略号跨段；页码范围由参考文献表承载，正文不加页码。

**AI 读取文献格式的难易度（供 L2 用）：**

| 格式           | AI 读取难度 | 优点                   | 缺点         | 适用场景                |
| ------------ | ------- | -------------------- | ---------- | ------------------- |
| TXT/Markdown | 最低      | 纯文本，无排版噪声            | 需先转换，丢失结构  | 已清洗文本               |
| HTML 全文      | 低       | 结构清晰、标题段落完整、无 OCR 误差 | 需去除页面广告等噪声 | 英文 OA 全文首选（PMC、出版社） |
| XML（JATS）    | 低至中     | 出版标准、机器可读性最强         | 普通用户难获取    | 出版商或数据库导出           |
| DOCX         | 中       | 结构较好                 | 样式噪声       | 作者原稿                |
| PDF（文本层）     | 中至高     | 最普遍、通用               | 双栏、公式、图表干扰 | 兜底方案                |
| PDF（扫描版）     | 高       | 覆盖老文献                | 需 OCR，错误率高 | 老文献，谨慎使用            |
| CAJ          | 高       | 知网原生格式               | 需专有阅读器     | 知网下载件，建议转 PDF       |

推荐策略：英文文献优先找 HTML 全文（PMC、出版社官网）；中文文献优先期刊官网 OA 全文、NSSD 免费全文；只有 PDF 时优先带文本层的数字原生 PDF；老文献扫描件需 OCR，错误率高，仅作参考。

## 冲突汇总表

三份报告合并后生成总核查表，按组合风险分级处理：

| 组合             | 风险等级 | 处理方式         |
| -------------- | ---- | ------------ |
| 第一步标记疑似伪造且正文引用 | 最高   | 优先人工核查，必要时删改 |
| 第一步标记存疑且正文引用   | 高    | 人工复核真实性后再定   |
| 第二步悬空引用或冗余文献   | 中    | 修正标号         |
| 第三步低置信度引用      | 中    | 进入 L2 全文复核   |

## 通过标准

- 清单每条有结论（可信/存疑/疑似伪造），疑似伪造优先人工核查、必要时删改；每条结论附核验来源与链接；
- 无悬空引用、无冗余文献（或已修正标号）；
- 高风险引用已完成 L2 全文复核；漏引疑点已交人工定夺；
- 全程无 AI 编造检索结果与文献元数据。

## 注意事项

1. 老文献、内刊、增刊、会议摘要集、未数字化出版物查不到**不等于假文献**；
2. 区分著录格式差异与事实信息错误：标点、大小写、作者缩写、空格属于格式问题，不算虚假文献；
3. 依赖 Crossref 的引文工具对中文支持差，不用于中文核验；
4. 语义相关性判断为半主观，AI 输出疑点、人工定稿；
5. 全程禁止 AI 编造检索结果与文献元数据，检索不到就如实记录；
6. AI 无法绕过知网权限，不把知网作为免费核验源；
7. **复核独立性**：6-3 的语义复核不要与 4-1 的写作共用会话——写作时“顺手”看过的句子，复核时会天然认可；
8. **脚本只做标号与格式，不做真假与语义**：不要拿 6-2 的脚本结果冒充 6-1 或 6-3 的结论。

## 提示词

### 提示词一 · 参考文献真实性核验（带链接完整版）

```
你现在是学术论文的参考文献题录核验专员，我们现在进行参考文献真实性核验，对我给出的参考文献逐条校验真伪与信息正误，区分中文文献、英文文献两套核验逻辑，全程不依赖知网账号、不访问知网受限内容。仅核验公开可获取的题录元数据，不需要下载全文。
一、中文文献核验规则（无知网）
可核查数据源优先级（公网可直接打开链接，检索题录或摘要，无需知网权限）：
1. NSTL国家科技图书文献中心：https://www.nstl.gov.cn/ （理工农医类优先）
2. NSSD国家哲学社会科学文献中心：https://www.ncpssd.cn/ （社科期刊优先）
3. 万方智搜：https://www.wanfangdata.com.cn/
4. 维普中文期刊平台：https://qikan.cqvip.com/
5. CALIS联合目录公共检索：http://opac.calis.edu.cn/ （图书、专著、学位论文）
6. 全国图书馆参考咨询联盟UCDRS：http://www.ucdrs.cn/ （学位论文、图书兜底）
7. 百度学术：https://xueshu.baidu.com/ （仅作为初筛工具，不可单独作为判定依据，必须至少一个上面的权威库复核）
8. 期刊官方网站当期目录（最高优先级，有条件优先采信）

中文判定规则：
【可信】有2个及以上独立权威数据源，核心字段（作者、题名、刊名、年份、卷期）一致；允许不同数据库著录格式差异（有无卷号、页码取舍、标点、全半角），格式差异不算事实错误。
【存疑】仅百度学术能搜到、权威库检索不到；多个数据源核心信息互相冲突；增刊、内刊、早期纸质文献、未数字化文献标记存疑；明确：查不到不等于判定伪造。
【疑似伪造】所有渠道均检索不到，且刊名或刊号不存在、年份超出期刊创刊时间、卷期页码明显违背常理。

二、英文文献核验规则（以Crossref为核心）
数据源优先级：
1. Crossref：https://www.crossref.org/ （DOI优先解析，英文文献主要采信源）
2. 期刊官方网站或出版商主页
3. Scopus公开检索页：https://www.scopus.com/ （免费摘要题录，不需要机构订阅权限）
4. Google Scholar：https://scholar.google.com/ （辅助兜底，不能推翻Crossref的匹配结果）

英文判定规则：
【可信】有DOI，Crossref解析返回题录，和参考文献条目核心信息匹配；无DOI时，使用标题加作者在Crossref检索命中，信息一致。
【存疑】无DOI，Crossref检索不到，仅谷歌学术可检索到；arXiv预印本、学位论文、小众专著、会议摘要、灰色文献统一标记存疑。
【疑似伪造】DOI无效，Crossref返回信息和条目严重冲突；全部渠道检索不到、期刊尚未创刊或不存在。

补充：arXiv独立核验地址：https://arxiv.org/ ，Crossref经常不收录arXiv预印本。

三、统一输出格式，每条参考文献严格按模板输出
序号｜原文参考文献条目
核验语种：中文或英文
核验来源：（列出本次比对用到的数据源名称加链接简写，并附实际检索地址）
结论：【可信／存疑／疑似伪造】
差异明细：
- 匹配项：xxx
- 不一致或异常字段：（无异常就写：无）
备注：（说明原因，例如：无DOI、仅百度学术检出、属于预印本、年代较早数字化缺失、OnlineFirst在线优先出版等）

四、强制约束
1. 严格区分【著录格式规范问题】和【文献事实信息真假错误】；标点、大小写、作者缩写、空格属于格式问题，不判定为虚假文献。
2. 禁止编造检索结果，检索不到就如实记录检索不到，严禁幻觉编造文献元数据。
3. 区分文献类型：期刊文章、学位论文、专著图书、会议论文、预印本，在备注中标注。
4. 一条文献同时存在中英文两个版本，分开独立核验。
5. 只输出核验诊断，不要自动修改参考文献原文；如需修正建议，我会单独提要求。
6. 全程不尝试访问知网受限内容，不依赖知网账号、机构IP。

接下来我会批量粘贴参考文献，请逐条执行这套核验规则。
```

### 提示词二 · 标号映射校验

```
你现在是学术论文的参考文献题录核验专员，我们现在进行【引用标号双向映射校验】，仅做标号数字匹配，不判断内容相关性、不核验文献真假、不解读论文观点。  
输入材料：①带引用标记\[1\]\[2]…的论文正文；②文末参考文献列表。

任务规则：

1. 提取正文全部出现的引用标号集合；提取参考文献全部序号集合。
2. 正向核查：正文里所有[n]，检查参考文献列表是否存在编号n。不存在标记为【悬空引用／死标号】。
3. 反向核查：参考文献列表中所有编号n，检查全文正文是否存在[n]。正文找不到标记为【悬空参考文献（冗余文献）】。
4. 额外统计：重复标号、同句重复标引、标号跳号，全部列出。

输出格式：

1. 正文检出全部引用标号集合：{xxx}
2. 参考文献存在标号集合：{xxx}
3. 【悬空引用（死标号）】：列表，写明标号加出现位置（段落或句子摘抄）
4. 【悬空参考文献（冗余文献）】：列表，写明标号加对应的参考文献原文
5. 【其他标号异常】：重复标引、跳号等

备注：本步骤只做标号匹配，不评价引用是否合适，不判断文献是否真实。
```

### 提示词三 · 语义相关性加漏引复核（L1/L2 分层）

```
你现在执行【引用相关性与潜在漏引复核】，本步骤必须建立在①参考文献真实性核验完成、②标号映射校验完成的基础上。  
输入材料：带引用标记的论文正文、已经过前两轮核验的参考文献清单。

硬性约束：

1. 你不能判定绝对的"错误引用"，只能输出【相关性疑点】；综述、二次转述、概括性引用有可能主题不完全一一对应，属于合理情况，不要误判。
2. 严禁主动检索、新增、推荐任何不在现有参考文献列表内的文献，不能自动给作者补参考文献。
3. 区分：作者原创结论、自身实验结果、自身推导内容，不需要引用，不标记漏引。
4. 只标记疑点，最终是否调整引用、补充引用，全部由人工学术审核决定。

任务分为两层：  
L1摘要级初筛（全部引用执行）：

- 逐句检查带有[n]引用标记的句子，提取核心论点，结合对应编号参考文献的题名与摘要信息，判断支撑相关性；
- 输出【匹配良好】或【疑似错配引用】（文献主题和句子论点关联性弱、主题偏离），并摘抄句子加文献条目说明差异；
- 同时按任务B规则识别潜在漏引；
- 对每条引用给出相关性置信度分档：高／中／低。

L2全文级复核（仅对以下条目执行）：

- L1中判定为中低置信度的引用；
- 涉及关键数据、方法、定义的引用；  
  对上述条目，逐一阅读对应文献原文全文，定位具体章节或段落，验证句子主张是否被原文支撑，输出最终判定【支撑成立／支撑不足／明显不支撑】。

任务B（漏引识别，贯穿L1）：  
逐句检查无引用标记的陈述，当句子属于下面类型时标记【潜在漏引疑点】：  
①经典理论、概念定义、成熟模型；②外部统计数据、基准参数；③表述"已有研究表明、学界普遍认为、某学者发现"这类前人成果。  
不属于漏引：作者自己的分析、自己的实验结果、自己提出的框架、自己的讨论推论。

输出格式：  
一、疑似引用错配清单：句子位置加原文｜引用标号｜对应文献标题｜疑点说明｜置信度分档  
二、L2全文复核清单：引用标号｜原文句子主张｜文献原文对应位置｜最终判定  
三、潜在漏引疑点清单：句子位置加原文｜疑点类型（定义、数据、前人结论等）｜备注：建议人工复核是否需要添加引用  
四、总体备注：本环节为语义疑点筛查，不构成学术定稿结论，全部需要人工复核。
```
